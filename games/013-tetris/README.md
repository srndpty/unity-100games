# 013. テトリス — STRATA DROP

仕様書：[plan/games/013-tetris.md](../../plan/games/013-tetris.md)

落ちてくる鉱石の塊を積み、横一列にそろえて地層を掘り抜く落ち物パズル。参考作品からはメカニクスだけを採用し、名称、絵、配色、音は独自に作っている。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード。HUD のボタンはマウスでも押せる。HUD は PanelRenderer / UI Toolkit。日本語は Windows の Yu Gothic で表示する

## 起動手順

```
dev gui 013      # エディタで開く
dev build 013    # Windows ビルド
dev run 013      # ビルドを起動
dev capture 013  # 証跡を evidence/ に撮る
```

シーンは `Assets/Scenes/StrataDrop.unity`。

## 操作

| 入力 | 内容 |
|---|---|
| ← → / A D | 左右へ移動。長押しでリピート |
| ↓ / S | ゆっくり落とす（ソフトドロップ） |
| Space | すぐ落として確定する（ハードドロップ） |
| ↑ / X | 右回転 |
| Z | 左回転 |
| C / 左Shift | ホールド |
| Esc / P | 一時停止、再開 |
| Enter / ボタン | 開始、再開、もう一度 |
| R / ボタン | やり直す（一時停止中と結果画面） |
| T / ボタン | タイトルへ（一時停止中と結果画面） |

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 盤面 | 幅10×可視20＋非表示4段（計24段）。範囲外は壁扱いで、天井より上にも入れない |
| 供給 | 7-bag。袋ごとにシード付き Fisher-Yates で混ぜる。次の5個を表示する |
| 出現 | 非表示の最下段に北向きで出現し、空いていれば直ちに1段下げる |
| 回転 | 右・左の90度。5候補のキック表（JLSTZ 共通、I 専用）を順に試す。O は回転しない。180度回転なし |
| 移動 | 左右に1マス。長押しは10 Tick 後から2 Tick ごと。後から押した方向を優先する |
| 重力 | 60Hz の固定 Tick。レベルごとの「1段に要する Tick 数」の整数表（48〜1） |
| ソフトドロップ | 2 Tick で1段（重力の方が速ければ重力）。1段につき1点。接地しても即確定しない |
| ハードドロップ | 即落下・即確定。1段につき2点 |
| 接地猶予 | 30 Tick。移動・回転の成功で計り直す。1ピース15回まで。より低い段へ進むと回数も戻る |
| ホールド | 1ピースにつき1回。初回は次のピースを出す。戻したピースは出現位置・北向きから |
| ライン消去 | 確定時に判定し、18 Tick の演出の後に消して上の段を詰める。上の段は消した段数だけ単純に下がる |
| 得点 | 1〜4ライン＝100 / 300 / 500 / 800 × 消す前のレベル。T-spin、コンボ、連続ボーナスなし |
| レベル | 10ラインごとに1上がる。上限15 |
| 敗北 | ①出現位置が埋まっている ②ピース全体が非表示の段で確定した。勝利はなく、結果画面でスコアを表示する |
| 記録 | 最高スコアは起動中のみ保持し、ファイルへ保存しない |
| 着地点 | ハードドロップの着地点を薄く表示する |
| 再戦 | 試合ごとに新しいシードを使う |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core | `Board`（確定ブロック）、`ActivePiece`（操作ピース）、`PieceShapes`（形のデータ）、`KickTable`（キックのデータ）、`SevenBag`（供給）、`StrataConfig`（設定）、`StrataGame`（1試合の進行） |
| App | `StrataFlow`（画面遷移、操作の窓口、実時間から Tick への変換）、`ShiftRepeater`（左右の長押し）、`Autopilot`（撮影とテスト専用の操縦役） |
| Unity | `StrataDropGame`（入力・HUD・音）、`StrataDropView`（描画）、`StrataDropSettings`（設定アセット）、シーンと素材の生成、撮影台本 |

- **確定ブロックと操作ピースを別の型にする。** `Board` は不変で確定ブロックだけを持ち、`ActivePiece` は盤面を知らない不変の値にした。合法手の判定は `Board.Fits` の1か所に集まる。
- **回転はデータで決める。** 形は北向きだけを定義して枠の中で回し、キックは回転の向きごとの表にした。逆回転の候補が符号反転になることをテストで確かめている。
- **Core は整数だけで動かす。** 時間も Tick 数で持つので、Mono と .NET で結果が一致する。同じシードと入力列の最終盤面を固定のハッシュ値で照合している。
- **接地したまま操作し続けても必ず確定する。** 猶予の延長に回数の上限があり、回数が戻る条件の「より低い段」は下がる一方なので、延長の総数にも上限がある。
- **演出は Tick から決める。** ライン消去の点滅は `TickCount` から求めるので、同じ状態なら撮影でも同じ絵になる。
- **操作は押した順に処理する。** すべての入力を1本の列に入れ、フォーカス復帰の直後の入力は終了ボタンも含めて捨てる。
- **押しっぱなしを持ち越さない。** 一時停止、再戦、フォーカス喪失で長押しとソフトドロップを解除し、キーを押し直すまで動かない。
- **物理エンジンは使わない。** 落下と衝突はすべて Core のマス目で判定する。

設定アセットは `Assets/Game/Unity/StrataDropSettings.asset`。重力表、接地猶予、消去演出、得点、長押しの間隔、音量を調整できる。

シーンの再生成：

```
unity run games/013-tetris -- -executeMethod Game.Unity.Editor.StrataDropSceneBuilder.Build
```

素材は `StrataDropArtGenerator` が図形から描き出した PNG。再生成は既存のファイル、そのインポート設定、Prefab を上書きしない。
