# 013 振り返り

2026-11-19に人間の完了承認を受領。

## 新たに学んだ点

確定ブロックを不変の `Board`、操作ピースを盤面を知らない値に分けると、移動・回転・着地点の計算がすべて `Board.Fits` の判定に集まった。Core を整数だけで書くと、Mono と .NET で最終盤面のハッシュ値まで一致させられた。

## 想定との差

UI Toolkit のボタンは `ClickEvent` を送っても反応せず、ポインタイベントが必要だった。反応しないことを確かめるテストは、この誤りがあっても通ってしまう。レビューでは、長押しのPlayModeテストがテスト自身の操作でピースを動かしており、入力の接続を確かめていないことが分かった。012で学んだ、キーを押したフレームの経過時間を長押しに数えない点も、固定Tickへ変換する構成で再発した。

## 次回の改善点

「押しても何も起きない」ことを確かめるテストは、同じ手順で「押すと起きる」場合も一緒に確かめる。入力のE2Eテストでは、確かめたい処理をテスト側から呼ばない。
