## 操作

キャラクター選択では、←→ またはクリックで操作するキャラを選び、Enter または「このキャラで戦う」で開始する。シンダーは火球を使う柔道家、キルンは突進で距離を詰める米軍出身の格闘家。

対戦中のコマンド表は画面左上。矢印キーまたは WASD で移動・しゃがみ・ジャンプ、相手と逆方向を押してガード。J で弱、K で強、↓＋L で足払い、J＋K で投げ。必殺技は右向きなら ↓↘→＋J、左向きなら ↓↙←＋J。Esc で一時停止、F1 で判定箱。

## 採用ルール

必殺技の攻撃ボタンは J（弱）のみ。方向コマンドを入力しても K は強、L は足払いの入力として扱う（足払いは ↓ が必要）。J＋K の同時押しは、方向コマンドの有無によらず、地上で動けるときは投げを優先する。

成立した投げ入力も通常攻撃と同じ `BufferTicks` の間保持し、ヒットストップ中は残りを減らさない。行動可能になった Tick に消費し、別の攻撃入力・期限切れ・入力の消去で解除する。両者が 2 本以上で同点なら延長し、延長で本数差が付けば多い側の勝ち。最大ラウンドでも同点なら引き分け。

1 Tick = 1/60 秒。座標は 1 px = 256 の整数。ヒットが成立した Tick の次から、硬直差は「相手が動けるまでの Tick − 自分が動けるまでの Tick」。表のヒット時・ガード時はこの差で、足払いのヒット時はダウンと起き上がりを硬直に含める。

1 Tick の順は、入力、ヒットストップ、両者の状態、押し合い、投げ、攻撃、KO。ヒットストップ中は状態と位置と飛び道具を止め、入力の履歴と先行入力だけ積む。攻撃は攻撃箱と喰らい箱、投げは投げ箱と被投げ箱だけで判定する。同じ発動は 1 人に 1 ヒット。立ちガードは上段と中段、しゃがみガードは上段と下段。必殺のガードは削りで、体力 1 からは KO しない。同じ Tick の投げは両方外れ。2 本先取。時間切れは体力の割合、同じなら引き分け（両者に 1 本）。同時に 2 本なら延長し、最大ラウンドで引き分けの試合にする。

## 設計上の選択

Core は技表を読む状態機械で、技ごとのコードを持たない。App が画面と CPU の操縦役、Unity が描画と入力。物理エンジンは使わない。

## テスト

`dev test 039` で Core と App を検証する。Unity 上は `dev test 039 -Unity` と `dev test 039 -Unity -Mode PlayMode`。

反応 8 Tick の CPU に対して、反応 16 Tick で同じ判断を 6 Tick 保持する操縦役は 20 戦中 8 勝。入力なしの側は 2 本先取で負ける。

## 試遊で見てほしい点

コマンドの猶予（方向 12 Tick、ボタン 12 Tick）、先行入力（10 Tick）、ヒットストップの長さ、ガードの分かりやすさ、投げの間合い、CPU の強さ、音量。値は `EmberSettings` に出してある。
