# 039 振り返り

2026-11-26、レビュー対応後の動作承認を受領。

- **学び**　発生・持続・硬直と各 Tick の判定箱を技表に置き、ログで継続時間と硬直差を測ると、README のフレーム表とルールの実装を照合できる。攻撃箱・喰らい箱と投げ箱・被投げ箱を分けることで、投げの対象条件を打撃から独立して検証できた。
- **想定との差**　方向履歴だけで必殺を判定して強・足払いでも発動し、空中の被弾硬直から Idle へ戻して落下を止めていた。入力保持状態のハッシュ漏れ、体力減少に依存したガード音、1P だけの攻撃音もレビューで修正。試遊ではキャラ選択の分かりやすさ、コマンド表、攻撃演出、ダウン画像の表示サイズを調整した。
- **次回**　複合コマンドは方向・ボタン・同時押しの優先順位まで仕様とテストをそろえ、硬直明けは地上と空中を分けて検証する。押下エッジを決める保持状態もハッシュに含め、効果音は出来事の累計から取り出して描画間の Tick を取りこぼさない。

PR レビューでは、同時に 2 本を超えた後の延長決着、投げの先行入力、押し合いで到達できない CPU の投げ条件を修正した。勝利のしきい値と同点判定を分け、複合入力も成立後は通常攻撃と同じ残り Tick で保持する。CPU の判断条件は実際に押し合いを進めた配置で発動と命中まで確かめる。
