# 005. Asteroids — ORBIT BREAKER

仕様書：[plan/games/005-asteroids.md](../../plan/games/005-asteroids.md)

船を回転・加速させ、慣性で滑りながら小惑星を撃つ。上下左右がつながる空間で大→中→小と分裂する小惑星を全破壊し、3Waveクリアを目指す。原作完全互換ではなく、速度・角速度とトーラス空間の扱いを学ぶルールを採用する。

## 環境・起動

- Unity 6000.6.9f1、Universal 2D、C# 9.0。
- Windows / StandaloneWindows64、Input System。
- シーン：`Assets/Scenes/Asteroids.unity`。

```text
dev gui 005
dev build 005
dev run 005
dev capture 005
```

## 操作

| 操作 | キー・ボタン |
|---|---|
| 回転 | ←→ / A・D。同時押しは角速度0 |
| 推進 | ↑ / W。離しても直進速度を維持 |
| 射撃 | Space長押し |
| 開始・再戦 | Enter / START / PLAY AGAIN |
| 停止・再開 | P / Esc / RESUME |
| タイトルへ戻る | 停止・結果画面のTITLE |

フォーカス喪失で停止し、復帰後は手動で再開する。停止・画面遷移では保留要求・操作・端数時間を捨てる。押し続けている回転・推進・射撃キーは、一度すべて離してから受け付ける。

## 採用ルール

| 項目 | 内容 |
|---|---|
| 勝敗 | 大惑星3→4→5個の3Wave。全破壊で勝利、残機0で敗北 |
| 移動 | 加速度8、最高速度8、回転速度240度/秒。回転入力を離すと角速度0。直進速度の減衰はない |
| 空間 | 幅32×高さ18。船・惑星・弾が上下左右をラップ。速度・角速度は変化しない |
| 射撃 | 船首から発射。速度は船の速度＋前方18、寿命1.2秒、0.2秒間隔、同時8発。満杯中の要求は予約しない |
| 惑星 | 半径は大1.2・中0.65・小0.35。初速1.2〜2.0、独立した角速度で自転 |
| 分裂 | 大→中2個、中→小2個、小→消滅。接触位置・親の速度を引き継ぎ、乱数で選ぶ方向に±0.8を加える。子は次Tickから移動・衝突に参加 |
| 接触 | 船→惑星、弾→惑星のみ円判定。惑星同士・弾同士・自弾と船は通過。船の接触では惑星を壊さない |
| 残機・復帰 | 残機3。1Tickの多重接触でも減算は1回。接触時に全弾を消し、船を中央へ速度0で戻す。1秒間全体を止め、復帰後2秒無敵 |
| Wave移行 | 全弾を消し、船を中央へ速度0で戻す。1秒後に次Waveを生成し2秒無敵。得点・残機を引き継ぐ |
| 初期配置 | 楕円上の8候補から重複なしで選ぶ。船からのトーラス距離は6以上。無制限の再抽選はしない |
| 得点 | 大20・中50・小100点。大1個の分裂木で520点、既定3Waveで6,240点。追加残機なし |
| 再戦 | 全状態を初期化し、新しい試合シードで開始 |

設定は [AsteroidsSettings.asset](Assets/Game/Unity/AsteroidsSettings.asset)。速度・サイズ・弾数・待機・無敵・Wave構成・残機・音量を調整できる。音量既定値は0.15、波形振幅は0.05。有限値と範囲を検証する。

## 設計

| 層 | 主な型・責務 |
|---|---|
| Core | `AsteroidsConfig`、`AsteroidsState`、`PlayerCommand`、`Point`、`Torus`。状態・移動・射撃・分裂・衝突・残機・得点・Wave |
| App | `AsteroidsFlow`。画面遷移・入力・フォーカス・実時間→60Hz固定Tick。`Autopilot`を撮影とテストで共有 |
| Unity | `AsteroidsGame`、`AsteroidsSettings`、`AsteroidsCaptureScenario`。入力・輪郭線描画・HUD・音・証跡 |

- Core・AppはUnity非依存。Unity物理に委譲する処理はない。回転・加速・速度制限をTick開始に反映し、そのTick内では直線移動する。
- 衝突は正規化前の相対移動と3×3の周期コピーに対する掃引円判定。端や角の通過、途中ですれ違う移動、高速弾も扱う。
- 接触は時刻順。同時刻は弾→船、同種は発生元ID→対象ID順。破壊済み対象・消費済み弾を無視する。船の接触より前の命中は有効で、それより後の弾は全弾消去で無効。同時刻に撃破した惑星は船へ接触しない。
- 残機0を勝利より優先して判定する。Wave移行と復帰が重なる場合、待機時間は長い方を使う。
- 1試合＝1シード。生成と分裂のxorshift状態を分離し、撃ち方で次Waveの初期乱数が変化しないようにする。自動操縦は試合シード・Tickから求める独立したxorshiftで推進をばらつかせる。
- 再現性は同じ実行環境内で保証する。Monoと.NET間の浮動小数点完全一致・同一勝利Tickは要求しない。
- 1フレーム最大5Tick。超過整数Tickを捨て、端数を維持する。時間は補償加算した同一Tick換算値の整数部から数える。秒設定の切り上げは整数境界のfloat表現だけを整数扱いにする。
- 現在Tickを描き、補間しない。端に重なる物体は周期コピーも描く。16:9基準、16:10〜21:9で全領域を収める。PanelRendererの読み込み直後にもHUDを描く。
- 描画物と作業配列を再利用する。生成Texture2D・Sprite・AudioClipはシーン破棄時に破棄する。`AudioPolicy`でバッチ実行・撮影を消音する。
- シーンの正は `AsteroidsSceneBuilder`。再生成：`unity run games/005-asteroids -- -executeMethod Game.Unity.Editor.AsteroidsSceneBuilder.Build`。

### 上限の根拠

最大5Wave、大惑星8個/Wave、同時16弾。大・中・小の容量重みを4・2・1とすると、分裂では合計が増えず、小の消滅で減る。惑星数は最大8×4＝32個で足りる。最大得点は5×8×520＝20,800点。

惑星の最大速度は初速6＋分裂2回×3＝12。船16、弾120＋船16＝136。最大相対変位は(136＋12)/60、接触半径を加えても最短周期18未満なので、3×3コピーで全接触を網羅できる。
