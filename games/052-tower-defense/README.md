# 052 峡谷の関門

4種類の塔で固定経路を守り、第10Waveを迎え撃つタワーディフェンス。

## 起動と操作

Unity 6000.6.9f1、2D URP、Windows x64。ルートから `dev build 052` と `dev run 052` を実行。マウスで建設枠と種類を選び、建設・強化・売却を行う。選んだ枠の円が射程を示す。円のうち盤面からはみ出した部分も画面内に描画する。「Wave開始」を押すまで敵は出現せず、進軍中も塔を編集できる。ウィンドウから離れると一時停止する。戻ったら中央に表示される「防衛を再開」を押す。

初期資金160、ライフ10。出口に到達した敵1体につきライフ1を失う。ライフ0で敗北し、第10Waveの敵を処理し切れば勝利。

| 塔 | 費用 | 射程（マス） | 間隔（Tick） | 威力 / 強化 | 効果 |
|---|---:|---:|---:|---:|---|
| 弓 | 45 | 2.5 | 15 | 5 / +3 | 単体 |
| 砲 | 80 | 2.3 | 36 | 10 / +5 | 主対象の0.8マス以内にも攻撃 |
| 氷 | 60 | 2.0 | 24 | 3 / +2 | 30 Tickの減速。速度を半分にし、再命中で期限を更新 |
| 魔導 | 90 | 2.1 | 24 | 12 / +6 | 重装の軽減を無視 |

Lv2は建設費の半額を切り上げ、Lv3は建設費と同額。売却では累計支出の70%を切り捨てて返す。次に攻撃できるTickは建設枠ごとに保持し、売却後に同じ枠へ建て直しても引き継ぐ。

通常兵・速兵・重装の順に、HPは18・12・32、速度は毎秒1.8・2.7・1.2マス、撃破報酬は8・9・14。重装は魔導以外のダメージを3軽減し、最低1を受ける。第nWaveの敵HPは基礎値に `2 × (n − 1)` 加算。Wave完了で資金25を得る。

Waveごとの出現数（通常兵 / 速兵 / 重装）は `6/0/0、6/2/0、5/4/0、6/0/2、4/5/2、6/3/3、4/6/3、5/4/5、4/6/6、6/6/8`。この順で30 Tick間隔。調整値は `CanyonSettings.asset` に格納している。

## 設計

Coreは固定経路の進捗と座標、射程判定、Waveの出現予定と生存敵を管理する。30 Hzで出現・移動と到達・攻撃・決着の順に進める。出口到達は攻撃に先行する。塔は射程内で進捗が最大の敵を選び、同率では出現順を使う。経路と戦闘は整数で処理し、乱数は使用しない。

Appは入力順、固定Tick、画面遷移を管理する。建設・強化・売却には入力時点の選択を記録し、処理前に選択や対象の塔が変わった操作は取り消す。UnityはUI Toolkitで、塔の種類と選択枠の操作を別々の欄に表示する。峡谷、塔4種、敵3種、関門は画像生成素材を使用し、弓と砲は弧を描く飛翔物、氷は着弾の霜、魔導は光線で表示する。飛翔と着弾は描画演出で、ダメージはCoreの発射Tickで確定する。短時間の発射・命中履歴を使い、複数の飛翔や被弾表示を重ねて描画する。Wave間は攻撃演出を消す。操作欄には現在の威力・射程・攻撃間隔と次に出現する敵の内訳を表示する。敵の頭上には、そのWaveでの最大HPに対する残り体力を表示する。シーンを再生成するには `unity run games/052-tower-defense -- -executeMethod Game.Unity.Editor.CanyonSceneBuilder.Build` を実行する。
