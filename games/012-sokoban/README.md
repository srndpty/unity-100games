# 012. 倉庫番 — HARBOR SHIFT

仕様書：[plan/games/012-sokoban.md](../../plan/games/012-sokoban.md)

港の倉庫で荷箱を押し、すべて黄色い印の上へ運ぶ盤面パズル。参考作品からはメカニクスだけを採用し、名称、絵、全10問は独自に作っている。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード。HUD のボタンはマウスでも押せる。HUD は PanelRenderer / UI Toolkit。日本語は Windows の Yu Gothic で表示する

## 起動手順

```
dev gui 012      # エディタで開く
dev build 012    # Windows ビルド
dev run 012      # ビルドを起動
dev capture 012  # 証跡を evidence/ に撮る
```

シーンは `Assets/Scenes/HarborShift.unity`。

## 操作

| 入力 | 内容 |
|---|---|
| 矢印キー / WASD | 移動、面選択のカーソル。長押しでリピート |
| Z / Backspace / ボタン | 1手戻す（押下1回につき1手） |
| R / ボタン | やり直し。クリア後はもう一度遊ぶ |
| Enter / ボタン | 決定、次の面 |
| Esc / ボタン | 1つ前の画面へ戻る |

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 移動 | 上下左右に1マス。壁へは移動不可 |
| 押す | 箱の先が床（目標含む）で空いているときだけ1個押せる。引けない |
| 連続押し | 箱の先が箱または壁なら拒否。拒否された手は状態・手数・履歴を変えない |
| クリア | 全ての箱が目標上に載った瞬間。箱数と目標数は同数 |
| 敗北 | なし。詰みの自動判定はせず、取り消しかやり直しで復帰する。結果画面はクリア時のみ |
| 取り消し | 1手（移動のみ／押しあり）単位で無制限。手数・押した数も戻す。履歴が空なら拒否 |
| やり直し | 初期盤面へ戻し、手数・押した数・履歴を消す。やり直し自体は取り消せない |
| クリア後 | 移動と取り消しは拒否。次の面、もう一度、面選択のみ |
| 面選択 | 最初から全10問を選べる。クリア印と最少手数は起動中のみ保持し、ファイルへ保存しない |
| 乱数 | 使わない。同じ面と入力列なら必ず同じ結果になる |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core | `LevelMap`（壁・床・目標の不変レイヤー）、`BoardState`（人と箱の可変レイヤー）、`LevelParser`（面データの変換と検証）、`MoveRules`（移動判定の純粋関数）、`MoveRecord`（1手の差分）、`SokobanGame`（1面の進行）、`LevelCatalog`（全10問） |
| App | `HarborFlow`（画面遷移と操作の窓口）、`MoveRepeater`（長押しリピート）、`SessionRecords`（起動中の記録） |
| Unity | `HarborShiftGame`（入力・HUD・音）、`HarborShiftView`（描画と演出）、`HarborShiftSettings`（設定アセット）、シーンと素材の生成、撮影台本 |

- **変わらないものと変わるものを分ける。** 壁・床・目標は `LevelMap`、人と箱は `BoardState` に置く。箱が目標を離れても目標のレイヤーは変わらない。
- **取り消しは差分で持つ。** 1手で変わるのは人と箱1個だけなので、`MoveRecord` のスタックを逆にたどる。
- **遊べない面は読み込みで拒否する。** 外周の開き、箱と目標の数の不一致、到達できない箱や目標、開始時点でクリア済みの面などは例外にする。
- **全問がクリアできることは解答手順の再生で確かめる。** 解答はテスト側にだけ持ち、ゲーム本体に解答機能はない。
- **操作は押した順に処理する。** 移動・取り消し・やり直しを1本の列に入れ、同じフレームでも順序が入れ替わらないようにしている。
- **押しっぱなしを次の画面へ持ち越さない。** 画面が変わるかフォーカスを失うと長押しを解除し、キーを押し直すまで動かない。
- **状態は即時に確定し、演出は表示だけにする。** 演出中の入力も捨てずに処理する。
- **物理エンジンは使わない。** ターン制で、ルールは時間に依存しない。

設定アセットは `Assets/Game/Unity/HarborShiftSettings.asset`。移動演出の秒数、リピート開始までの秒数、リピート間隔、音量を調整できる。

シーンの再生成：

```
unity run games/012-sokoban -- -executeMethod Game.Unity.Editor.HarborShiftSceneBuilder.Build
```

素材は `HarborShiftArtGenerator` が図形から描き出した PNG。再生成は既存のファイル、そのインポート設定、Prefab を上書きしない。
