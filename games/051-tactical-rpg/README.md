# 051 霧の砦

8×8の戦場で地形を読み、4人の部隊で敵指揮官を撃破するタクティカルRPG。

## 起動と操作

Unity 6000.6.9f1 / 2D URP / Windows x64。リポジトリのルートで `dev build 051`、`dev run 051` を実行する。

マウスで味方、青枠の移動先、赤枠の攻撃対象を選ぶ。移動先にポインターを重ねると経路、敵に重ねると予測ダメージと命中率を表示する。盤面から離れるとプレビューを消す。「ターン終了」で敵の手番に移り、敵の移動・待機・攻撃結果を通知欄に表示する。

## 戦闘ルール

| 項目 | ルール |
|---|---|
| 移動 | 上下左右。平地1、林2。岩と生存ユニットのマスには進入できない |
| 行動 | 自陣営の手番に各ユニットが移動1回と、その後に攻撃1回。その場から直接攻撃すると行動終了 |
| 戦闘 | マンハッタン距離で近接射程1、弓射程2。地形越しも射程内なら攻撃可能。命中すれば固定ダメージ |
| 決着 | 敵指揮官を撃破すると勝利。味方全滅で敗北 |
| 再戦 | 初期配置とHPに戻り、起動時のシードから進めた次のシードを使う |

初期の能力値は `FortSettings.asset` で編集できる。ユニット順は前衛、盾兵、斥候、弓兵、指揮官、護衛、護衛、弓護衛、護衛。敵の操作間隔も同じアセットで調整する。

## 設計と検証

Coreはダイクストラ法で移動コストと経路を求める。敵AIは撃破確率、有効ダメージの期待値、攻撃後に残る射程内の脅威を順に評価する。攻撃できない場合は、攻撃可能な全マスから逆向きに探索した最短コストで接近先を選ぶ。同点はセル番号とユニットIDで解決する。撮影用の味方操縦では指揮官を撃破できる攻撃を最優先する。Appは画面・選択・手番と敵の行動間隔を管理する。UnityはUI Toolkitで盤面と操作をつなぐ。

シーンを再生成する場合は `unity run games/051-tactical-rpg -- -executeMethod Game.Unity.Editor.FortSceneBuilder.Build`。本編は1マップで、仕様の対象外は大規模ストーリー・クラスチェンジ・追加ステージ量産など。

検証結果は[動作証跡](evidence/README.md)を参照。
