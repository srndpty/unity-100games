# 011. 2048 — TWIN FORGE

仕様書：[plan/games/011-2048.md](../../plan/games/011-2048.md)

同じ数字の金属板をぶつけて鍛え、2048の板を完成させる盤面パズル。参考作品からはメカニクスだけを採用し、名称と見た目は独自に作っている。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード。HUD は PanelRenderer / UI Toolkit。日本語は Windows の Yu Gothic で表示する

## 起動手順

```
dev gui 011      # エディタで開く
dev build 011    # Windows ビルド
dev run 011      # ビルドを起動
dev capture 011  # 証跡を evidence/ に撮る
```

シーンは `Assets/Scenes/TwinForge.unity`。

## 操作

| 入力 | 内容 |
|---|---|
| 矢印キー / WASD | 板を動かす（押下1回につき1手。長押しのリピートなし） |
| Enter / ボタン | 開始・再戦 |
| Esc / ボタン | タイトルへ戻る |

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 盤面 | 4×4 固定 |
| 開始 | 空きマスに2枚出現した状態で始める |
| 移動 | 上下左右。全タイルが進行方向の端へ詰まる |
| 合体 | 同じ値の2枚が1枚になる。1枚は一手で1回だけ合体でき、できた板は同じ手で再合体しない |
| 合体の優先 | 進行方向の端に近い側から組む（`2,2,2,_` を左へ → `4,2,_,_`） |
| 得点 | 合体でできた板の値を加算（`2,2,2,2` → `4,4` は +8） |
| 無効手 | 盤面が変わらない手は拒否。出現・得点・手数・乱数すべて変化なし |
| 出現 | 有効手の後、空きマスから一様に1枚。2が90%、4が10% |
| 勝利 | 2048の板ができた時点で試合終了。その手では新タイルを出さない |
| 敗北 | 出現後に空きマスがなく、隣接する同値もない |
| 同時成立 | 勝利を優先（勝利時は出現しないので敗北判定に進まない） |
| 終了後 | 移動はすべて拒否 |
| 再現性 | 1試合1シード。乱数の消費順は「出現マス→値」で固定。再戦は新シード |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core | `BoardState`（不変の盤面）、`MoveRules`（移動の純粋関数）、`MoveOutcome`（移動の前後とタイルごとの動き）、`SpawnRules`（出現の抽選）、`ForgeRules`（設定）、`ForgeGame`（1試合の進行） |
| App | `ForgeFlow`（画面遷移と操作の窓口） |
| Unity | `TwinForgeGame`（入力・HUD・音）、`TwinForgeView`（描画と演出）、`TwinForgeSettings`（設定アセット）、シーンと素材の生成、撮影台本 |

- **移動は純粋関数にする。** `MoveRules.Slide` は入力の盤面を変更せず、移動後の盤面と各タイルの動きを `MoveOutcome` として返す。
- **4方向の処理を1つにまとめる。** 方向の違いは「進行方向の端から数えたマス番号」の対応だけに閉じ込め、詰めと合体の処理は1か所に置く。
- **合体は一手一回。** 直前に置いた板がまだ合体していないときだけ合体でき、合体後はその板を候補から外す。
- **状態は即時に確定し、演出は表示だけにする。** 演出中の入力も捨てず、次の手を処理して新しい移動の演出へ切り替える。
- **結果表示で盤面を隠さない。** 案内は盤面の右の固定パネルに置き、終局の盤面を見返せるようにしている。
- **物理エンジンは使わない。** ターン制で、ルールは時間に依存しない。

設定アセットは `Assets/Game/Unity/TwinForgeSettings.asset`。4が出る確率、演出の秒数、音量を調整できる。盤面の大きさと目標値は画面の配置に関わるので定数にしている。

シーンの再生成：

```
unity run games/011-2048 -- -executeMethod Game.Unity.Editor.TwinForgeSceneBuilder.Build
```

素材は `TwinForgeArtGenerator` が図形から描き出した PNG。再生成は既存のファイル、そのインポート設定、Prefab を上書きしない。
