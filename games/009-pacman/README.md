# 009. Pac-Man — NIBBLE MAZE

仕様書：[009-pacman.md](../../plan/games/009-pacman.md) ／ [実装計画](../../plan/games/009-pacman-implementation.md)

夜の食料庫でネズミを操り、4匹の猫をかわしながらパン屑を集める見下ろし2Dの迷路ゲーム。参考作品からはメカニクスだけを採用し、名称・キャラクター・迷路・見た目は独自に作っている。

## 環境と起動

Unity 6000.6.9f1、Universal 2D、C# 9.0、Windows / StandaloneWindows64。入力はInput Systemのキーボード、HUDはPanelRenderer / UI Toolkit。日本語はWindowsのYu Gothicで表示する。

```text
dev build 009
dev run 009
dev gui 009
```

シーンは `Assets/Scenes/Maze.unity`。

## 操作

| キー | 内容 |
|---|---|
| 方向キー / WASD | 移動方向の指定（次に曲がれる場所で曲がる） |
| Enter | 開始・再戦 |
| P / Esc | 停止・再開 |
| Tab | 猫が狙っているマスの表示切替 |

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 盤面 | 29×15マス、左右対称、行き止まりなし、左右をつなぐ通路1本、中央に猫の寝床と扉 |
| 自機の移動 | 希望方向を保持し、マス中心で曲がれるときに曲がる。逆走は即時。壁の前で停止。扉は通れない |
| 勝利 | パン屑とマタタビをすべて取ると即勝利。同じ瞬間の接触より優先 |
| 敗北 | 残機3。接触で1減り、配置だけ初期化（取った餌は残る）。0で終了 |
| 得点 | パン屑10、マタタビ50、猫200→400→800→1600 |
| 猫の分岐 | マス中心で、逆走を除く通行可能な方向から目標に最も近い方向を選ぶ（距離の2乗）。同点は上→左→下→右 |
| 巡回と追跡 | 巡回7秒→追跡20秒→巡回7秒→追跡20秒→巡回5秒→以後追跡。切替時に反転 |
| 逃走 | 7秒。開始時に反転し、分岐はシード付き乱数。巡回・追跡の時計は停止 |
| 逃走の対象外 | 寝床の中、退出中、帰還中の猫 |
| 逃走中の再取得 | 時間を7秒に戻し、得点倍率は200へ戻す |
| 捕まえた猫 | 高速で寝床へ帰り、到着後すぐ退出して通常に戻る |
| 寝床からの退出 | トラは最初から外、ミケ2秒、クロ5秒、シロ9秒（ラウンド開始から） |
| 進行 | 準備2秒→プレイ→ミス演出1.5秒→準備または結果 |
| 乱数 | 1試合1シード。再戦は新しいシード |

### 猫ごとの目標マス（追跡時）

| 猫 | 性格 | 目標 | 実装 |
|---|---|---|---|
| トラ | 直進 | 自機のマス | `DirectSelector` |
| ミケ | 先回り | 自機の4マス先 | `AmbushSelector` |
| クロ | 挟み撃ち | 自機の2マス先を中心に、トラの位置を点対称に移した点 | `PincerSelector` |
| シロ | 気まぐれ | 自機から8マス以上なら自機、近いと自分の隅 | `ShySelector` |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core | `MazeLayout`（迷路データ）、`MazeGraph`（グラフと距離場、不変条件の検証）、`MazeActor`（位置）、`ITargetSelector`（目標選択の差し替え）、`CatState`（猫の状態遷移）、`MazeGameState`（試合進行） |
| App | `MazeFlow`（画面遷移・保留入力・時間変換）、`Autopilot`（テストと撮影で共有する操縦役） |
| Unity | `MazeGame`（入力・HUD・音）、`MazeView`（描画）、`MazeSettings`（設定アセット）、シーンと素材の生成、撮影台本 |

- **整数のみで計算する。** 1マス=600単位、速度は0.1マス/秒単位、時間はTick（60Hz）。Monoと.NETで結果が一致する。
- **1Tickを4つの部分ステップに分ける。** 各ステップで自機移動→餌の取得→勝利判定→猫の移動→接触判定の順に処理し、すれ違いと接触の順序を正しく扱う。接触は部分ステップ内の軌跡どうしの最短距離で判定する（`MotionPath`）ので、斜めのかすり接触も見逃さない。同じ部分ステップで複数の猫に触れたら、危険な猫を優先してミスにする。
- **設定の検証で上限を保証する。** 速度は最大20マス/秒、判定半径は0.2〜0.75マス。壁越しの接触とすり抜けが起きない範囲に収めている。
- **物理エンジンは使わない。** 移動と接触はすべてCoreで計算する。
- **終了を1フレーム遅らせる。** Unity 6000.6.9f1でタイトルバーの✖を押すとUnity本体の終了処理でクラッシュするため、`WindowsQuitWorkaround` が終了要求を次のフレームへ送る。通常の終了処理はすべて動く。

設定アセットは `Assets/Game/Unity/MazeSettings.asset`。速度・時間・得点・残機・音量を調整できる。迷路とシーンの生成：

```text
unity run games/009-pacman -- -executeMethod Game.Unity.Editor.MazeSceneBuilder.Build
```

素材は `MazeArtGenerator` が図形から描き出したPNG。配置の正は `Art/MazeStage.prefab` で、再生成は既存のファイル、そのインポート設定、Prefabを上書きしない。

## 未実装範囲

仕様書のOut of scopeどおり、原作全迷路の再現、AIの学習機能、大量のアセット制作、追加ステージ、課金・実績・外部ランキング。加えて、果物、面の進行、速度上昇、残機の追加、保存は採用していない。

## 未解決事項

- 難易度・速度・音量は人間のプレイ確認で調整する。
- 通常設定で操縦役が全面クリアすることは保証していない。自動テストで確かめているのは、通常設定で必ず決着することと、猫を止めた設定でクリアできること。
