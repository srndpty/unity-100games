# 033 振り返り

- **学び**　ロープを Core の整数の Verlet と距離拘束で解くと、切った後の露玉を自由落下の参照と毎 Tick 照合でき、10 問の解答の手順を dotnet で再生して「解ける」を保証できる。最終ハッシュも .NET と Mono で一致した。
- **想定との差**　1 マス = 4096 単位では、重い露玉への補正が丸めで 0 になる不感帯で振り子が傾いたまま止まり、65536 単位に上げた。そのため掃引の上限を超え、目標とトゲの先後を比べずに「同じ Tick なら失敗」にした。問の配置は総当たりで確かめるまで解けないものがあった。
- **次回**　UI の札のクリックは、押下の時点の画面を覚えて「その画面で押したクリック」にだけ効かせる。なぞりの判定は移動だけでなく解放の位置までの線分も含める。
- **不具合**　タイトルのクリックを離したときに、移った先の問題選択の札の clicked が届いて問が始まった。押して離すまでに移動が届かないと、離した位置までの線分で切れなかった。
