# 043. 伝統的ローグライク — MIRE LANTERN（仮）

仕様書：[plan/games/043-traditional-roguelike.md](../../plan/games/043-traditional-roguelike.md)　実装計画：[plan/games/043-traditional-roguelike-implementation.md](../../plan/games/043-traditional-roguelike-implementation.md)

自動生成の 5 階をターン制で降りる、オリジナルのローグライク。参考作品の名称・敵・アイテム名・演出は使っていない。

## 環境

- Unity：6000.6.9f1
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：キーボードのみ（テンキー 8 方向、矢印/WASD と Shift で斜め）。マウスは使わない

## 起動手順

```
dev gui 043      # エディタで開く
dev build 043    # Windows ビルド
dev run 043      # ビルドを起動
dev capture 043  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 盤 | 1 階 = 48×27 マスの格子。壁・部屋の床・通路・階段。座標・HP・時刻は全て整数で、浮動小数点を使わない |
| 地形生成 | 盤を 3×3 の区画に分け、6〜9 区画に部屋（幅 4 以上・高さ 3 以上）、残りは通路の交点（1 マス）。区画の全域木（無作為な Prim 法）に余分な辺を 1〜2 本足して通路を掘る。通路は部屋の壁の 1 マスを出入口にし、2 つの出入口の間の余白で 1 回折れる（部屋を横切らない）。開始位置と階段は別の部屋。生成後に「全ての床が開始位置から歩いて行ける」「階段は開始と別の部屋」を検証し、外れたら同じ系列で引き直す（上限 20 回、超えたら例外。作り方でつながるので 2,000 階を生成して引き直しは 0 回） |
| 乱数の系列 | 試合シードから (シード, 階, 場面) で派生する xorshift32。場面は **地形**・**配置**（階に入ったときの敵と品）・**行動**（命中・ダメージ・敵の巡回先・瞬間移動の行き先）。地形と配置は自機の行動に依らず、同じシードなら同じ階は同じになる |
| 統一ターンスケジューラ | 自機も敵も「次に動ける時刻」（long）を持つ。最も早い者が 1 行動し、行動の重さを足す。自機は 100、速い小獣 50、岩人形 200、他は 100。同じ時刻なら番号の小さい方が先（自機は 0、敵は出現の順に 1 から）。Core は自機の番で止まって操作を待つ |
| 無効操作 | 壁・角抜け（斜めの両脇のどちらかが壁）への移動、足元に品がないのに拾う、持ち物が満杯で拾う、空の枠を使う・投げる・置く、石を使う、足元に品があるのに置く、階段でないのに降りる、範囲外の方向・枠、試合の終了後の全ての操作は **受け付けず（`Rejected`）、時刻・乱数・満腹度・敵・状態ハッシュを何も変えない** |
| 向きを変える | Ctrl＋方向。受け付けるが時間を使わない（敵は動かない） |
| 移動 | 8 方向に 1 マス。斜めは両脇がどちらも床のときだけ。敵のいるマスへの移動は攻撃。品の上に乗ると自動で拾う（満杯なら拾わずに知らせる。移動は受け付ける）。足踏みは 1 行動 |
| 視界 | 対称シャドウキャスティング（傾きを整数の分数で計算）、半径 8（dx² + dy² ≤ 8² + 8）。床どうしは「A から B が見える ⇔ B から A が見える」。壁は見えるが先を遮る。自機が動いたら計算し直す |
| 既知マップ | 視界とは別の構造。一度見たマスの地形と、**最後に見たときの品**を覚える（見えない所で品が動いても記憶は古いまま）。敵は覚えない。地図の巻物は床と床に接する壁を既知にするが、品と敵は明かさない |
| 画面に出す情報 | Unity と操縦役は `PlayerView` だけを読む。地形は既知のマスだけ、品は視界の中なら今の品・外なら記憶、敵は視界の中だけ、出来事は起きた場所が視界の中のものだけ |
| 自機 | HP 24・攻撃 5・防御 1 から。経験値でレベル（最高 10）。1 レベルごとに最大 HP +5（HP も +5）・攻撃 +1、偶数レベルで防御 +1。6 行動ごとに HP 1 回復（満腹度 0 の間は回復しない） |
| 満腹度 | 最大 100。10 行動ごとに 1 減る。20 になったら「おなかが減ってきた」、0 になったら「空腹で倒れそう」と知らせる。0 の間は 1 行動ごとに HP が 1 減り、0 で餓死。パン +50、大きなパン +100（上限 100）。眠っている間の自動の足踏みも行動に数える。階段を降りるのは行動に数えない |
| 戦闘 | 命中 90%（自機も敵も）。ダメージ = 攻撃 × (87〜112)% − 防御、最低 1（整数、切り捨て）。敵の HP が 0 で倒れ、経験値を得る |
| 敵 5 種 | **すばしこい小獣**（HP 7・攻 3・重さ 50）、**重い岩人形**（HP 30・攻 9・防 3・重さ 200）、**射手**（HP 12・攻 3、同じ直線 8 方向・距離 2〜6・間の地形と敵が遮らなければ矢 4）、**盗っ人**（HP 14・攻 2、隣で持ち物を 1 つ盗んで自機から見えないマスへ跳び、以後は追わない。倒すと盗んだ品を落とす。持ち物が空なら殴る）、**眠りの大蛇**（HP 40・攻 11・防 3、眠って出る。自機が隣に来たときの自分の番か攻撃されると起きる）。階ごとの出現の重みは設定の表（深いほど岩人形と大蛇が増える）。1 階の敵の数 = 4 + 階（開始の部屋には置かない） |
| 敵の考え | 視界は対称なので「自機から見えるマスにいる敵は自機を見ている」。見えていれば最後に見た位置を覚えて追う（隣なら攻撃、射手は射てれば射つ）。見失ったら最後に見た位置へ、着いたら巡回（無作為な部屋のマスへ）。1 歩は地形の距離（8 方向・角抜けなし）が最も縮む空きマス、同じなら方向の順（北から時計回り） |
| 品 8 種 | 回復薬（HP +30）、毒薬（飲むと HP −6、ただし 1 は残る／投げると 15 ダメージ）、眠り薬（飲むと 6 行動眠る／投げると敵が 6 行動眠る）、パン、大きなパン、石（使えない／投げると 7 ダメージ）、地図の巻物、瞬間移動の巻物（同じ階の無作為な空きマスへ）。1 階の品の数 = 5 + 階。持ち物は 16 個まで |
| 投げる | 向いている方向へ最大 10 マス。角抜けと壁で止まる。最初の敵に当たれば効果（石・毒薬はダメージ、眠り薬は眠らせる、回復薬は敵を回復、他は 1 ダメージ）を与えて消える。外れたら止まったマスの近く（8 方向の幅優先、方向の順）の品のない床に落ちる。階の品が 48 個なら消える |
| 階段・勝敗 | 階段の上で降りると次の階（地形は (シード, 階) から）。**5 階の階段を降りたら勝利**。HP 0 で死亡（敵・餓死）。結果画面（勝敗・到達階・レベル・行動数・倒した数・死因）→ タイトル → 新しいシードで再挑戦 |
| 状態ハッシュ | 設定の指紋・シード・階・自機の全ての値と持ち物・敵の全ての値・床の品・地形・既知マップ・スケジューラの時刻・行動の乱数の状態を FNV-1a で混ぜる |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core（`Game.Core`） | 地形の生成（`FloorGenerator`）、視界（`Fov`）、既知マップ（`KnownMap`）、統一ターンスケジューラ（`TurnScheduler`）、試合（`CrawlRun`：操作の検証と実行・敵の考え・品・満腹度・勝敗・状態ハッシュ）、画面に出す窓口（`PlayerView`） |
| App（`Game.App`） | 画面遷移（`CrawlFlow`）、物理キーごとの保持と方向（`HeldKeys`）、押したままの連続移動と停止、持ち物の画面の選択、メッセージ（`MessageLog`）、操縦役（`Autopilot`） |
| Unity（`Game.Unity`） | 描画・HUD・音・入力の変換・撮影（セッション3） |

- **視界と既知マップを分ける。** `Fov` は毎回の位置から「今見えるマス」を作るだけで、記憶は `KnownMap` が持つ。`PlayerView` はこの 2 つを合わせて「既知の地形・視界の中なら今の品／外なら記憶・視界の中の敵」を出す。試合の中身（`CrawlRun` の敵の一覧・床の品・地形）は `internal` で、Unity 層と操縦役は `PlayerView` しか読めない。
- **出来事に「見えたか」を付ける。** `CrawlRun` は全ての出来事を記録し、起きた場所が自機の位置か視界の中なら `Seen`。`PlayerView.Events` は見えた出来事だけを出し、メッセージと音はそこからだけ作る（視界の外で敵が目を覚ましても文も音も出ない）。
- **無効操作は検証と実行を分ける。** `Submit` はまず状態を変えない `Validate` で判定し、受け付けたときだけ `Perform` する。乱数も検証の後でしか引かない。
- **敵の経路は地形だけの距離の地図。** 地形は階の中で変わらないので、目的地ごとの距離の地図を階の間だけ覚える（結果は変わらず、速さだけのため）。
- **操縦役は画面の情報だけで遊ぶ。** `Autopilot.Decide(PlayerView)` は既知マップの幅優先探索で、起きた敵 → 品 → 未知の境界 → 階段の順に向かう。見た眠っている敵の位置は覚えて避ける（見える・見えないで行き先が往復しないように）。行き先が全て眠った敵の向こうなら起こして倒す。
- 操縦役の成績（既定の設定）：40 シード中 38 勝（2 敗は 2 階の岩人形・5 階の大蛇との戦闘）、20 シードの決着はいずれも 2,000 行動以内。シード 1 の最終ハッシュ 0x48E3B9C7 は .NET と Mono で一致
