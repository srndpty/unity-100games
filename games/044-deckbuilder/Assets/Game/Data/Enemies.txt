# CINDER LEDGER の敵（5 種＋ボス）。
# enemy <id> <名前> の後に hp・order（cycle＝書いた順に繰り返す／random＝重みで抽選、直前と同じ行動は選ばない）・move <id> <名前> [重み]・do（効果）。
# 敵の do の対象は player（プレイヤー）・self（自分）。summon <敵 id> は敵を呼ぶ。
# onhalf <行動 id> は HP が半分以下になって最初に選ぶ行動（一度だけ、普段の順番には入らない）。
