# CINDER LEDGER のカード（20 種）。
# card <id> <名前> の後に type（attack/skill/power）・rarity（starter/common/uncommon/rare）・cost・exhaust（任意）・do（効果、書いた順に解決）。
# do の書式：
#   damage <量> <対象>        対象は chosen（選んだ敵）・all（全ての敵）・random（無作為の敵）
#   damage_block <対象>        今のブロックを量にした攻撃
#   block <量> self / double_block self
#   draw <枚数> / energy <量> / exhaust_random <枚数>（手札から無作為に廃棄）
#   status <種類> <量> <対象>  種類は strength・weak・vulnerable・poison・bulwark・miasma、対象は chosen・all・random・self
# 持続（power）は使うと廃棄の山へ移り、効果は状態として残る。
