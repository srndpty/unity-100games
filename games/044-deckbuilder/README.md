## 採用ルール

ルールの正はこの表。数値は全て整数で、倍率は百分率で 0 方向へ切り捨てる。

| 項目 | 採用ルール |
|---|---|
| 自機 | 最大 HP 70（戦闘をまたいで持ち越し）、毎ターン エネルギー 3（持ち越さない）・5 枚引く、手札上限 10（満杯のときは引かずに山札に残す） |
| 初期デッキ | 10 枚：打ち込み ×5・構え ×4・砕き ×1 |
| 領域 | 山札・手札・**解決中**・捨て札・**廃棄**。カードは実体 ID で持ち、どの時点でもちょうど 1 つの領域にある。山札が空で引くときは捨て札を混ぜて山札にする（解決中・廃棄のカードは混ぜない） |
| カードを使う | 自分の番・手札にある・エネルギーが足りる・対象が合う（対象を選ぶカードは生きている敵 1 体、選ばないカードは対象なし）を全て満たすときだけ受け付ける。満たさなければ理由を返し、状態・乱数を何も変えない |
| 解決 | エネルギーを払ってカードを解決中へ移し、効果を**書いた順に**コマンドとして解決キューへ積み、FIFO で最後まで解決する。各コマンドは出来事を記録する。終わったらカードを捨て札へ（廃棄・持続のカードは廃棄の山へ） |
| 対象 | 選ぶ（chosen）は確定した 1 体。全体（all）・無作為（random）は**解決の時点で**生きている敵から決める（全体は番号順）。選んだ敵が途中で倒れたら、その敵への残りの効果は不発で、他の効果は続ける |
| 攻撃の量 | 基礎 ＋ 筋力 → 脱力なら ×75% → 弱体なら ×150% → 0 未満は 0。ブロックが先に受け、残りが HP を減らす |
| 状態異常 | 筋力（戦闘の間ずっと）、脱力・弱体（持ち主のターンの終わりに 1 減る）、毒（持ち主のターンの初めに量だけ HP を失い、ブロックを無視、1 減る）、守りの火・煤煙（持続カードの効果。自分の番の初めにブロック・全ての敵へ毒） |
| ターン | 自分の番：ブロック 0 → 毒 → 持続の効果 → エネルギー → 5 枚引く → 敵が次の行動（意図）を決めて公開 → 操作。ターン終了：手札を全て捨て札へ（廃棄のカードも使っていなければ捨て札）→ 自分の脱力・弱体が 1 減る → 敵が番号順に：ブロック 0 → 毒 → 公開していた行動 → 脱力・弱体が 1 減る |
| 敵の意図 | 巡回（書いた順に繰り返す）か重みの抽選（直前と同じ行動は選ばない）。ボスは HP が半分以下になって最初の意図で一度だけ仲間を呼ぶ（同時に戦う敵は 3 体まで、満杯なら不発） |
| 勝敗 | 敵が全滅したら勝利（残りのキューは捨てる）。自機の HP が 0 になったら即敗北。終わった後の操作は全て拒否する |
| 乱数 | 試合のシードから節・用途ごとに系列を分ける：ルート・報酬・山札の混ぜ直し・敵の抽選・効果の乱択。再戦は新しいシード |
| データ | `Assets/Game/Data/` の Cards.txt・Enemies.txt・Encounters.txt。読み込み時に書式と参照を、検証で規則（対象の種類と効果の組合せ・コスト 0〜エネルギー・効果の数と量・遭遇の数など）を理由付きで確かめる |

## 設計上の選択

- **カード効果はコマンド列で実行する。** カードと敵の行動は同じ `EffectDef` の列で書き、`Battle` が `Command`（効果・出した者・選んだ対象）に展開して FIFO の解決キューで処理する。各コマンドは状態を変えて `BattleEvent` を記録し、演出（Unity）はこの列を後から再生する（Core は状態を先に最後まで変える）。
- **対象選択と解決を分ける。** Core の入口は `Play(実体 ID, 対象 ID?)` だけで、選ぶ途中の状態（選んだカード・カーソル）は App が持つ。全体・無作為の対象は実行の時点で決めるので、途中で敵が倒れても同じ規則で決まる。
- **拒否は副作用なし。** `Play` は検証を全て済ませてから状態を変える。拒否の前後で状態ハッシュ（乱数の状態を含む）が同じことをテストする。
