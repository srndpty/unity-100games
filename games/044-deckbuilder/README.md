# 044. デッキ構築ローグライト — CINDER LEDGER（仮）

仕様書：[plan/games/044-deckbuilder.md](../../plan/games/044-deckbuilder.md)　実装計画：[plan/games/044-deckbuilder-implementation.md](../../plan/games/044-deckbuilder-implementation.md)

オリジナル作品。カードで戦う短い 3 戦のルート（分岐あり）を進み、勝つたびに報酬でデッキを改善してボスを倒す。参考作品の名称・カード名・敵・演出は使わない。

## 環境

- Unity：6000.6.9f1
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：マウス＋キーボード（どちらだけでも遊べる）

## 起動手順

```
dev gui 044      # エディタで開く
dev build 044    # Windows ビルド
dev run 044      # ビルドを起動
dev capture 044  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| 操作 | マウス | キー |
|---|---|---|
| カードを選ぶ | 手札のカードをクリック（もう一度で外す） | 1〜0（左から） |
| 対象を選んで使う | 敵をクリック | ←→ / Tab で敵を選び Enter |
| 対象のないカードを使う | クリック（その場で使う） | 1〜0 |
| ターン終了 | 「ターン終了」 | E |
| 取り消し／一時停止 | 右クリック（選択中は取り消し、それ以外は一時停止） | Esc |
| ルート・報酬・休憩の選択 | 選択肢をクリック | 1・2・3 |
| 報酬の除去 | デッキのカードを選んで「除去する」 | — |
| 先へ進む・決定 | ボタン | Enter |
| 遊び方／タイトルへ | ボタン | H（タイトル）／ T（一時停止・結果） |

演出の再生中（カードの解決・敵の番・ターンの始め）は操作を受け付けず、届いた操作は捨てて選択も消す。

## 採用ルール

ルールの正はこの表。数値は全て整数で、倍率は百分率で 0 方向へ切り捨てる。

| 項目 | 採用ルール |
|---|---|
| 自機 | 最大 HP 70（戦闘をまたいで持ち越し）、毎ターン エネルギー 3（持ち越さない）・5 枚引く、手札上限 10（満杯のときは引かずに山札に残す） |
| 初期デッキ | 10 枚：打ち込み ×5・構え ×4・砕き ×1 |
| 領域 | 山札・手札・**解決中**・捨て札・**廃棄**。カードは実体 ID で持ち、どの時点でもちょうど 1 つの領域にある。山札が空で引くときは捨て札を混ぜて山札にする（解決中・廃棄のカードは混ぜない） |
| カードを使う | 自分の番・手札にある・エネルギーが足りる・対象が合う（対象を選ぶカードは生きている敵 1 体、選ばないカードは対象なし）を全て満たすときだけ受け付ける。満たさなければ理由を返し、状態・乱数を何も変えない |
| 解決 | エネルギーを払ってカードを解決中へ移し、効果を**書いた順に**コマンドとして解決キューへ積み、FIFO で最後まで解決する。各コマンドは出来事を記録する。終わったらカードを捨て札へ（廃棄・持続のカードは廃棄の山へ） |
| 対象 | 選ぶ（chosen）は確定した 1 体。全体（all）・無作為（random）は**解決の時点で**生きている敵から決める（全体は番号順）。選んだ敵が途中で倒れたら、その敵への残りの効果は不発で、他の効果は続ける |
| 攻撃の量 | 基礎 ＋ 筋力 → 脱力なら ×75% → 弱体なら ×150% → 0 未満は 0。ブロックが先に受け、残りが HP を減らす |
| 状態異常 | 筋力（戦闘の間ずっと）、脱力・弱体（持ち主のターンの終わりに 1 減る）、毒（持ち主のターンの初めに量だけ HP を失い、ブロックを無視、1 減る）、守りの火・煤煙（持続カードの効果。自分の番の初めにブロック・全ての敵へ毒） |
| ターン | 自分の番：ブロック 0 → 毒 → 持続の効果 → エネルギー → 5 枚引く → 敵が次の行動（意図）を決めて公開 → 操作。ターン終了：手札を全て捨て札へ（廃棄のカードも使っていなければ捨て札）→ 自分の脱力・弱体が 1 減る → 敵が番号順に：ブロック 0 → 毒 → 公開していた行動 → 脱力・弱体が 1 減る |
| 敵の意図 | 巡回（書いた順に繰り返す）か重みの抽選（直前と同じ行動は選ばない）。ボスは HP が半分以下になって最初の意図で一度だけ仲間を呼ぶ（同時に戦う敵は 3 体まで、満杯なら不発） |
| 勝敗 | 敵が全滅したら勝利（残りのキューは捨てる）。自機の HP が 0 になったら即敗北。終わった後の操作は全て拒否する |
| 乱数 | 試合のシードから節・用途ごとに系列を分ける：ルート・報酬・山札の混ぜ直し・敵の抽選・効果の乱択。再戦は新しいシード |
| データ | `Assets/Game/Data/` の Cards.txt・Enemies.txt・Encounters.txt。読み込み時に書式と参照と初期デッキの枚数（`deck` 行は 1 枚以上、合計 40 枚以下。カードの列へ展開する前に確かめる）を、検証で規則（対象の種類と効果の組合せ・コスト 0〜エネルギー・効果の数と量・遭遇の数など）を理由付きで確かめる |

## 設計上の選択

- **カード効果はコマンド列で実行する。** カードと敵の行動は同じ `EffectDef` の列で書き、`Battle` が `Command`（効果・出した者・選んだ対象）に展開して FIFO の解決キューで処理する。各コマンドは状態を変えて `BattleEvent` を記録し、演出（Unity）はこの列を後から再生する（Core は状態を先に最後まで変える）。
- **対象選択と解決を分ける。** Core の入口は `Play(実体 ID, 対象 ID?)` だけで、選ぶ途中の状態（選んだカード・カーソル）は App が持つ。全体・無作為の対象は実行の時点で決めるので、途中で敵が倒れても同じ規則で決まる。
- **拒否は副作用なし。** `Play` は検証を全て済ませてから状態を変える。拒否の前後で状態ハッシュ（乱数の状態を含む）が同じことをテストする。

- **ルート（`Run`）。** 戦 1（Easy／Normal の 2 択）→ 報酬 → 休憩（最大 HP の 30% 回復か最大 HP +6）→ 戦 2（Normal／Hard の 2 択、戦 1 と別の Normal）→ 報酬 → ボス → 結果。報酬は希少度の重み（通常 70/25/5、手強い方 40/40/20）でカードを重複なく 3 枚引き、1 枚取る（取らずに進んでもよい）。除去は報酬ごとに 1 枚まで、デッキは 5 枚未満にしない。HP は戦闘をまたいで持ち越す。戦闘の結果（HP・記録・次の段階）は、`Battle` を直接操作した場合も `Run` を読んだ時点で一度だけ反映する。
- **出来事の記録は完全。** 状態の変化は全て出来事になる（ターンの終了・ターンの初めのブロックの消失・脱力と弱体の減少・エネルギーの補充・意図の公開を含む）。App の `TableModel` は戦闘の始めの状態に出来事を順に当てはめて卓を作り、全てを当てはめると Core の状態と一致する（30 シードの乱択対戦で毎手照合）。
- **演出は Tick で再生する。** `EventPlayback` が出来事ごとの長さ（`PlaybackTiming`、設定アセットで調整）だけ待ちながら卓に当てはめる。Unity はこの卓を描くので、Core が先に最後まで解決していても、当たる前に敵が倒れて見えることはない。再生中は戦闘の入力を受け付けず、届いた操作は捨てて選択も消す。Tick は 1 フレームで最大 8（`MaxTicksPerFrame`）だけ進め、それを超えた遅れは追いつかずに捨てる（処理落ちの後は演出の時間を飛ばす）。一時停止の間は Tick・通知の表示期限・演出の再生位置を止める。
- **対象選択は App の `Targeting`。** 対象を選ぶカードはクリック（または数字キー）で選び、敵のクリック（または ←→/Tab と Enter）で確定する。対象を選ばないカードは選んだ時点で使う。払えないカードは選べず案内を出す。
- **Unity は卓だけを描く。** `LedgerStage`（背景・自機・立ち位置 3 つ・対象の印）と `LedgerHud`（UI Toolkit：手札・エネルギー・山の枚数・敵の意図と HP・被弾の数字・対象の矢印・各画面のパネル）は、`EventPlayback` の卓と演出の再生位置（今の出来事と経過 Tick）から描き、Core の戦闘は読まない。敵の意図の数字は、行動の効果列を書いた順にたどり、卓の状態から Core と同じ式（`DamageCalc`）で見積もる（行動の前にブロックが 0 に戻る・同じ行動の防御や強化や弱体の付与が後の攻撃に効く・ブロックぶんの攻撃も攻撃として出す・プレイヤーの番の途中ならターン終了で減る弱体を差し引く）。量の違う攻撃は「3+8」のように書いた順に並べる。立ち位置は番号の位置で、倒れた敵の位置は呼ばれた敵だけが使う。
- **クリックは押下で意図にする。** UI の要素の PointerDown で意図を作り、キーの意図と 1 本の列にして届いた順に Flow へ渡す。押した時点の画面と一時停止を覚え、処理する時点で変わっていたら捨てる（画面を移るクリックの離しで次の画面を押さない）。フォーカスを取り戻した直後のクリックも捨てる。
- **演出の長さと音量は設定アセット（`LedgerSettings`）。** 規則（`DeckConfig`）・演出の長さ（`PlaybackTiming`）・音量・データの TextAsset を持つ。画面の配置は敵 3 体・手札 10 枚専用なので、設定の検証でそれ以外を拒否する。
- **操縦役（`Autopilot`）。** そのターンの手順を `Battle.Clone` で先読みして選ぶ（局面の上限 3,000、ハッシュで同じ局面をまとめる）。複製の乱数で無作為の効果まで見るので人より少し有利。20 シード全勝、シード 1 の最終ハッシュ 0x0C54A0A7 が .NET と Mono で一致。1 枚ずつ貪欲に選び 15% で無作為に使う人寄りの操縦役は 10 シード中 7 勝。

## 未実装範囲

- 仕様書の Out of scope：長大マップ、数百カード。
- カードの強化版、金貨・店、イベントのマス、レリックは作らない（報酬はカード 3 択と 1 枚の除去だけ）。
- セーブはない（1 回の挑戦は短いので、途中でやめたら最初から）。
- 山札・捨て札・廃棄の中身の一覧画面はない（枚数だけ出す。報酬の画面ではデッキの全カードを出す）。
