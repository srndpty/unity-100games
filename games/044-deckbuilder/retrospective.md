# 044 振り返り

2026-11-26、動作承認を受領。

- **学び**　カードの効果を書いた順に `Command` へ展開して FIFO で解決し、変化を全て出来事として記録すると、App が出来事だけから卓を作って Core と毎手照合でき、Core が先に解決し終えていても画面は当たった時点で HP を減らせた。対象の選択を App の `Targeting` に置き、Core は確定した `Play(カード, 対象)` だけを受けると、拒否が状態・乱数・ハッシュを変えないことを全ての理由で確かめられた。
- **想定との差**　ボスが強すぎ操縦役でも 20 戦 5 勝で、HP などを下げた。レビューで、敵の意図の見積もりが Core の解決と別の式になっていた（ブロックぶんの攻撃・量の違う攻撃・同じ行動や先に動く敵の弱体の付与・ターン終了で減る弱体）こと、初期デッキの枚数を展開後に検証していたこと、クリックの画面の照合が先の入力を当てはめる前だったことを直した。
- **次回**　画面の予告（意図・見積もり）は、出荷データの見積もりと実際の結果をプレイヤーの番の途中と行動の直前で照合するテストを最初から置く。データの数は展開・確保の前に上限を検証する。押した画面の照合は入力層ではなく、意図を当てはめる直前の Flow で行う。
