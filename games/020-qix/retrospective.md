# 020 振り返り

## 新たに学んだ点

占有マスクを 3 状態のセルで持ち、線を閉じたときだけ 4 連結の Flood Fill（明示的なスタック）で領域を分けると、「敵のいる側を残す」は「敵の円が重なるセルを含む領域を残す」と書けた。敵が 2 領域にまたがっても誤って消さない。

敵の位置・速度・半径を固定小数点の整数にし、1 Tick の移動を 1 単位ずつの歩みに分けると、触れた位置での停止と斜めのかすりの検出ができ、盤面ハッシュが Mono と .NET で一致した。

## 想定との差

ミスの後に入力を保持したままだと、同じ場所から同じ敵へ毎 Tick 踏み出し、数 Tick で残機をすべて失うことをレビューで指摘された。自動操縦はミスしないため、自分のテストでは通らない経路だった。描画キーを離すまで線を引けないことを Core で保証した。

敵の半径の検証は「盤に収まる」だけで、目標占有率と両立しない大きさ（勝てない試合）を通していた。敵の円が覆いうるセルを除いても目標に届く半径に制限した。

## 次回の改善点

ミス・被弾・復帰の後は「同じ入力を保持し続けたら何が起きるか」を最初からテストする。自動操縦は危険を避けるので、境界の状況は状態を直接作って確かめる。

設定の各値の範囲だけでなく、値の組み合わせで勝利・クリアに到達できるかを検証に含める。
