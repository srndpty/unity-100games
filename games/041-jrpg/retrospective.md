# 041 振り返り

2026-11-26、動作承認を受領。

- **学び**　定義を ScriptableObject のアセットに置き、Core の定義クラスへ写してから `GameDataValidator` で全体を検証すると、Inspector で壊した値も起動前に理由付きで止まった。戦闘は時間を持たない純粋な解決（`BattleResolver.ResolveTurn`）にし、返した出来事の列を前の状態へ順に当てた結果がターンの終わりの状態と一致することをテストにすると、演出と早送りが状態を変えないことを保証できた。セーブは全ての切り位置・1 文字の改変・データの指紋違いを拒否するテストで、部分データと版の違いの扱いを決められた。
- **想定との差**　ダメージ式の実装（7〜9/8 の倍率）が README の表（88〜112%）と食い違っていたのをレビューで直した。敵の報酬・抽選の重みの合計、回復の `Hp + 量` が int を超えて報酬なし・HP が負になる問題、セーブの読み書きそのものの失敗（権限・容量・ロック）が例外のまま落ちる問題、ボスの導入会話からタイトルへ戻ると新しい冒険にボス戦が持ち越される問題も直した。
- **次回**　ルール表の式はコードの定数と同じテストで照合し、文書と実装を別々に書かない。足し算・掛け算で決まる値は、個々の値の検証に加えて合計の上限まで検証で見る。保留中の画面遷移（会話の後の戦闘など）は、タイトルへ戻るときに消す状態の一覧に最初から入れる。
