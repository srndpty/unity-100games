## 採用ルール

| 項目 | 採用ルール |
| --- | --- |
| 時間・移動 | 60 Tick/秒。フィールドはタイル単位の 4 方向移動で 1 歩 = `StepTicks`（既定 8 Tick）。移動中の次の方向キーは 1 枠の先行入力に保持し、タイル到達時に壁でなければ滑らかに次の一歩へ繋ぐ |
| パーティ | 固定 3 人（戦士アレン・僧侶リナ・魔法使いセオ）。最大レベル 10。戦闘不能（HP 0）の仲間は戦闘終了時に経験値を得ない。複数レベル分の経験値を一度に得た場合は連続レベルアップし、習得呪文をすべて解放する |
| 地図構成 | 全 5 マップ：`town`（灯守りの町・安全地帯）、`dungeon_f1`〜`dungeon_f3`（焔鎖の坑道 B1F〜B3F）、`boss_room`（焔鎖の祭壇）。B2F の宝箱で『鉄格子の鍵』を入手すると B3F の鉄格子を開錠でき、祭壇の魔将ヴァルグへ到達できる |
| エンカウント | 安全地帯以外でタイル移動完了時に歩数を進め、マップ出入り・戦闘直後の猶予歩数 `GraceSteps`（既定 4 歩）を超えると `RatePercent × EncounterRateMultiplier`（上限 100%）で重み付き抽選する。乱数は探索系列 `GameRng.ForEncounter(matchSeed)` から引く |
| 行動順 | ターン開始時に全員のコマンドを確定し、`素早さ + rng[0..素早さ/4]` の降順で行動する（同値は味方優先・隊列順）。乱数は戦闘ごとの独立系列 `GameRng.ForBattle(matchSeed, battleNumber)` から引くため、メッセージ早送りで結果が変わらない |
| ダメージ式 | 物理：`max(1, max(0, ATK/2 - DEF/4) × [88..112]/100)`。攻撃呪文：`max(1, Power × [90..110]/100)`、弱点属性一致時は `× 3 / 2`。倍率は各整数を等確率で引く。防御選択中はそのターンの被ダメージを半減（最低 1）。途中は long で計算し、結果は int の上限で止める |
| ターゲット再割り当て | 指定した単体敵が行動前に倒れていた場合、同一種族サブグループ内の先頭生存個体へ自動で振り替える。同サブグループが全滅していた場合のみ「しかし効果がなかった！」となり、MP・道具を消費しない |
| 不正コマンド防止 | MP 不足の呪文・所持数を超える道具予約・生存者への蘇生・戦闘不能者への通常回復・ボス戦の逃走は UI でグレーアウトし、決定押下時も理由を表示してコマンド確定を拒否する |
| 全滅ペナルティ | 味方全員が HP 0 になると所持金を半減（端数切り捨て）し、全員 HP/MP 全回復の状態で灯守りの町の教会前へ復帰する。レベル・経験値・装備・所持品・開封済み宝箱・鍵フラグはすべて保持する |
| 戦闘報酬 | 勝利時の経験値・ゴールドは敵の報酬の合計（long で計算し int の上限で飽和）。経験値は最大レベルの必要経験値、ゴールドは `MaxGold` で止まる |
| 施設とセーブ | 宿屋は生存者のみ HP/MP 全回復（戦闘不能者は教会の蘇生が必要）。よろず屋は購入時の即時装備（旧装備は袋へ移動）と装備中武具の直接売却に対応。所持袋＋装備中の同一品合計は 99 個を上限とする。**セーブは町の教会の神父の前でのみ実行可能** |
| セーブ検証 | テキスト `key=value` 形式＋末尾チェックサム（`SaveCodec`）。1 文字改ざん・全位置の途中切断・データ指紋不一致・範囲外値をすべて拒否し、破損検知時はタイトルに警告を表示して「つづきから」を非表示にする。保存領域の読み書き自体の失敗（権限・容量・ロック）も例外にせず、タイトルの警告・教会のメッセージで理由を伝える |

## 設計上の選択

- **Core（`Assets/Game/Core`）**：Unity API 非依存（`noEngineReferences`）。`GameDataValidator` が起動時・ビルド時に全参照整合性（呪文・道具・装備・敵・出現表・店・双方向階段・宝箱・鍵扉・経験値単調増加）を検証し、不備があれば `GameDataException` で即座に止める。戦闘解決 `BattleResolver.ResolveTurn` は時間を持たない純粋関数で、返された `BattleEvent` 列を `BattleSnapshot` に順適用した最終状態が Core の戦闘状態と完全一致する。
- **App（`Assets/Game/App`）**：画面遷移（`QuestFlow`）、戦闘イベントの Tick 送り再生と早送り（`BattlePresenter`）、タイムスタンプ付きキー入力とフレーム単位の Tick 上限共有、全 20 シード完走を保証する決定論的自動操縦（`Autopilot`）を持つ。
- **Unity（`Assets/Game/Unity`）**：地形は `Tilemap`、宝箱・鉄格子・町人・魔将・主人公は `SpriteRenderer` を持つ各マップの Stage Prefab（`Stage_town` ほか全 5 枚＋`BattleStage`）として保存し、プレイ前から Scene ビューで確認できる。`EmberlockMapStage.Mismatch` が Prefab の全タイルと配置物の座標を Core の地図定義と照合する。UI は `PanelRenderer`（UI Toolkit）で構築し、カーソル列を固定幅 32 px に分離して選択移動でラベル位置が揺れないようにした。各定義データ（職業・呪文・道具・装備・敵・出現表・店・地図）は個別の `ScriptableObject` アセットとして `Assets/Game/Data/` に配置している。
- **シーン生成**：`unity run games/041-jrpg -- -executeMethod Game.Unity.Editor.EmberlockSceneBuilder.Build` でドット絵・定義アセット・Stage Prefab・シーンを一括生成・検証できる。

## 試遊で見てほしい点

`dev run 041` で遊ぶ。調整用の値は `Assets/Game/Unity/EmberlockSettings.asset` と `Assets/Game/Data/` 配下の各アセットにある。

- フィールドの歩行テンポ（`StepTicks = 8`）と階段・扉・会話の操作感
- 坑道 B1F〜B3F のエンカウント頻度（猶予 4 歩、基本率 16〜18% × `EncounterRateMultiplier = 1.0`）
- 戦闘メッセージの送り速度（`EventDurationTicks = 18`、Enter/Space/Z で早送り可）
- 買い物・育成から魔将ヴァルグ撃破までの難易度バランス（氷呪文『フロスト』『グレイシア』が弱点）
- 効果音の音量バランス（既定 `Volume = 0.05`）
