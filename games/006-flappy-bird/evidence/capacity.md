# 最大設定の容量・CPU計測

2026-11-16（日本時間）。Unity 6000.6.9f1、Windows 11、Intel Core i9-13900KF、NVIDIA GeForce RTX 4090。PlayModeバッチの解像度640×480でCPU更新を測る。画面構成の検証・証跡は横長を対象とする。

## 条件と成功基準

- 自機半径0.6、重力−30、上昇9、落下速度下限−16。障害物幅2、間隔5、速度5→7、隙間4.75→3.5、壁余白1.5、隣接高さ差2。
- 固定シード71で10,000Tick飛行し、100点以上・最大難易度・再配置の継続を確認する。
- 容量は `ceil((24 + 2) / 5) + 2 = 8` 組。各組4 SpriteRenderer、背景23、自機4の合計59個。開始時に最大描画数を確保し、再配置前後で個数が同じことを検証する。
- Core設定の幅・間隔1,271組を検証し、容量が8以下、配列の横方向の長さが表示範囲より大きいことを確かめる。1Tickの最大変位7/60は最小間隔5未満で、1Tickで再配置が複数周期をまたがない。
- 10,000Tick後に`Render()`を1,000回測定し、CPU描画更新のp95が16.67ms未満であることを成功基準とする。探索を行う自動操縦の時間は含めない。

## 結果

最終PlayMode実行の値を検証証跡READMEに記録する。計測対象はカメラ調整・障害物と自機のTransform更新・HUD文字列更新。GPU時間、レンダリング全体、フレーム全体の時間、他のPCでのFPSを保証するものではない。
