# 006. Flappy Bird — SKY HOPPER

仕様書：[plan/games/006-flappy-bird.md](../../plan/games/006-flappy-bird.md)

隙間を飛び続けるワンボタンのスコアアタック。原作の素材や名称を複製せず、シード付き生成と画面外オブジェクトの再利用を学ぶ。

## 環境・起動

- Unity 6000.6.9f1、Universal 2D、C# 9.0。
- Windows / StandaloneWindows64、Input System。
- シーン：`Assets/Scenes/Flappy.unity`。

```text
dev gui 006
dev build 006
dev run 006
dev capture 006
```

## 操作と採用ルール

| 項目 | 内容 |
|---|---|
| 上昇 | Space / 左クリックの押下で1回。長押しによる連続上昇なし |
| 開始・再戦 | Enter / START / PLAY AGAIN。中央の開始待ちになり、最初の上昇入力で飛行開始 |
| 停止・再開 | P / Esc / RESUME。フォーカス喪失で停止し、復帰後は手動再開 |
| タイトル・終了 | 停止・結果画面のTITLE。タイトルのQUIT / ウィンドウを閉じる |
| 飛行 | 横位置−6固定、開始高さ0、円の半径0.3。上昇速度6へ置換、重力−18、落下速度下限−10 |
| 領域 | 幅24×高さ14。上下壁・障害物への接触で即失敗。残機なし |
| 障害物 | 幅1.4、横間隔6。最初の中心横位置8。右から左へ移動 |
| 隙間 | 初期幅4.5、上下壁から0.8以上離す。隣接中心の高さ差は最大2。最初は高さ0を基準に抽選 |
| 得点 | 障害物の右端が自機の左端を通過したら1点。1組につき1回。同時刻の衝突は得点より優先 |
| 難易度 | 5点ごとに上昇、最大レベル5。速度4→5.5、隙間4.5→3.5 |
| 難易度変更 | 移動速度は次Tickから全組へ反映。隙間は再配置する組から反映し、既存の隙間は変えない |
| 再戦 | 新しい試合シードで全状態を初期化。結果から待機時間なしで再挑戦できる |
| 結果 | 衝突位置で停止して得点を表示。無限スコアアタックで勝利条件はない |

UIボタン上のクリックは上昇として扱わない。停止・画面遷移・フォーカス喪失では保留入力と端数時間を消す。押したままのSpace・左クリックは、両方を離すまで再受付しない。

設定は [FlappySettings.asset](Assets/Game/Unity/FlappySettings.asset)。物理、サイズ、障害物、難易度、音量を調整でき、有限値と範囲を検証する。音量既定値0.15、波形振幅0.05。

## 設計

| 層 | 型・責務 |
|---|---|
| Core | `FlappyConfig`、`FlappyState`、`FlappyCommand`、`PipeState`、`Sweep`。飛行・生成・得点・衝突・難易度 |
| App | `FlappyFlow`。タイトル→開始待ち→飛行→結果→再戦、停止・フォーカス・実時間の固定Tick変換。`Autopilot`は撮影とテストで共有 |
| Unity | `FlappyGame`、`FlappySettings`、`FlappyCaptureScenario`。入力・固定プールの描画・PanelRenderer HUD・音・証跡 |

- Core・AppはUnity非依存。Unity物理に委譲する処理はない。60Hzで上昇・重力・速度制限を反映し、Tick内は直線移動する。
- 円と矩形の相対軌跡を、辺の帯と四隅の円に分けて掃引する。角の外側を矩形で水増ししない。上下壁も接触時刻を求め、全障害物を含む最初の接触で止める。
- 得点時刻が最初の衝突より前なら加点し、同時または後なら加点しない。結果後は更新を無視する。得点はlong上限で飽和する。
- 1試合＝1シードのxorshift。生成以外で乱数を進めない。隙間中心は壁からの範囲と前の中心±高さ差の共通区間から直接抽選し、再抽選を繰り返さない。
- 障害物は固定配列。左端を完全に抜けた組を、最も右の組＋間隔へ再配置して得点済み状態を解除する。再配置時だけ隙間と中心を生成する。
- 必要容量は `ceil((24 + 障害物幅) / 間隔) + 2`。表示範囲内の組に両端の余裕を持たせ、初期列は横位置8から右へ並べる。既定7組、設定上限（幅2・間隔5）で8組。最大移動7/60は最小間隔5より小さく、1Tickで複数周期を抜けない。
- 描画は開始時に最大8組×4個を確保し、未使用分を無効化する。背景23個＋自機4個を含め、SpriteRendererは最大59個で増えない。動的Texture2D・Sprite・AudioClipは所有者が破棄する。
- 1フレーム最大5Tick。超過整数Tickを捨て、端数を維持する。時間は補償加算した同一Tick換算値から整数部を数える。
- 現在Tickを描画し、補間しない。障害物は横幅24のプレイ領域内だけ描き、カメラの余白に生成待ちの組を見せない。16:9基準、16:10〜21:9で全プレイ領域を収める。HUDは接続直後にも描く。
- `Autopilot`は90Tick先まで、3Tickごとの上昇／待機を幅24の探索で評価する撮影・検証専用の操縦役。通常プレイでは実行しない。無限生存は保証しない。
- 再現性は同じ実行環境内で保証する。Monoと.NETで長期軌道や得点Tickの完全一致は要求しない。難易度の設定境界はfloat表現同士で比較し、派生する速度と隙間をdouble計算後floatへ戻して上限・下限内に収める。
- シーンの正は `FlappySceneBuilder`。再生成：`unity run games/006-flappy-bird -- -executeMethod Game.Unity.Editor.FlappySceneBuilder.Build`。

## 検証

```text
dev lint
dev check
dev test
dev test 006 -Unity
dev test 006 -Unity -Mode PlayMode
dev build 006
dev capture 006
```

Coreは合法・不正入力、接触・得点の境界、シード、設定検証を確認する。Appは入力の消費・遷移・時間・フォーカス競合に加え、既定3シードと最大設定2シードで各10,000Tickの連続飛行を検証する。PlayModeは実シーンのキーボード・マウス・UIクリック・HUD・横長カメラ・資源解放・最大設定の再利用とCPU描画更新を確認する。

実測・検証結果・画像は [evidence/README.md](evidence/README.md) に記録する。
