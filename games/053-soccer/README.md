## 採用ルール

3 対 3（各チーム GK 1・フィールド 2）・小さなコート・5 分。画面は見下ろしの 2D で、球の高さは影で見せる。人間は青チームのフィールドの 1 人を操作し、GK は両チームとも自動。

### コートと試合

| 項目 | 採用ルール |
|---|---|
| 座標 | 1 m = 1000 単位、60 Tick/秒。中心が原点、x が縦（ゴールは x = ±16 m）、y が横（タッチラインは y = ±10 m）。青は +x のゴールへ攻める |
| ゴール | 幅 3 m（ポストの中心の間）・高さ 2 m・奥行き 1.2 m。ポストは半径 6 cm の柱 |
| GK の範囲 | 自陣のゴールの中心から半径 5 m の半円（コートの内側）。GK はこの外へ出ない |
| 時間 | 5 分（18,000 Tick）。前後半なし。得点・ライン外の間も時計は進む。時間切れで終わり、勝ち・負け・引き分け（延長・PK なし） |
| 反則 | なし（体は押し合いで重ならないだけ）。オフサイドなし |

### 球

| 項目 | 採用ルール |
|---|---|
| 状態 | 位置・高さ（球の下端）・速度（1 Tick あたり）。全て整数 |
| 転がる | 高さ 0 で縦の速さ 0 なら転がる。横の速さを毎 Tick 12 ‰ 減らす（0 に向けて切り捨て）。速さの成分の和が 4 以下で止まる |
| 空中 | 縦の速さから重力（3）を引く。地面に着いたら弾む（縦は 45 %、横は 85 % が残る）。弾みが 8 より小さければ転がりに変わる |
| ポスト | 動いた線分がクロスバーより下でポストに触れたら（掃引）、触れた位置で止めて法線について反射し、70 % の速さにする（その Tick の残りは捨てる） |
| 予測 | 球を複製して本番と同じ Step で進める（予測と本番は Tick 単位で一致） |

### 保持・キック・タックル

| 項目 | 採用ルール |
|---|---|
| 保持 | Tick の中の選手と球の軌跡どうし（掃引）が 0.45 m より近づき、球の下端が 0.45 m 以下、相対速度が 420 以下なら止める（GK は 0.7 m・2.2 m 以下・速さを問わない）。候補が複数なら終わりの位置で球に近い方、同じなら番号の小さい方 |
| ドリブル | 持っている選手の向きの 0.38 m 先に球を置いて運ぶ。最高速は 85 % |
| パス | 目標の点へ地を這う球。速さは「受け手の位置で 70 が残るいちばん遅い速さ」（本番と同じ減り方で作った表から）。目標の点は向きと直角に ± 0.25 m ぶれる |
| ループ | 縦の速さ 100 の浮き球。着地が目標になる横の速さ。間の選手の上を越える |
| シュート | 速さ 430・縦の速さ 30 の低い浮き球。目標の点は ± 0.5 m ぶれる |
| ぶれの乱数 | 試合のシード・蹴った回数・用途から派生した系列（int-geometry の `RandomSeries`） |
| 蹴った後 | 12 Tick は同じ選手が球を止めない |
| タックル | 相手の持つ球が 0.65 m 以内なら球を弾く（タックルした選手から球への向きに速さ 160）。奪われた選手は 30 Tick 動けない。タックルした選手は 18 Tick、空振りは 40 Tick 動けない。GK の持つ球・味方の球はタックルできない（空振り） |
| GK | 自動。シュートが自陣のゴールの口を越える予測なら、越える位置へ。球が範囲の中で転がっていれば球へ。それ以外はゴールと球を結ぶ線の上（ゴールから 1.2 m）。持ったら 75 Tick 後に近い味方へパス |

### 得点とライン外

| 項目 | 採用ルール |
|---|---|
| 得点 | 球の全体がゴールラインを越え（中心 − 半径 > 16 m）、ポストの間（|y| < 1.5 m）で、全体がクロスバーの下（下端 + 直径 ≤ 2 m）。**その Tick に 1 回だけ**記録し、得点の間（120 Tick）に入る。得点の間は判定しない（球はネットの中で止まる）。自陣のゴールに入っても相手の得点 |
| ライン外 | 球の全体がタッチラインを越えたら、最後に触れた側の相手のスローイン（越えた位置）。ゴールの口の外でゴールラインを越えたら、攻めた側が最後ならゴールキック（守る側の GK、ゴールから 2.5 m）、守った側が最後ならコーナー（攻める側） |
| 再開の流れ | 得点・ライン外の後は「止まった段」（60 Tick、得点は間の後）→「再開」：蹴る人（ゴールキックは GK、ほかは位置に近いフィールドの選手）を球の後ろに置いて球を持たせる。蹴る人は動けず、蹴るまで相手は球から 3 m 以内に入れない。スローインはシュートできない。300 Tick 蹴らなければ近い味方へ自動でパス |
| キックオフ | 試合の始めは青、得点の後は失点した側。全員を自陣の並び（GK はゴール前、フィールドは自陣の左右）に置く |

### 命令と終了

| 項目 | 採用ルール |
|---|---|
| 命令 | 選手ごとに移動の向き・行動（パス・ループ・シュート・タックル）・目標の点。GK の命令は無視する |
| 受け付けない行動 | 持っていない選手のキック、蹴った直後のキック、再開で蹴る人以外のキック、スローインのシュートは何もしない |
| 終了 | 時計が 5 分に達した Tick で終わる。その後の命令では何も変わらない（状態のハッシュも同じ） |

## 設計上の選択

| 層 | 内容 |
|---|---|
| Core | `Pitch`（寸法・ゴール・ポスト）、`SoccerConfig`（調整値と検証）、`Ball`（高さ付きの球）、`BallPredictor`（軌跡と到着時刻）、`PassTable`（パスの速さの表）、`Footballer`、`Match`（1 Tick の進行・保持・キック・タックル・GK・得点・ライン外・再開・時計・Clone・Hash） |

- 共通パッケージ：int-geometry（`Vec2i`・`IntMath`・`Sweep`・`RandomSeries`）、tile-motion（`StateHash`）。
- 到着時刻：選手が止まった状態からまっすぐ走った距離（毎 Tick 加速して最高速で頭打ち）の閉じた式で求め、試合の移動と Tick 単位で一致する。
- パスの速さは、閉じた式（等比級数）ではなく、本番と同じ整数の減り方で作った表から選ぶ（切り捨てで低速の減りが大きく、式では遠くのパスが届かなかった）。
