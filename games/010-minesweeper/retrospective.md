# 010 振り返り

2026-11-19に人間の動作確認OKと完了承認を受領。

## 新たに学んだ点

答えを不変の `MineField` に分け、描画には `CellFace` だけを渡すと、進行中に爆弾の位置が表示へ漏れないことをテストで確かめられた。連鎖公開はキューへの投入時に公開済みにすると、各セルを最大1回だけ処理でき、キューの大きさもセル数で足りる。

## 想定との差

Core が4〜32の盤面を受け付ける一方、画面の配置は16×16専用だったため、設定で通る値が画面からはみ出るとレビューで指摘された。仕様は難易度1種なので、可変レイアウトは作らず、作品の設定検証で16×16に限定した。

再戦シードに `Environment.TickCount` を直接使うと、短い間隔で同じ値になりうる。起動時の値から試合ごとに進める方式へ直した。

## 次回の改善点

Core の設定範囲を決めるときに、表示側が支えられる範囲も同時に決め、作品の設定検証へ入れる。HUD のボタンは表示状態だけでなく、最初からクリック経路までテストする。
