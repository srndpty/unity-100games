# 042 振り返り

2026-11-26、動作承認を受領。

- **学び**　Affix を `StatMod`（能力・Flat/Increased・値）の列にし、能力値を「基礎 + Σ Flat → ×(100 + Σ Increased)/100」で装備一式から毎回計算し直すと、付け替えの順序に依らないことを素朴な再計算との乱択照合で保証できた。戦利品の乱数を「試合シード × 階 × 敵の配置番号」の系列に分けると、倒す順・時機に依らず同じ品が出て、二重ドロップのテストと固定ハッシュが安定した。
- **想定との差**　倒れると番人が全快する規則のため、計画の体力 900 では操縦役が削り切れず 440 に下げ、操縦役も階を一掃してから進むようにした。レビューで、試合が可変の `Equipment` を公開して能力値の再計算を迂回できること、初期武器がデータに無い・武器でない設定が検証を通ること、ハッシュの漏れ（飛び道具の半径・最も希少な品）、持ち物が満杯だと操縦役が回復薬も探さないことを直した。
- **次回**　再計算で保つ不変条件を持つ状態は、可変の部品を公開せず参照と複製だけを出す。データの ID を指す設定は、データと合わせて検証する。操縦役の回帰テストは、修正前のコードで失敗することを確かめ、別の経路（次の階など）で条件を満たして通らないよう打ち切り条件を入れる。
