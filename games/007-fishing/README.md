# 007. 釣り — STILLWATER

仕様書：[007-fishing.md](../../plan/games/007-fishing.md) ／ [実装プラン](../../plan/games/007-fishing-implementation.md)

魚の走りと休みを見ながら、巻く・緩めるを切り替える釣りゲーム。1つの釣り場でコブナ・スズキ・コイの3種を捕獲すると総合結果になる。

## 環境・起動

- Unity 6000.6.9f1、Universal 2D、C# 9.0、Windows / StandaloneWindows64。
- Input System、PanelRenderer / UI Toolkit。日本語表示にはWindowsのYu Gothicを使用する。
- シーン：`Assets/Scenes/Fishing.unity`。

```text
dev gui 007
dev build 007
dev run 007
dev capture 007
```

## 操作・採用ルール

| 項目 | 内容 |
|---|---|
| 開始・次の投・新しいプレイ | Enter / UIボタン |
| ポイント選択 | 左右キーで選択しSpaceで決定、またはポイントのボタンをクリックして即決定。浅場＝コブナ、中層＝スズキ、深場＝コイ |
| キャスト | Space / ポイントのボタン。飛行0.5秒、待機2〜4秒の最後0.5秒は魚が接近 |
| 合わせ | アタリから1秒未満にSpaceを新しく押す。早合わせ・見逃しは失敗 |
| ファイト | Space長押しで巻く、離すと緩める。合わせのSpaceを押したまま、最初から巻き続けられる |
| 捕獲 | 距離1m以下かつスタミナ0。取り込み0.8秒後に捕獲確定 |
| 糸切れ | 張力80以上が0.75秒連続 |
| 針外れ | 張力10以下が1.5秒連続 |
| 距離逃走 | 岸から30m以上離れる |
| 危険域から復帰 | 対応する継続カウンタをリセット |
| 同一Tickの決着 | 逃走が捕獲より優先。逃走理由は糸切れ→針外れ→距離 |
| 釣果 | 投ごとの結果から再投。失敗しても釣果を保持し、3種で総合結果。同じ魚を複数回釣ってもよい |
| リセット | タイトルへ戻る／総合結果から新しいプレイ。投数と魚種別捕獲数をリセット。保存なし |
| 停止・再開 | P / Esc。フォーカス喪失でも停止し、復帰後は手動再開 |

停止・画面遷移・フォーカス喪失で保留入力と端数時間を消す。再開後はSpaceを離してから受け付ける。UIクリックは釣り操作には使わない。アタリの開始Tickは有効、期限Tickは無効。

## 魚AIと固定Tick

| 魚 | 初期距離 | スタミナ | 走る強度 | 走る時間 | 休む時間 |
|---|---:|---:|---:|---|---|
| コブナ | 10m | 60 | 0.8 | 1〜2秒 | 2〜3秒 |
| スズキ | 16m | 90 | 1.1 | 2〜3秒 | 1〜2秒 |
| コイ | 22m | 120 | 1.4 | 3〜4秒 | 1〜2秒 |

ファイト中は走る→休む→向き直る（0.5〜1秒）を繰り返す。状態開始時に整数Tickで継続時間を抽選する。

60Hz、初期張力40。引き強度pは走る＝表の値、休む＝0、向き直る＝0.3、スタミナ0＝0。巻くとr=1、緩めるとr=0。

- 張力：`clamp(T + (38r + 18p - 32) / 60, 0, 100)`。
- 距離：`max(0, D + (1.2p - 2.4r) / 60)`。
- Tick開始時の張力が20以上80未満なら、スタミナを`(5 + 5r) / 60`減らす。下限0、回復なし。

入力→AI期限→数値→危険カウンタ→逃走→捕獲の順に処理。スタミナ0による引きの消失は次Tickから反映する。

## 設計

| 層 | 責務 |
|---|---|
| Core | `FishingConfig`・`FishProfile`、`FishingState`・`FishingCommand`、魚AI、数値更新・決着・xorshift |
| App | `FishingFlow`による画面・釣果・入力・時間・停止の管理。`Autopilot`は撮影とテストで共有 |
| Unity | `FishingGame`の描画・入力・HUD・音、`FishingSettings`の設定、`FishingCaptureScenario`の撮影 |

Unity物理への委譲はない。1投＝1シードで状態を新しく作り、再投時は次のシードを使う。同じ実行環境内での再現を保証し、Monoと.NETで決着Tickの一致は要求しない。

設定は`Assets/Game/Unity/FishingSettings.asset`。魚の距離・スタミナ・引き・行動時間、各段階の時間、更新係数、音量を調整できる。有限値・値域・魚種の重複・期間の順序・緩めると張力が下がる関係を検証する。任意の許容設定の捕獲可能性は保証しない。既定値は3種×固定シード1〜20で60秒以内の捕獲を検証する。

時間は補償加算したTick換算値から整数部と端数を取り、1フレーム最大5Tick、超過整数分は捨てる。描画は現在Tickで補間なし。水中が見える横視点、16:9基準で横長16:10〜21:9まで領域が収まるカメラ配置。

背景・人物・魚・ウキ・餌・竿・糸は`Assets/Game/Unity/Art/FishingStage.prefab`に保存し、Sceneビューでプレイ前から表示する。スプライトはインポート済みアセットを参照し、実行時生成しない。Font・AudioClipは所有者の破棄時に解放する。音量既定0.15、波形振幅0.05。バッチと撮影では消音する。

シーン構成の正は`FishingSceneBuilder`。見た目の配置は`FishingStage.prefab`が正で、Sceneビュー／Prefabモードから人物・RodHand・RodTipなどを調整できる。再生成時は既存Prefabを上書きしない。魚と餌の位置は`FishingView`が固定Tickから計算し、遊泳→接近→水面の餌への食いつき→ファイトへ連続して動かす。食いつき中は口元と餌を一致させる。

素材は組み込みimagegenで生成。[保存先と全プロンプト](Assets/Game/Unity/Art/README.md)。背景は容量上限に合わせてJPEG品質95へ形式変換し、人物と魚のPNGアルファは保持する。HUDのみPanelRendererで描画する。

ファイト中の糸は竿先から魚の口まで一本の直線で描き、固定ウキとして、針（魚の口）から竿側へ描画上0.2の距離にウキを置く。待機中と同じウキ下を保ち、魚が潜ればウキも引き込まれる。水面を経由する別の糸は表示しない。ヒット後は踏ん張り用スプライトへ切り替え、AnglerRigを固定Tick由来の小さな平行移動・回転で動かす。人物・手元・竿先・竿が同じRigに属し、糸の始点とウキも追従する。停止時は同じTickを再描画するため揺れも止まる。配置はAnglerAnchor、揺れ幅・周波数・角度はFishingViewで調整できる。

シーン再生成：

```text
unity run games/007-fishing -- -executeMethod Game.Unity.Editor.FishingSceneBuilder.Build
```
