## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 分岐 | 分岐は選択肢と変数（int・bool）だけで決まる。乱数は使わない。同じスクリプトと同じ選択の列なら同じ状態ハッシュになる |
| 実行器 | `ScriptRunner` は番地・変数・表示状態（背景と立ち絵 3 枠）だけを持つ。送り（`Advance`）・選択（`Choose`）で次の待ち（文・選択肢・結末）まで、待ちのない命令（背景・立ち絵・代入・分岐）をまとめて実行する |
| 拒否 | 選択肢の待ちで送る、文の待ちで選ぶ、範囲外の番号、結末の後の操作は理由付きで拒否し、状態・ハッシュを変えない |
| 選択の代入 | 選んだ時点で代入を書いた順に適用してから飛ぶ。選択肢を出している間の状態には、まだ入っていない |
| 立ち絵 | 3 枠（left・center・right）。同じ人物を別の枠に出すと元の枠から消える。`@hide` は出ていなければ何もしない。`@clear` で全て消す |
| 値の範囲 | int 変数は ±9999。代入の結果は範囲で飽和する。リテラルも ±9999 まで |
| 終わらない流れ | 1 回の送りで待ちのない命令を 10,000 回を超えて実行したら例外（検証の網羅探索で、どの経路でも超えないことを確かめる） |
| 文の ID | 既読の記録に使う ID は「直前のラベル名#ラベル内の連番」。ラベルの途中に文を足すと、その後ろの文は既読が付け直しになる |

## DSL の文法

1 行 1 文。行頭の `#` はコメント、空行は無視。インデントは意味を持たない。名前（ラベル・変数・人物・結末の ID）は英小文字・数字・`_`。

| 文 | 例 | 意味 |
|---|---|---|
| ラベル | `*harbor_night` | 飛び先。ファイル内で一意 |
| 変数の宣言 | `$var clue = 0` / `$var trusted = false` | int か bool。最初のラベルより前にだけ書ける |
| 人物の定義 | `@char mio 澪 #8fc3e0` | 話者の ID・表示名・名前の色。最初のラベルより前にだけ書ける |
| 背景 | `@bg hall` | 背景の ID は素材の表（`ScriptCatalog`）と照合する |
| 立ち絵 | `@show mio smile left` / `@hide mio` / `@clear` | 人物・表情（素材の表と照合）・位置 |
| 地の文 | `扉の向こうで、何かが倒れる音がした。` | 1 回の送りで進む 1 文 |
| 台詞 | `mio「見なかったことにはできないよ」` | 話者は `@char` で定義済み |
| 代入 | `$set clue += 1` / `$set trusted = true` | int は `=`・`+=`・`-=`、bool は `= true/false` だけ |
| 条件分岐 | `$if clue >= 2 -> truth` / `$if trusted -> x` / `$if !trusted -> y` | 成り立てば飛ぶ。int は `== != < <= > >=` で値と比べる |
| 飛ぶ | `-> act2` | 無条件 |
| 選択肢 | `?choice` の後に `- 鍵を調べる -> look_key { clue += 1; trusted = true }` を 2〜3 行、`?end` で閉じる | `{}` の代入は省略できる |
| 結末 | `@ending truth 真相` | 結末の ID と名前。ここで終わる |

最初のラベルより前には宣言（`$var`・`@char`）だけを書き、実行は最初のラベルから始まる。

### 検証（`ScriptCompiler`、誤りは行番号と理由付きで全て返す）

| 段階 | 拒否するもの |
|---|---|
| 読む前 | 行数が上限（4,000）を超える |
| 構文 | 未知の命令、`?choice` の閉じ忘れ・対応のない `?end`、選択肢の外の `- ` 行、閉じていない台詞、書式の誤り |
| 名前 | **存在しないラベルへの参照**（`->`・`$if`・選択肢の飛び先）、重複（ラベル・変数・人物・結末）、未定義の変数・話者・人物、素材にない背景・立ち絵・表情、不正な位置 |
| 型 | bool に `+=`、int に true/false、int を比較なしで条件に、bool を大小で比較 |
| テキスト | 空の文・選択肢、文 80 字・選択肢 24 字・名前 10 字を超える、制御文字、`<` `>`（UI のタグになる）、「」の不一致 |
| 数 | 選択肢の項目が 2〜3 個でない。本番シナリオでは選択肢 3 箇所・結末 3 つ |
| 到達性 | 条件分岐は両方へ進むとみなして、どこからも届かない文、結末も飛び先もなくスクリプトの終わりへ素通りする文、後ろに文のないラベル |
| 網羅探索 | 実行器を複製して全ての選択の列をたどり、同じ（番地・変数）の待ちに戻る経路、終わらない流れ、どの選び方でも届かない結末 |

ビルドの直前にも本番シナリオを同じコンパイラで検証し、誤りがあればビルドを止める（セッション 3）。

## 設計上の選択

- **DSL と実行器の分離**：`Game.Core.Script`（構文解析 `ScriptParser`・名前の解決と検証とコンパイル `ScriptCompiler`・規則 `ScriptRules`・素材の表 `ScriptCatalog`）が `Game.Core.Runtime` の命令列（`CompiledScript`・`Instruction`）を作り、実行器（`ScriptRunner`）は命令列だけを読む。`Runtime` の型が `Script` の型を使っていないことをテストで確かめる。
- 網羅探索（`PathExplorer`）は実行器そのものを複製して進めるので、検証と遊ぶときの分岐が食い違わない。テストと撮影の選択の列もここから取る。
- 表示状態（背景・立ち絵）は実行器の状態として持つ。読み込みは命令を再生せず、写し（`RunnerSnapshot`）から戻すだけで画面も戻る。
- スクリプトの指紋（`CompiledScript.Fingerprint`）は命令列と表から作る。コメントや空行を変えても変わらず、文を 1 字変えると変わる。
