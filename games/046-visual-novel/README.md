## 操作

| 操作 | キー・マウス |
|---|---|
| 文を送る（表示の途中なら全文を出す） | クリック・Enter・Space・↓・Z |
| 選択肢を選ぶ | ↑↓ と Enter、または項目をクリック |
| 既読のスキップ | Ctrl を押している間／S で切り替え（未読の文・選択肢・結末で止まる） |
| クイックセーブ／クイックロード | F5／F9（タイトルの「つづきから」も同じ枠） |
| テキスト枠を隠す | H（もう一度 H か決定で戻す） |
| 一時停止（つづける・タイトルへ） | Esc |

クリックはボタンを押した瞬間に効く（離したときではない）。ウィンドウを選び直したクリックは捨てる。

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 分岐 | 分岐は選択肢と変数（int・bool）だけで決まる。乱数は使わない。同じスクリプトと同じ選択の列なら同じ状態ハッシュになる |
| 実行器 | `ScriptRunner` は番地・変数・表示状態（背景と立ち絵 3 枠）だけを持つ。送り（`Advance`）・選択（`Choose`）で次の待ち（文・選択肢・結末）まで、待ちのない命令（背景・立ち絵・代入・分岐）をまとめて実行する |
| 拒否 | 選択肢の待ちで送る、文の待ちで選ぶ、範囲外の番号、結末の後の操作は理由付きで拒否し、状態・ハッシュを変えない |
| 選択の代入 | 選んだ時点で代入を書いた順に適用してから飛ぶ。選択肢を出している間の状態には、まだ入っていない |
| 立ち絵 | 3 枠（left・center・right）。同じ人物を別の枠に出すと元の枠から消える。`@hide` は出ていなければ何もしない。`@clear` で全て消す |
| 値の範囲 | int 変数は ±9999。代入の結果は範囲で飽和する。リテラルも代入・条件ともに ±9999 まで |
| 終わらない流れ | 1 回の送りで待ちのない命令を 10,000 回を超えて実行したら例外（検証の網羅探索で、どの経路でも超えないことを確かめる） |
| 文の ID | 既読の記録に使う ID は「直前のラベル名#ラベル内の連番」。ラベルの途中に文を足すと、その後ろの文は既読が付け直しになる |
| 文字送り | 1 文を Tick（60/秒）で 1 文字ずつ出す（既定 2 Tick/字）。表示途中の決定で全文を出し、出し終えていれば次へ送る |
| 既読 | 文を送った時点で既読にする（表示途中で全文にしてから送った文も既読）。選択肢は既読の対象外 |
| スキップ | Ctrl を押している間か、S で切り替え。**既読の文だけ**を 4 Tick ごとに全文で送り、**未読の文・選択肢・結末で止まる**（切り替えは解除、押し続けは未読の文を普通に文字送りする）。未読もスキップする設定は作らない |
| クイックセーブ | F5 で保存・F9 で読み込み。1 枠だけ。タイトルの「つづきから」も同じ枠。保存するのは実行器の写し（番地・変数・表示状態）で、**選択肢を出している間に保存すると、読み込むと選ぶ前に戻る**。結末の後は保存しない |
| セーブの拒否 | 行指向テキスト（版・スクリプトの指紋・末尾のチェックサム）。空・途中で切れた・1 文字の改変・版違い・指紋違い（シナリオを変えた）・キーの過不足・待ちでない番地・範囲外の変数・素材にない背景や立ち絵は、理由付きで拒否してタイトルの「つづきから」を選べなくし、理由を案内する。移行はしない |
| 既読の記録 | 既読の文と到達した結末を別のファイルに持ち、周回をまたいで残す。選択・結末・タイトルへ戻る・終了のときにまとめて書く。読めなければ空から始めて案内し、書けなければ案内だけ出して遊び続ける |
| 書き込み | 一時ファイルに書いてから原子的に置き換える（041 の `FileSaveStore`）。I/O の失敗は例外にせず案内に変える |
| 結果 | 結末で結果画面：結末の名前と、3 つの結末の到達状況（未到達は「？？？」）。決定でタイトルへ。再プレイは最初から（変数・表示は初期化、既読と到達は残る） |
| 入力 | 1 本の列で順に当てる。クリックは押した画面の版を持ち、画面・待ち・全文表示・枠の表示が変わった後に届いたクリックは捨てる（同じフレームの 2 回のクリックで、全文表示と送り・枠を戻すと送り・2 文送り・2 回選ぶ、をしない） |
| 一時停止 | Esc で一時停止。一時停止の間は時計（Tick）も止め、文字送り・スキップ・案内の期限は進めない |

## シナリオ

オリジナル作品 **LANTERN WAKE（仮）**。嵐で足止めされた灯台の島の宿で、灯台の灯が消え、灯台守の宗助が戻らない一晩の小さなミステリー。本文は [Assets/Game/Data/Scenario.txt](Assets/Game/Data/Scenario.txt)（文 250、1 周 3,300〜3,700 字。1 分 400 字で読み、文字送りと選ぶ時間を足して 10 分前後）。

| 選択肢 | 1 | 2 | 3 |
|---|---|---|---|
| 1. 灯が消えた後 | 灯台を見に行く（手がかり＋1：靴の跡） | 澪と宗助の部屋を調べる（手がかり＋1・信頼＋1：日記） | 蓮と広間に残る |
| 2. 真夜中 | 蓮の部屋の前で待つ（手がかり＋1：油の匂いの手袋） | 澪の話を聞く（手がかり＋1・信頼＋1：合鍵） | 部屋に戻って眠る |
| 3. 午前三時の広間 | 蓮を問い詰める | 澪を疑う | 朝まで待とうと言う |

結末の決まり方：問い詰めるとき、手がかりが 2 以上なら蓮を追い詰め、さらに合鍵を知っていれば **灯は戻る**（真相）、なければ **夜明けの船**（通常）。手がかりが足りなければ **消えた灯**（バッド）。朝まで待つと、合鍵を知っていれば夜明けの船、なければ消えた灯。澪を疑うと必ず消えた灯（信頼 2 なら澪の言葉が変わる）。

全 27 通りの選び方のうち、バッド以外（番号は上の表の列）：

| 選び方 | 結末 |
|---|---|
| 1 → 2 → 1 | 灯は戻る |
| 2 → 2 → 1 | 灯は戻る |
| 1 → 1 → 1 | 夜明けの船 |
| 1 → 2 → 3 | 夜明けの船 |
| 2 → 1 → 1 | 夜明けの船 |
| 2 → 2 → 3 | 夜明けの船 |
| 3 → 2 → 3 | 夜明けの船 |

残りの 20 通りは消えた灯。どの箇所でも選び方を 1 つ変えるだけで結末が変わる組がある（`ScenarioTests` が網羅探索から確かめ、この表とも照合する）。

## DSL の文法

1 行 1 文。行頭の `#` はコメント、空行は無視。インデントは意味を持たない。名前（ラベル・変数・人物・結末の ID）は英小文字・数字・`_`。

| 文 | 例 | 意味 |
|---|---|---|
| ラベル | `*harbor_night` | 飛び先。ファイル内で一意 |
| 変数の宣言 | `$var clue = 0` / `$var trusted = false` | int か bool。最初のラベルより前にだけ書ける |
| 人物の定義 | `@char mio 澪 #8fc3e0` | 話者の ID・表示名・名前の色。最初のラベルより前にだけ書ける |
| 背景 | `@bg hall` | 背景の ID は素材の表（`ScriptCatalog`）と照合する |
| 立ち絵 | `@show mio smile left` / `@hide mio` / `@clear` | 人物・表情（素材の表と照合）・位置 |
| 地の文 | `扉の向こうで、何かが倒れる音がした。` | 1 回の送りで進む 1 文 |
| 台詞 | `mio「見なかったことにはできないよ」` | 話者は `@char` で定義済み |
| 代入 | `$set clue += 1` / `$set trusted = true` | int は `=`・`+=`・`-=`、bool は `= true/false` だけ |
| 条件分岐 | `$if clue >= 2 -> truth` / `$if trusted -> x` / `$if !trusted -> y` | 成り立てば飛ぶ。int は `== != < <= > >=` で値と比べる |
| 飛ぶ | `-> act2` | 無条件 |
| 選択肢 | `?choice` の後に `- 鍵を調べる -> look_key { clue += 1; trusted = true }` を 2〜3 行、`?end` で閉じる | `{}` の代入は省略できる |
| 結末 | `@ending truth 真相` | 結末の ID と名前。ここで終わる |

最初のラベルより前には宣言（`$var`・`@char`）だけを書き、実行は最初のラベルから始まる。

### 検証（`ScriptCompiler`、誤りは行番号と理由付きで全て返す）

| 段階 | 拒否するもの |
|---|---|
| 読む前 | 行数が上限（4,000）を超える |
| 構文 | 未知の命令、`?choice` の閉じ忘れ・対応のない `?end`、選択肢の外の `- ` 行、閉じていない台詞、書式の誤り |
| 名前 | **存在しないラベルへの参照**（`->`・`$if`・選択肢の飛び先）、重複（ラベル・変数・人物・結末）、未定義の変数・話者・人物、素材にない背景・立ち絵・表情、不正な位置 |
| 型 | bool に `+=`、int に true/false、int を比較なしで条件に、bool を大小で比較 |
| テキスト | 空の文・選択肢、文 80 字・選択肢 24 字・名前 10 字を超える、制御文字、`<` `>`（UI のタグになる）、「」の不一致 |
| 数 | 選択肢の項目が 2〜3 個でない。本番シナリオでは選択肢 3 箇所・結末 3 つ |
| 到達性 | 条件分岐は両方へ進むとみなして、どこからも届かない文、結末も飛び先もなくスクリプトの終わりへ素通りする文、後ろに文のないラベル |
| 網羅探索 | 実行器を複製して全ての選択の列をたどり、同じ（番地・変数）の待ちに戻る経路、終わらない流れ、どの選び方でも届かない結末 |

ビルドの直前にも本番シナリオを同じコンパイラで検証し、誤りがあればビルドを止める（セッション 3）。

## 設計上の選択

- App の `NovelFlow` が実行器を動かす唯一の場所。Unity 層には表示用の値（話者・見えている文字・選択肢・背景・立ち絵・既読か）だけを見せる。文字送り・スキップ・クイックセーブ・既読の記録は App にあり、Core の実行器は時間を知らない。
- Unity 層（`NovelGame`）は、物理キーごとの入力アクションとマウスの押下を `Intent` にして Flow に渡し、Stage（`NovelStage`：背景と立ち絵 3 枠の Prefab）・HUD（`NovelHud`：PanelRenderer）・効果音（`NovelAudio`）に Flow の状態を写すだけ。クリックは UI Toolkit のイベントを使わず、押した位置をパネルの座標で HUD の項目の矩形と照合する（バッチ実行の PlayMode テストでも同じ経路を通る）。
- 素材（背景 5・立ち絵 7）はエディタスクリプト（`NovelArtGenerator`）で生成する。Stage Prefab の素材の並びと名前は `Scenario` の素材の表と照合する（`NovelStage.Mismatch`）。シーンは `NovelSceneBuilder` が組む。
- ビルドの直前に `ScenarioBuildCheck`（`IPreprocessBuildWithReport`）が本番シナリオを遊ぶときと同じ規則（設定アセットの上限字数）でコンパイルし、誤りがあれば行番号と理由を付けて `BuildFailedException` でビルドを止める。
- **DSL と実行器の分離**：`Game.Core.Script`（構文解析 `ScriptParser`・名前の解決と検証とコンパイル `ScriptCompiler`・規則 `ScriptRules`・素材の表 `ScriptCatalog`）が `Game.Core.Runtime` の命令列（`CompiledScript`・`Instruction`）を作り、実行器（`ScriptRunner`）は命令列だけを読む。`Runtime` の型が `Script` の型を使っていないことをテストで確かめる。
- 網羅探索（`PathExplorer`）は実行器そのものを複製して進めるので、検証と遊ぶときの分岐が食い違わない。テストと撮影の選択の列もここから取る。
- 表示状態（背景・立ち絵）は実行器の状態として持つ。読み込みは命令を再生せず、写し（`RunnerSnapshot`）から戻すだけで画面も戻る。
- スクリプトの指紋（`CompiledScript.Fingerprint`）は命令列と表から作る。コメントや空行を変えても変わらず、文を 1 字変えると変わる。

## 未解決事項・試遊で見てほしい点

- 文字送りの速さ（既定 2 Tick/字 ＝ 30 字/秒）、スキップの間隔（4 Tick/文）、案内を出す長さは `NovelSettings.asset` で変えられる。試遊で決める。
- クリックとキーの感触（押した瞬間に効く・表示途中の決定で全文）、Ctrl と S のスキップの止まり方、選択肢の分かりやすさ、1 周の長さ（10 分相当か）、3 つの結末の分かれ方、音量。
- 立ち絵は生成した簡素なドット絵（表情は目と口だけ）。
