# 028. 自動攻撃サバイバー — THORN TIDE（仮）

仕様書：[plan/games/028-survivors.md](../../plan/games/028-survivors.md)　実装計画：[plan/games/028-survivors-implementation.md](../../plan/games/028-survivors-implementation.md)

果てのない平原を歩き回り、押し寄せる敵の群れを自動で攻撃する武器で倒して経験値の宝石を集める。レベルが上がるたびに 3 択から武器を得るか強化し、5 分後に現れるボスを倒せば勝ち。参考作品からはメカニクスだけを採用し、名称と見た目は独自に作る。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード（移動・3 択・画面の操作）とマウス（3 択のクリック）。ゲームパッドは対応しない。HUD は PanelRenderer / UI Toolkit
- 共通パッケージ：
  - [com.games100.int-geometry](../../packages/com.games100.int-geometry/)（`Vec2i`・`IntMath`・`Rect`・円の掃引 `Sweep`・整数の角度表 `Trig`・`SeededRandom`）
  - [com.games100.tile-motion](../../packages/com.games100.tile-motion/)（`Units`・残り Tick の `Countdown`・状態ハッシュ `StateHash`）

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 単位 | 1 セル = 256 単位の整数。速さは単位/Tick、60 Tick/秒。時間の設定は Tick 数。浮動小数点を使わないので Mono と .NET で同じ結果になる |
| 試合 | **5 分（18000 Tick）でボスが出て、倒せば勝ち**。体力 0 で負け。ボスが出てから 2 分（7200 Tick）以内に倒せなければ時間切れで負け。仕様書の「10 分間」から、計画の段階で 5 分に決めた（長さは設定の Tick 数） |
| フィールド | 果てのない平面（壁も障害物もない）。視野は自機を中心とする 32×18 セルで、カメラも同じ関数（`TideRun.ViewOf`）で置く。最も長い試合を最も速く動いても座標が int に収まることを設定の検証で保証する |
| 自機 | 体力 100・半径 80。8 方向に速さ 22（斜めは各軸 181/256 倍、最低 1）。最後に動いた向きと、最後に左右へ動いた向き（Lash の向き）を覚える |
| 敵の定義（データ） | 名前・振る舞い・半径・速さ・体力・接触ダメージ・落とす経験値。振る舞いはコード（**Chase**：自機へ向かう／**Swarm**：出現したときの自機の向きへ直進して通り過ぎる／**Boss**：Chase と同じ動きで、倒すと勝ち）、数値はデータ。既定は mite（Chase・体力 3・速さ 10）、gnat（Swarm・体力 2・速さ 22）、husk（Chase・体力 16・速さ 7）、warden（Boss・体力 1500・半径 320）。ボスの定義はちょうど 1 つ |
| 武器の定義（データ） | 種類とレベル 1〜5 の値の表（ダメージ・間隔・数・射程・大きさ・速さ・貫通・寿命）。**表の値をそのまま使い、倍率の計算をしない**（強化後の値は表と照合できる）。種類ごとに使わない値は 0 |
| 武器 5 種 | **Bolt**：射程の中の近い順に「数」体を狙って弾を撃つ（敵が数より少なければ近い敵から重ねて狙う。射程に敵がいなければ撃たずに待つ）。弾は直進し、寿命か貫通数を使い切ると消える。**Orbit**：自機の周り（半径＝射程）を「数」枚の刃が毎 Tick「速さ」の角度だけ回る。同じ敵へは「間隔」Tick に 1 回。**Pulse**：「間隔」ごとに、自機を中心とする半径＝射程の円に重なる敵すべてへ。**Lash**：「間隔」ごとに、向いている左右へ長さ＝射程・半分の高さ＝大きさの矩形を斬る（数 2 なら反対側も）。**Arc**：「間隔」ごとに、射程の中の最も近い敵から、1 段の距離＝大きさの中の最も近い（まだ打っていない）敵へ順に「数」体まで連鎖する（射程に敵がいなければ待つ）。最初の武器は Bolt Lv1 |
| 発動の間隔 | 発動したら待ちを「間隔」にし、毎 Tick 1 減らして 0 になった Tick に発動する（間隔 I なら I Tick ごと）。強化の後の待ちは新しい間隔を超えない。新しく得た武器は次の Tick に発動する |
| 当たり判定 | 弾×敵・自機×敵・宝石×自機・刃×敵は **Tick の中の相対軌跡どうしの掃引**（`Sweep`）。中心の距離が半径の和より小さくなったら触れたとする（ちょうど接するだけでは触れない）。刃は始めの位置から終わりの位置への弦で円弧を近似する。Pulse は円どうし、Lash は円の外接矩形と矩形で、発動した Tick の位置で判定する |
| 1 回の発動は 1 回だけ当たる | 弾は当たった敵を覚え、同じ敵へ二度当たらない（貫通数まで、触れた時刻の順。同時なら番号の小さい敵）。弾は並びの順に解決し、先の弾が倒した敵は素通りする（倒れた敵に弾を使わない）。Lash の両側・Arc の連鎖で同じ敵には 1 回。Orbit の刃が同じ Tick に同じ敵へ 2 枚触れても 1 回 |
| 被弾 | 無敵でない自機は、その Tick で最初に触れた敵（同時なら番号の小さい敵）の接触ダメージを受け、**被弾した Tick を含めて 30 Tick 無敵**。敵は消えない。武器が倒した敵は同じ Tick に自機へ触れない |
| 経験値の宝石 | 倒した敵の位置に、敵の経験値の値の宝石（固有の番号）を落とす。自機から 2.5 セル未満に入った宝石は以後ずっと自機へ吸い寄せられ（速さ 40）、自機に触れた Tick に値を**1 回だけ**加えてその場で消える。落ちている宝石は 256 個まで。満杯のときの宝石は、いちばん近い宝石に値を足す（落ちている値の合計は保たれる）。常に「取った合計 + 落ちている合計 = 落とした合計」 |
| レベルアップ | 経験値の表（Lv1→2 に 5、以後 8・11・14…）。到達したら超えた分を持ち越し、**レベルごとに 1 回ずつ 3 択**を出す。3 択の間は試合が止まる（Tick が進まない）。候補は「持っていない武器の取得（Lv1）」と「最大でない武器の強化」から重複なく 3 つを専用の乱数で選び、武器の番号の順に並べる。3 つに満たなければ「体力回復（+30、最大まで）」を足す。最大レベルの武器は候補に出ない |
| 出現 | 30 秒ごとの 10 区間の表で「目標の生存数」「出現の間隔」「種類の重み」を決める（目標 20 → 40 → … → 350、間隔 30 → … → 3 Tick）。予算を毎 Tick 1 ずつ貯め、間隔に達して、ボスを除いた生存数が目標と上限の小さいほうを下回っていれば 1 体出して 0 に戻す。**予算は間隔 1 回分で頭打ち**、1 Tick に出すのは最大 1 体。位置は自機から 20〜24 セルの輪の上（乱数の角度・距離）で、**視野の外**（設定の検証で、輪の内側を視野の半分の対角線 + いちばん大きい敵の半径 + 8 以上にする。角度表の丸めの誤差は 1 未満） |
| 敵の数の上限 | ボスを除いて **400 体**（設定の上限は 1000）。ボスは別に 1 体。上限に達している間は出さない |
| 置き直し | 自機から 32 セルより離れた敵（ボス以外）は、自機の進む向きの側（±45°）の出現の輪へ置き直す。体力と番号は保ち、数は増えない。Swarm は新しい位置から自機へ向け直す |
| 更新頻度の制御 | Chase とボスが自機への向きを決め直すのは **6 Tick に 1 回**。どの Tick に決め直すかは敵の番号で位相をずらすので、毎 Tick 全体の約 1/6 だけが決め直し、どの敵も 6 Tick の中でちょうど 1 回決め直す。移動は毎 Tick、直前に決めた向きで進む |
| 近傍探索 | 自機を中心とする一様グリッド（1 マス 2 セル、置き直しの距離を覆う大きさ）に、毎 Tick 敵の番号を計数ソートで詰め直す（固定長の配列だけで、割り当てをしない）。範囲の外の敵は端のマスに入れる（寄せ方が単調なので、矩形の中の敵を問い合わせで見逃さない）。武器の狙い・当たり・押し合い・被弾はすべてこのグリッドの候補から正確な距離で絞る |
| 押し合い | 重なった敵どうしは、移動の後の位置から全員の押す量をまとめて計算してから動かす（処理の順に依らない）。1 体が見る近傍は 6 体まで（グリッドの順）、動かされる量は 1 Tick 12 まで。ボスは押されない |
| 1 Tick の順序 | 時間（無敵・点滅・Orbit の再ヒット待ち）→ 自機の移動 → 敵の向き（位相の合う敵だけ）と移動 → 押し合い → グリッドの作り直し → 武器の発動（定義の順）→ 弾の移動と当たり → 自機×敵 → 宝石の吸い寄せと取得 → 倒れた敵を詰める → レベルアップ → 置き直し → 出現 → ボスの出現・時間切れ。ボスを倒した Tick に勝ちが決まる |
| 乱数 | 1 試合 = 1 シードの xorshift（`SeededRandom`）。出現の位置（置き直しを含む）・種類・3 択で系列を分ける。再戦は次のシード |
| 終了後 | 勝ち・負けの後の Tick と入力は状態を変えない。3 択の外での選択は拒否する |

## 設計上の選択

- **物理エンジンは使わない。** 移動・当たり・押し合いはすべて Core の整数演算で行う。
- **敵・武器・出現はデータ。** Core の `EnemyDef`・`WeaponDef`（レベルの表）・`SpawnStage` は公開フィールドの素のクラスで、Unity 層の定義アセット（ScriptableObject）から写す。振る舞い（`EnemyBehavior`・`WeaponKind`）だけがコードで、数値の範囲・組み合わせ（ボスは 1 つ、重みの数は敵の定義と同じ、Bolt の弾が強化をまたいで同時に存在しうる数の上界 ≤ 弾の容量、出現の輪が視野の外、置き直しが輪より遠い、座標が int に収まる）は `TideConfig.Validate` で拒否する（fail-closed）。
- **敵・弾・宝石は固定容量の SoA。** 容量は設定から作り、Step の中で割り当てをしない（.NET のテストで 0 バイトを確かめる）。倒れた敵は Tick の終わりまで番号を保ち（グリッドの番号が Tick の中で変わらない）、最後に末尾と入れ替えて詰める。
- **近傍探索と更新頻度は Core の規則。** グリッドの問い合わせは全探索と照合し、向きの決め直しの位相（`TideRun.IsSteerPhase`）は「どの番号・どの Tick から数えても間隔の中で 1 回」をテストする。
- **3 択の間は Core が止まる。** `TideRun.Step` は 3 択の間は何もせず、`Choose` で選ぶと次の 3 択（残っていれば）を出す。App（`TideFlow`）は 3 択が出たら `LevelUp` の画面へ移り、選んだ時刻から時計を数え直す。出たばかりの 3 択は 0.3 秒の間は選ばない（連打・押しっぱなしで出た瞬間の候補を選ばない）。
- **定義アセットが正。** Unity 層の `EnemyDefinition`・`WeaponDefinition`（ScriptableObject、`Assets/Game/Unity/Data/`）は Core の定義をそのまま持ち、表示名・説明・絵の区画だけを足す。`ThornTideSettings.BuildRules` が定義アセットの並びで Core の設定を組み立てて検証する（設定の側の Enemies・Weapons は空で、二重に持たない）。生成スクリプトは既存の定義アセットを上書きしない。
- **描画は Stage Prefab 1 つ。** 床は Tiled の SpriteRenderer を模様の倍数の位置に寄せて置き、果てなく続いて見せる。数の多い敵・宝石・弾は `QuadLayer` が 1 つの Mesh に四角形を詰めて描き（容量は設定の上限の和、毎フレームの割り当てなし）、被弾の点滅は頂点の色で示す。自機・ボス・Orbit の刃・Pulse の輪・Lash の斬撃・Arc の稲妻は Prefab の描画物。体の絵は既定の半径で描き、設定の半径に合わせて拡縮する。Tick の状態をそのまま描き、補間しない。
- 自動操縦（`Autopilot`）は App に置き、移動（9 通りから、近くの敵との隙間が 1.5 セルを切る危なさが小さく、いちばん近い敵（ボスが出ていればボス）から武器の届く距離を保ち、近くの宝石へ寄る向き）と 3 択（未所持の武器 → 低いレベルの強化 → 回復）を決める。判断の状態を持たない。撮影台本とテストで共有する。

## 未実装範囲

- 仕様書の Out of scope：大規模メタ進行、多数キャラ（自機は 1 種）。
- 仕様書の「10 分間」は 5 分 + ボスにした（試合の長さは設定）。
- 受け身の強化（移動速度・吸い寄せ範囲など）、武器の進化・合成、宝箱は作らない。敵は弾を撃たない。
- ゲームパッドには対応しない。
