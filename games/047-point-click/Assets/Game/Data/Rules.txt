# ---- 持ち物 ----
@item knife 包丁
@item rusty_key 錆びた鍵
@item bottle 空き瓶
@item oil 油の瓶
@item cup カップ
@item hot_water お湯のカップ
@item tea_leaves 茶葉
@item tea 温かいお茶
@item matches マッチ

@flag met_captain
@flag asked_leave
@flag asked_fire
@flag tap_open
@flag lamp_oiled

# ---- 謎（after は先に解く謎） ----
@puzzle free_key 網から鍵を外す
@puzzle open_tower 灯台の扉を開ける after free_key
@puzzle draw_oil 樽から油を汲む
@puzzle warm_captain 船頭にお茶を出す
@puzzle light_lamp 灯台に灯をともす after open_tower draw_oil warm_captain
@goal light_lamp

# ---- 小屋のルール ----
look cottage.door : 「船着き場へ出る戸だ。」
look cottage.tower_door when !solved open_tower : 「灯台へ続く扉。錆びた錠がかかっている。」
look cottage.tower_door when solved open_tower : 「灯台へ続く扉。もう開いている。」
use knife on cottage.tower_door : 「包丁でこじ開けるのは無理だ。鍵がいる。」
use rusty_key on cottage.tower_door : unlock cottage.tower_door ; lose rusty_key ; solve open_tower ; 「錆びた鍵が回った！ 扉が開いた。」
look cottage.window : 「横殴りの雨だ。灯台の灯が消えている。」
look cottage.table : 「使い込まれた木の机だ。」
look cottage.knife : 「よく研いだ包丁だ。」
take cottage.knife : give knife ; hide cottage.knife ; 「包丁を手に取った。」
look cottage.cup : 「空のカップだ。」
take cottage.cup : give cup ; hide cottage.cup ; 「カップを手に取った。」
look cottage.shelf : 「缶や瓶が並んだ棚だ。」
look cottage.tea_tin : 「茶葉の缶だ。」
take cottage.tea_tin : give tea_leaves ; hide cottage.tea_tin ; 「缶から茶葉をひとつかみ取った。」
look cottage.bottle : 「空き瓶だ。何か入れられそうだ。」
take cottage.bottle : give bottle ; hide cottage.bottle ; 「空き瓶を拾った。」
look cottage.stove : 「ストーブの上でやかんが湯気を立てている。」
use cup on cottage.stove : lose cup ; give hot_water ; 「やかんのお湯をカップに注いだ。」
use bottle on cottage.stove : 「油を入れる瓶だ。お湯は要らない。」

# ---- 船着き場のルール ----
look dock.path : 「小屋へ戻る小道だ。」
look dock.net when !solved free_key : 「古い漁網に、何か光る物が絡まっている。」
look dock.net when solved free_key : 「切れた漁網だ。」
take dock.net when !solved free_key : 「固く絡まっていて、手では外せない。」
use knife on dock.net : solve free_key ; give rusty_key ; 「網を切ると、錆びた鍵が落ちた。」
look dock.barrel when !tap_open : 「灯台用の油の樽だ。栓が固く閉まっている。」
look dock.barrel when tap_open : 「灯台用の油の樽だ。栓はゆるんでいる。」
use knife on dock.barrel when !tap_open : set tap_open ; 「包丁でこじると、栓がゆるんだ。」
use knife on dock.barrel when tap_open : 「栓はもうゆるんでいる。」
use bottle on dock.barrel when !tap_open : 「栓が固くて開かない。何かでこじれば……。」
use bottle on dock.barrel when tap_open : lose bottle ; give oil ; solve draw_oil ; 「瓶に油を汲んだ。」
look dock.captain when !met_captain : 「小舟のそばで、男が寒そうに震えている。」
look dock.captain when met_captain : 「町の船頭だ。寒そうに震えている。」
talk dock.captain when !met_captain : set met_captain ; 「おう、灯台守の見習いか。ひどい嵐だな。」
talk dock.captain when met_captain : 「どうした？」
use hot_water on dock.captain : 「ただのお湯か。せめて茶葉くらい入れてくれ。」
use tea on dock.captain when !asked_fire : 「茶か。ありがたいが、何の用だ？」
use tea on dock.captain when asked_fire : lose tea ; give matches ; solve warm_captain ; 「ああ、生き返る。約束のマッチだ。」
look dock.boat : 「船頭の小舟だ。嵐の中でも出せそうだ。」
look dock.sea : 「荒れた海だ。岩場で白い波が砕けている。」

topic dock.captain leave 「町へ戻れませんか？」 when !asked_leave : set asked_leave ; 「灯台の灯が消えてちゃ、岩場を抜けられん。」 ; 「灯がともれば、すぐ船を出すさ。」
topic dock.captain leave_again 「灯台のことですが……」 when asked_leave : 「灯がともれば船を出す。それだけだ。」
topic dock.captain fire 「火を持っていませんか？」 when asked_leave and !asked_fire : set asked_fire ; 「マッチならある。だが体が冷えてかなわん。」 ; 「温かい茶でも一杯あればなあ。」
topic dock.captain fire_again 「マッチを貸してください。」 when asked_fire and !solved warm_captain : 「温かい茶が先だ。小屋にストーブがあるだろう。」
topic dock.captain storm 「ひどい嵐ですね。」 : 「朝までは止まんだろうな。」

# ---- 灯室のルール ----
look lighthouse.stairs : 「小屋へ下りる階段だ。」
look lighthouse.window : 「嵐の海だ。灯がなければ船は出せない。」
look lighthouse.logbook : 「日誌だ。油は船着き場の樽、火は船頭が持っている。」
look lighthouse.lamp when !lamp_oiled : 「大きなランプだ。油が切れて消えている。」
look lighthouse.lamp when lamp_oiled : 「油は入った。あとは火をつけるだけだ。」
use oil on lighthouse.lamp : lose oil ; set lamp_oiled ; 「ランプに油を注いだ。あとは火だ。」
use matches on lighthouse.lamp when !lamp_oiled : 「油が空だ。先に油を入れないと。」
use matches on lighthouse.lamp when lamp_oiled : lose matches ; solve light_lamp ; 「灯がともった！ 光が嵐の海を照らす。」

# ---- 持ち物 ----
look knife : 「よく研いだ包丁だ。」
look rusty_key : 「錆びた鍵だ。灯台の錠に合いそうだ。」
look bottle : 「空き瓶だ。」
look oil : 「灯台用の油が入っている。」
look cup : 「空のカップだ。」
look hot_water : 「熱いお湯の入ったカップだ。」
look tea_leaves : 「ひとつかみの茶葉だ。」
look tea : 「湯気の立つお茶だ。」
look matches : 「湿っていないマッチだ。」
use tea_leaves on hot_water : lose tea_leaves ; lose hot_water ; give tea ; 「茶葉を入れて、温かいお茶ができた。」
use tea_leaves on cup : 「お湯がなければお茶にならない。」
