# 035 振り返り

- **学び**　連続衝突検出は、経路を 1 単位ずつの点の列と定義すると整数の比較だけで厳密になり、すり抜けないことが点の間隔から言える。保守的前進で飛ばしても、全点の走査という素朴な参照実装と照合できる。物理を整数で持つと、操縦役の試合の最終ハッシュが .NET と Mono で一致し、撮影の試合も .NET で先に探せた。
- **想定との差**　接触した区間の残りや位置の端数を捨てると、斜面の球が止まり、フリッパーの軸の上で釣り合って止まった。「近づいているか」をフリッパーの面の速さとの相対で判定すると、今の姿勢へ食い込んだ。光った Tick の初期値 `long.MinValue` の引き算が桁あふれした。束ねたキーを入力層で集約すると、一時停止で Flow が離したとみなした状態と食い違った。
- **次回**　物理の区間の中で「止まっているとみなす物」は、当たる相手の選び方も同じ前提で判定する。時刻の差を取る値の初期値は桁あふれしない印にし、比べる前に除く。状態を離す側（Flow）が、押しているキーをキーごとに持つ。
- **不具合**　セッション3でタイトルと試合の始めに全てのバンパーが光る（初期値の桁あふれ）。レビュー P2-1 一時停止・フォーカス喪失をまたぐと束ねた別のキーが効かない、P3-1 左右のフリッパーの重なりを検証しない、P3-2 Prefab の照合がプランジャーの拡大率を見ない。
