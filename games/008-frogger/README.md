# 008. Frogger — LITTLE CROSSING

仕様書：[008-frogger.md](../../plan/games/008-frogger.md) ／ [実装計画](../../plan/games/008-frogger-implementation.md)

車をよけ、流れる丸太に乗って向こう岸へ渡る、見下ろし2Dの1面。

## 環境と起動

Unity 6000.6.9f1、Universal 2D、C# 9.0、Windows / StandaloneWindows64。Input System、SpriteRenderer、PanelRenderer / UI Toolkitを使用。日本語はWindowsのYu Gothicで表示する。

```text
dev build 008
dev run 008
dev gui 008
```

シーンは `Assets/Scenes/Frogger.unity`。

## 操作とルール

| 項目 | 採用ルール |
|---|---|
| 開始・再挑戦 | Enterまたはボタン |
| 移動 | 方向キー／WASD、1押下1マス。長押しリピートなし |
| 同時入力 | 同一Tickは上→下→左→右の優先順で1方向。入力は蓄積しない |
| 停止・再開 | P／Escまたはボタン。フォーカス喪失で停止し、復帰後は手動再開 |
| 盤面 | 幅11マス、下から開始岸・道路3列・中間岸・川3列・ゴール岸の9行 |
| 勝利 | 最上段の岸に1回到達。複数の巣・残機・時間制限・得点は設けない |
| 敗北 | 車接触、丸太のない川へ着地、足場で画面外へ運ばれる。理由を別々に表示 |
| 丸太 | カエルの横方向の当たり範囲全体が1本に収まれば乗れる。端の一致は有効 |
| 足場上の移動 | 流された現在位置から1マス移動し、グリッドへ吸着しない |
| 手動の場外入力 | 無視する。足場による場外移動ではカエルをラップさせず敗北 |
| 再挑戦 | 同じ固定配置のTick 0から開始。乱数・保存なし |

ホップはCoreでは瞬時に隣接位置へ移動し、途中を通過した物体とは判定しない。カエルの当たり幅は足元の0.5マス、四肢の装飾は含まない。車は接触を含めて衝突、川では足場内への完全な包含を要求する。終了後は入力とTick更新を無視する。

停止・遷移・フォーカス喪失で保留入力と端数時間を消す。復帰時は方向キーを離してから入力を受け付ける。

## 固定Tickと構成

| 層 | 責務 |
|---|---|
| Core | `FroggerConfig`・レーン設定、`FroggerState`、方向・結果、周期移動、足場と危険判定 |
| App | `FroggerFlow`の画面遷移・保留入力・時間管理、撮影とテスト共用の`Autopilot` |
| Unity | 入力・HUD・音、`FroggerView`の描画、設定アセット、シーン生成、撮影 |

60Hz。入力・着地・ゴール判定→足場確定→物体移動→移動中の危険判定の順。即時の着地失敗・勝利ではその時点で止める。車はTick開始と終了を結ぶ掃引区間と前後1周期のコピーで判定し、周期境界を盤面横断として扱わない。丸太の正規化前の変位をカエルへ加え、相対位置を維持する。Unity物理への委譲はない。

Appは補償加算したTick換算値から整数部と端数を分ける。1フレーム最大5Tick、超過整数分は捨てる。描画は現在Tickの状態を使い補間しない。タイトルの初期位置はCoreと共通の位置計算から直接描き、状態オブジェクトを生成しない。固定配置と入力列による再現性は同じ実行環境内で保証する。

レーンは各4物体、間隔4マス、周期16マス。設定の最大速度は絶対値12マス/秒、物体幅1〜3.5マス、位相0以上16未満、カエル半幅0.1〜0.4マス。1Tickの変位は最大0.2、接触半径は最大2.15で、前後1周期のコピーが十分な範囲を覆う。表示位置は-2.5以上13.5未満で、半幅上限1.75が盤面外の余白2.5に収まるため、画面内の描画コピー追加は不要。

設定アセットは `Assets/Game/Unity/FroggerSettings.asset`。速度・方向（符号）・幅・位相・カエル判定幅・音量を調整できる。間隔・本数・盤面サイズは固定。有限値と値域を検証する。許容設定すべてのクリア可能性は保証せず、既定面の通し走破を自動検証する。

## 描画と制作素材

[生成素材と全プロンプト](Assets/Game/Unity/Art/README.md)。組み込みimage_genで盤面・カエル・車・丸太を生成した。透過PNGを保持し、世界の描画はインポート済みスプライトと`FroggerStage.prefab`で構成する。背景・主要物体はプレイ前からSceneビューで見える。画面外の物体はSpriteMaskで隠す。

配置の正はStage Prefab。シーン生成スクリプトは既存Prefabを上書きしない。HUDのみPanelRendererで描画し、接続直後に描画する。16:9を基準に16:10〜21:9の横長で盤面が収まるカメラ配置。音量既定0.12、波形振幅0.05、バッチと撮影では消音。実行時生成のFontとAudioClipは所有者が破棄する。

```text
unity run games/008-frogger -- -executeMethod Game.Unity.Editor.FroggerSceneBuilder.Build
```
