# 037 振り返り

- **学び**　車両・壁・ゲート・車同士の接触を 1 mm 単位の整数と Tick だけで書くと、400 Tick の固定ハッシュが .NET と Mono で一致し、接触の掃引も `Sweep.First` の上限を設定の検証で保証できる。煙のような演出の粒もレースの Tick で歳を取らせると、撮影が同じ絵になり、PlayMode で 2 回の通しを比べられる。
- **想定との差**　当初の「車同士はすり抜ける」「ターマックの端が壁」は試遊で物足りないとされ、接触・芝とガードを足した。接触は触れた時刻で止めると並走する車がほとんど進めず、Tick の残りを衝突後の速度で進めた。接触を入れると CPU が一列に詰まったので、自分の側から追い越す筋を足し、回復中に停滞を数えて後退し続ける不具合も表に出た。
- **次回**　ゲートのような線の通過判定は、最初から線の上を片側に含める（半開）。1 つの操作に複数のキーを割り当てるなら、入力層も物理キーごとに縁を取って番号を送る。車の絵の大きさを決めてから当たりの半径を決める。
- **不具合**　レビュー P2-1 線の上にちょうど止まると次の Tick に奥へ出てもゲートを数えない、P2-2 一時停止の後に W を押したまま ↑ を押しても加速しない（Unity 側が 2 本のキーを 1 つにまとめていた）、P3-2 `Track.Walls`・`Gates` が外から書き換えられる、P3-3 リポジトリ直下の `Library/ilpp.pid` が追跡されていた。PR のレビュー P1 で、キーを毎フレームの `isPressed` で読んでいたため、フレームの間に押して離した操作が届かず、時刻もフレームの時刻になっていた。022・035 と同じく Input System のコールバックで起きた時刻つきで集めるようにした。台本の走りは変わらず、固定ハッシュ `108021296` と証跡 8 枚は対応前と同じ。
