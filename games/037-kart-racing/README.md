# 037. カートレース

THISTLE CIRCUIT（仮）。真上から見る 1 周のカートレース。仕様書：[plan/games/037-kart-racing.md](../../plan/games/037-kart-racing.md)

## 環境

- Unity：6000.6.9f1
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：キーボード（Input System）

## 起動手順

```
dev gui 037      # エディタで開く
dev build 037    # Windows ビルド
dev run 037      # ビルドを起動
dev capture 037  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| キー | 操作 |
|---|---|
| ← → または A D | 旋回 |
| W または ↑ | 加速 |
| S または ↓ | ブレーキ（後退まで） |
| Space | ドリフト（加速と旋回を押しているとき） |
| Enter | スタート、再開、再戦 |
| Esc | 一時停止、再開。結果ではタイトルへ |
| R | 一時停止中にやり直し |
| Backspace | 一時停止からタイトルへ |

フォーカスを失うと一時停止し、押したままのキーとドリフトの溜めを消す。ブーストにはしない。復帰は Enter か Esc。

## 採用ルール

| 項目 | ルール |
|---|---|
| 時間 | 60 Tick/秒。入力はその時刻を含む Tick の前に反映し、次の Tick から効く |
| 座標 | 1 単位 = 1 mm。向きは 1 周 = 65536。速さは mm/Tick。浮動小数点は使わない |
| 車 | 半径 450 mm の円。位置、向き、速さ、ドリフトの溜め、ブースト残り、周回、次のゲート、回復の残り |
| 加速 | 押している間 `Accel`（8）ずつ上限へ。ブースト中の上限は 500。離すと `Drag`（3）で 0 へ向かい、0 は越えない |
| ブレーキ | `Brake`（14）ずつ、後退の上限 140 まで |
| 旋回 | 低速で大きく（700）、`MaxSpeed`（340）で小さい（160）。速さ 0 では向きも位置も変えない。後退中は符号を反転する |
| ドリフト | 加速中、旋回が左右どちらか一杯、速さ 160 以上で開始できる。押している間は旋回を 280 足し、速さを 4 減らし、移動を向きより 600 遅らせる。ボタンだけを離したとき溜めが 8 Tick 以上なら 40 Tick のブースト。1 Tick 不足、加速を離す、壁に当たった Tick は溜めを消してブーストを出さない |
| 壁 | 左右の折れ線。食い込んだら内側へ押し出して接線方向へ滑る。1 Tick に 2 回まで。まだ食い込んでいたら速さを 0 にする。ちょうど接するだけでは触れない |
| 車同士 | 重なっても速度も位置も変えない |
| 周回 | 次のゲートを、手前から奥へ横切ったときだけ印が進む。逆走、飛ばし、線の上では進まない。0 番を前向きに横切ると周回 +1。3 周目の 0 番で完走し、その場で止まる |
| 順位 | 完走は記録の早い順、未完走は周回・ゲート・区間の進みの順。同着は番号の小さい方が上。必ず 1〜4 が 1 つずつ |
| 終了 | 4 台が完走するか 20000 Tick。1 位が勝利。結果の後は操作で順位を変えない |
| スタート | 90 Tick は車を動かさない |
| CPU | 中心線の 8 m 先へ向き、32 m 先までの曲率で目標の速さを決める。角ではドリフトし、8 Tick 溜めたら離してブーストする。進みが 40 Tick 止まると後退して向きを直す。直線の速さは 880 / 800 / 720（1000 がプレイヤー） |
| 再現 | 乱数は使わない。初期配置と設定と入力列だけで決まる。再戦は同じコースを最初からやり直す |

実装で当初の表から変えた点：上限の速さは 340（380 だと角で壁に張り付く）。ミニターボは 8 Tick（25 Tick ドリフトし続けるとコースを外れる）。横滑りは 600。CPU の先読みはハンドル 8 m、曲率は 32 m。スタートグリッドは 0 番ゲートの手前にいるため、立ち往生の判定は区間の進みではなく中心線に沿った進みで行う。

## 設計上の選択

- 車両の積分、壁、ゲート、順位、CPU の意図は Core。画面遷移と時刻付きの入力は App。Unity は描画と入力と音だけを行う。物理エンジンには委譲しない。
- 車同士はすり抜ける。順位はコース上の進みだけで決まる。
- 固定ハッシュ `1723866012`（400 Tick の同じ操作）。.NET と Mono で一致する。

## 性能

実コースを走っている 300 Tick（4 台、このコースの壁）で、Core の Step は p95 0.058 ms、車と追従カメラの更新は p95 0.003 ms、割り当て 0 バイト。計測の条件と画面は [evidence/README.md](evidence/README.md)。

## 試遊で見てほしい点

加速の伸び、高速での曲がりにくさ、ドリフトの滑りとミニターボの溜め（8 Tick）、壁に擦ったときの止まり方、CPU との速さの差、スタート待ち（1.5 秒）、音量。
