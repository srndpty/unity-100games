# 048 攻略（デバッグ用）

答え（ダイヤルの 3 桁・リングの星座・時計の時刻・宝石の順）は、試合ごとのシードで変わる。下の手順は場所と読み方で、答えそのものは手がかりか、**H を 3 回**（同じ一手のヒントの答えの段階）で分かる。

## 詰まないことの保証

- 仕掛けは一本の鍵の連鎖で、拾った物はなくならず、仕掛けの値（ダイヤル・リング・針）は循環するので何度でも合わせ直せる。宝石は間違えると最初からになるだけ。
- ビルドの前に、状態空間の全 15 状態から脱出に届くこと（クリックで実際に操作できることを含む）を確かめている（`RoomBuildCheck`）。
- したがって「先へ進めない」ときは、答えを読み違えている可能性が高い。H を 3 回押すと、今の一手の答えが出る。

## 手順

| # | 場所（壁 → 近景） | すること | 手がかり・答えの読み方 |
|---|---|---|---|
| 1 | 北の壁 → 机 | 真鍮の筒をクリックで手に取り、**上へドラッグ**（縦に 1 段）して底を見る | 底の 3 桁がダイヤルの答え（左から 1・2・3 桁目） |
| 2 | 机 | 引き出しの右のダイヤルの桁をクリックして合わせる（0→1→…→9→0） | 合うと前板が倒れる。中の**真鍮の鍵**をクリックで拾う |
| 3 | 東の壁 → キャビネット | 持ち物の真鍮の鍵の枠をクリックで選び、扉の下の鍵穴をクリック | 扉が開く。中の**星図の円盤**を拾う |
| 4 | どこでも | 持ち物の円盤の枠を選び、同じ枠をもう一度クリックして手に取る。**横へドラッグして 180°**（4 段）回し、裏を見る | 裏の 3 つの星座が、上から天球儀の上・中・下のリングの答え。**縦に 180° 裏返すと逆さに見えるので読めない**（正立したときだけ星座が出る） |
| 5 | 西の壁 → 天球儀 | 円盤の枠を選び、台座のくぼみをクリックしてはめる | リングが回るようになる |
| 6 | 天球儀 | リングをクリックして 45° ずつ回し、正面の印を円盤の印に合わせる | はめた円盤も台座でクリックすれば手に取って見直せる。H を 3 回で「上のリングをあと N 回…」が出る |
| 7 | 天球儀 | ふたが外れる。上の**歯車**を拾う | |
| 8 | 東の壁 → 本棚 | 飛び出している赤い天文書をクリックで手に取り、横に 180° 回して裏表紙を見る | 文字盤の時刻が柱時計の答え（12 時は赤い三角） |
| 9 | 南の壁 → 柱時計 | 歯車の枠を選び、文字盤の中央の軸をクリック | 針が動くようになる |
| 10 | 柱時計 | 文字盤の下の左のつまみ（短針、1 時間ずつ）と右のつまみ（長針、5 分ずつ）で時刻に合わせる | 振り子の扉が開く。中の**金庫のハンドル**を拾う |
| 11 | 北の壁 → 望遠鏡 | のぞく | 星が赤・青・緑・黄のどれかの色で 1 つずつ瞬く。その順が金庫の宝石の順（1 巡の後に少し休む） |
| 12 | 西の壁 → 金庫 | ハンドルの枠を選び、右下の穴をクリック | 宝石が押せるようになる |
| 13 | 金庫 | 宝石を星の順に押す（間違えると最初から。光った宝石が正しく押せた印） | 金庫が開く。中の**出口の鍵**を拾う |
| 14 | 南の壁 → 出口の扉 | 出口の鍵の枠を選び、扉の鍵穴をクリック | 脱出（結果画面） |

## 操作のおさらい

- ← → か A D：壁の向き直り。右クリック・Esc：一段戻る（選択を外す → 置く → 壁へ）。壁の前の Esc は一時停止（R でリセット）。
- 手に取った物：横ドラッグでヨー 45° ずつ、縦ドラッグでピッチ 90° ずつ。手がかりは、その面がこちらを向いて**正立**しているときだけ出る。
