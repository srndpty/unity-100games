# 032 振り返り

- **学び**　ローマ字の照合は、読みの各位置から打てる区切り（「ん」「っ」は次の区切りと結合した候補）を前もって並べ、打った文字と矛盾しない道筋を全て持つ非決定性の状態にすると、誤字が状態を何も変えないことを保証でき、総当たりの参照実装と受け付ける打ち方の集合で照合できる。
- **想定との差**　Button 型のアクションは前のキーを押したまま次のキーを押すと 2 打目が届かず、物理キーを PassThrough のアクションで読む必要があった。描画の書き換えを（敵の番号・打った文字数）で決めると、Backspace の後に別の綴りで同じ文字数まで打ち直したときに古い案内が残った。
- **次回**　表示の書き換えの要否は、見た目を決める状態そのものが変わったときに増える版で決め、番号を使い直す ID には試合も含める。タイトルの選択の印は、文字列に混ぜず固定幅の列に分けて置く。
- **不具合**　▶ を含めて 1 行を中央ぞろえにしていたため、難度を選び直すと難度名が左右に動いた。敵の照合器を書き換えられる型のまま公開していて、試合を通さずに打ち切れた。
