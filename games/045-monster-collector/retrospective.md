# 045 振り返り

2026-11-27、動作承認を受領。

- **学び**　技・属性・状態異常をテキストのデータにし、効果を書いた順に解決する戦闘を明示的なフェーズ機械（コマンド → 解決 → 強制交代 → 捕獲 → 終了）にすると、各フェーズで受け付けない操作の拒否が状態・乱数・ハッシュを変えないことを全てのフェーズで確かめられた。手持ちとボックスの増減の入口を `Roster` 1 つにしたので、乱択の長い通しで全局面の上限を検査できた。041・043・044 の乱数系列を `RandomSeries` に抽出してから使い、固定ハッシュが変わらないことで置き換えを確かめた。
- **想定との差**　試遊でぶつかる音が鳴りすぎ・敵が強い・戦闘の絵がずれる、と 2 回調整した。眺める自動プレイを足したら、一時停止から戻れない・クリアを記録してしまう・一時停止中の方向キーが残る、と自動プレイと人の入力の境目の不具合が続いた。レビューで、遊んだ時間を Tick の上限で切っていたこと、フォーカスを失った間の再開、最後の相手を倒したときに効果の列の残りを解決していなかったことを直した。
- **次回**　自動プレイのような「人の入力を止める」モードは、入るとき・出るとき・一時停止・フォーカス喪失・記録の書き込みの組み合わせを最初に表にしてテストする。効果の列は「相手が倒れても最後まで解決する」かを規則として先に決めて README に書く。
