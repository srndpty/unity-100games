# 045. モンスター収集RPG — THORNWILD KEEPERS（仮）

仕様書：[plan/games/045-monster-collector.md](../../plan/games/045-monster-collector.md)　実装計画：[plan/games/045-monster-collector-implementation.md](../../plan/games/045-monster-collector-implementation.md)

参考作品の名称・モンスター・技名・演出は使わないオリジナル作品。灯ノ村から茨野ノ道を進み、モンスターを捕まえて育て、道を塞ぐトレーナー 3 人に勝つと終わる。

## 環境

- Unity：6000.6.9f1
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：キーボード（Input System）

## 起動手順

```
dev gui 045      # エディタで開く
dev build 045    # Windows ビルド
dev run 045      # ビルドを起動
dev capture 045  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| キー | 操作 |
|---|---|
| 矢印 / WASD | 歩く（押し続けると歩き続ける）・メニューの項目を選ぶ |
| Z / Enter / Space | 決定・向いている相手に話しかける（トレーナー・回復所のカウンター）・文を送る |
| X / Esc / Backspace | もどる・フィールドでメニュー（てもち・ずかん） |
| P | 一時停止（決定キーでも再開）。ウィンドウのフォーカスを失うと一時停止し、押していたキーは離したものとする |

- 戦闘：たたかう（技）・こうたい・どうぐ（傷薬・捕獲玉）・にげる。受け付けない操作（トレーナー戦の捕獲玉・逃走、PP 0 の技など）は理由を出してメニューに残る。
- 出来事の文は一定の時間で進み、決定キーで送れる（出てから 6 Tick 後から）。
- **F9：眺める自動プレイ**。操縦役が人の間合い（会話を読み、戦闘の文は流し、メニューは少し間をおいて操作）で、人の 4.5 倍の速さで遊ぶ（`KeeperSettings.AutoplaySpeed`）。クリアすると結果 → タイトル → はじめからを繰り返す。自動プレイ中は人のキーを捨て、F9 と P（一時停止。P か決定で再開）だけが効く。フォーカスを失っても止めない。記録（セーブ）はしない。起動引数 `-autoplay` で最初から自動プレイにもできる。
- 回復所：カウンターの前で上を向いて決定 → 全快と補充 → 記録する・ボックス・やめる。
- てもち：決定で 1 匹を選び、もう 1 匹を選ぶと並びを入れかえる（先頭が最初に戦闘に出る）。

## 採用ルール

ルールの正はこの表。データは `Assets/Game/Data/*.txt`（属性・状態異常・技・種族・世界）にあり、Core の `MonsterData` が読み、`MonsterDataValidator` が理由付きで検証する。

| 項目 | 採用ルール |
|---|---|
| 数値 | 全て整数。倍率は百分率で、掛けるたびに 0 方向へ切り捨てる |
| 属性 | 灯・潮・苔の 3 種の三すくみ（灯→苔、苔→潮、潮→灯が 200%、逆向きと同じ属性どうしは 50%）。相性表は `Types.txt` のデータ。属性なしの技（たいあたり など）は常に 100%、一致補正もない |
| 種族 | 6 種（各属性 2 種）。種族値（HP・攻撃・防御・素早さ）・捕獲率・経験値の量・覚える技は `Species.txt`。進化・個体差はない |
| 能力 | 最大 HP = 種族値×2×Lv/100 + Lv + 10、他 = 種族値×2×Lv/100 + 5 |
| 技 | `Moves.txt`：属性・威力・命中・PP・優先度と**効果の列**（ダメージ・状態異常の付与・自分の回復・能力の段階）。効果は**書いた順に**解決する。技は 4 つまで |
| ダメージ | `((2×Lv/5+2) × 威力 × 攻撃 / 防御) / 50 + 2` → 一致補正 150% → 相性 → 乱数 85〜100% → 最低 1。攻撃・防御には能力の段階（正なら (2+s)/2 倍、負なら 2/(2−s) 倍、±3 まで）を掛ける |
| **命中** | 命中 A（1〜100）に対し、戦闘の乱数 `Next(100) < A` なら当たる。**命中 100 の技でも乱数を 1 回引く**（技によって乱数の使用回数を変えない）。外れたら効果の列の残りは全て起きない |
| **状態異常** | `Statuses.txt` のデータ。**毒**：ターンの終わりに最大 HP の 1/8（最低 1）を失う、持続 4 ターン。**眠り**：動けない、持続 2〜3 ターン。**持続は付与したときに乱数で決め、「付与したターン + 持続」を解除予定のターンとして持ち、そのターンの開始で治る**（そのターンから動ける）。控えにいても予定のターンに治る。状態異常の上に重ねられない（状態異常だけの技なら「効かなかった」）。戦闘が終わると治る |
| 行動順 | 交代・道具・逃走 → 技。技どうしは優先度 → 素早さ（段階込み）→ 同じなら戦闘の乱数で 1 回の抽選 |
| 戦闘のフェーズ | コマンド選択 → 解決（1 回のコマンドでターンの終わりまで進む）→ 味方が倒れたら**交代先の選択**（ターンを消費せず、相手は動かない）→ 終了（勝利・敗北・逃走・捕獲）。各フェーズで受け付けない操作は理由付きで拒否し、**状態・乱数・出来事を何も変えない** |
| 交代 | 自分の番の交代は 1 ターン使い、相手の技は交代先が受ける。交代で能力の段階は戻る。トレーナーは倒れたら次を番号順にターンの終わりに出す |
| わるあがき | PP が全て 0 のときは わるあがき（属性なし・威力 40・PP を減らさない） |
| **捕獲** | 野生のみ（トレーナー戦では拒否）。捕獲値 = 捕獲率 × (3×最大HP − 2×HP) / (3×最大HP) × 状態異常の補正（眠り 200%・毒 150%）、上限 255。`Next(256) < 捕獲値` か 255 なら成功。失敗したら相手の番。捕獲玉が 0、または手持ちもボックスも満杯なら投げられない（玉も減らない） |
| 逃走 | 野生のみ。逃走値 = 自分の素早さ × 128 / 相手の素早さ + 30 × 失敗した回数、`Next(256) <` 逃走値 か 256 以上で成功 |
| 傷薬 | 手持ちの 1 匹の HP を 20 まで回復（足りない分だけ）。倒れた個体・満タンには使えない |
| **育成** | 倒した相手の経験値 = 経験値の量 × 相手の Lv / 5（トレーナー戦は 150%）を、その相手と戦った（場に出た）生存者で等分（切り捨て、最低 1）。レベル L に必要な累計経験値は L³/2、上限 Lv 20。上がった最大 HP の分だけ HP も増える。覚える技は空き枠へ、4 つ埋まっていれば戦闘の後に入れ替えるか覚えないかを選ぶ |
| CPU | 野生は PP のある技を等確率。トレーナーは 20% で無作為、それ以外は「威力 × 相性 × 一致補正 × 命中」などの点が最も高い技（状態異常の相手に状態異常の技は使わない） |
| 敗北 | 自分の残りがいなければ敗北（相手も同時に全滅していても） |
| 乱数 | `RandomSeries.Derive(試合シード, 番号, 用途)` で場面ごとに系列を分ける：遭遇（番号 0）、戦闘（番号は戦闘番号）。1 試合 = 1 シード、再戦は新しいシード |

### 手持ち・フィールド・セーブ

| 項目 | 採用ルール |
|---|---|
| **手持ちとボックス** | 手持ちは**最大 6 匹**。捕まえたとき手持ちが 6 匹ならボックス（最大 30 匹）へ送る。ボックスも満杯なら捕獲玉を投げられない。回復所のボックスで預ける・引き出す。手持ちを 0 匹、または戦える個体のいない手持ちにはできない。ボックスに入った個体は全快する。出し入れは `Roster` のメソッドだけが行う |
| 開始 | 3 匹（灯・潮・苔から 1 匹ずつ）から相棒を選ぶ（Lv 5）。捕獲玉 5・傷薬 3 |
| フィールド | 1 マス = 8 Tick で歩く。歩いている間に押した方向は 1 つだけ先行入力。灯ノ村（回復所）と茨野ノ道（草むら 3 か所・トレーナー 3 人） |
| 遭遇 | 草むらのマスに歩き終えたとき、草むらの文字ごとの遭遇率（15%）で出会う。出現表（種族・Lv の範囲・重み）は `World.txt`。遭遇の直後と地図を移った直後の 3 歩は出会わない |
| トレーナー | 道の 1 マスの切れ目に立って道を塞ぐ。向かい合って決定キーで話しかけると戦闘。勝つといなくなって通れ、もう戦わない。3 人目に勝つとクリア |
| 回復所 | カウンターに向かって決定キー：手持ちの HP・PP・状態異常を全快し、捕獲玉と傷薬を初期の数まで補う。続けて「記録する」「ボックス」が使える |
| 全滅 | 回復所の前へ戻って全快する。捕まえた個体・経験値・倒したトレーナー・道具は残る |
| 技を覚える | 戦闘で 4 つ埋まっていて覚えられなかった技は、戦闘の後に「忘れる技」か「覚えない」を選ぶ |
| **セーブ** | **回復所の前でだけ、1 枠**。行指向のテキスト（`key=value` を決まった順、最後に本文のチェックサム）。中身：版・データの指紋・シード・戦闘番号・遊んだ Tick・勝ち負け・位置・歩数・遭遇の乱数の状態・倒したトレーナー・図鑑・道具・手持ち・ボックス。読み込みは**切れた・壊れた（チェックサム）・版違い・データの指紋違い・値域外（手持ち 0 や 7 以上・ボックス 31 以上・知らない種族や技・PP や HP の範囲外など）**を理由付きで拒否し、タイトルに「セーブデータを読み込めません（理由）」と出してつづきからを出さない（移行はしない。ファイルは消さず、次の記録で上書き）。書き込みは一時ファイルからの原子的な置き換え（041 の `FileSaveStore`）。読み書きの失敗は例外にせず案内に変える |
| 記録 | クリアしたら `records.txt` に最短クリア時間・最多の捕まえた種類数・クリア回数を残す（良くなった値だけ置き換え）。結果画面とタイトルに出す |
| 再戦 | 結果画面からタイトルへ戻り、はじめからは新しいシード |

### 野生の戦闘の乱数の順（味方が先に動くとき）

相手の技の抽選 `Next(PP のある技の数)` → 味方の命中 `Next(100)` → 味方のダメージの乱数 `Range(85, 100)` → 状態異常の判定 `Next(100)`・持続 `Range(最短, 最長)` → 相手の命中 → …。テスト（`TypeAndAccuracyTests`）はこの順で命中の境界を決まった値で確かめる。

## 設計上の選択

- **データ駆動（中心課題）**：属性・相性表・状態異常・技（効果の列）・種族・地図・草むら・トレーナー・規則は `Assets/Game/Data/*.txt`。Core の `MonsterData` が読み、書式の誤りは `FormatException`、規則上の誤りは `MonsterDataValidator` が理由を並べて拒否する。技の効果は `EffectKind` の列で、解決は書いた順。状態異常は「行動不能か・ターンの終わりのダメージ・持続の範囲・捕獲の補正」の 4 つの値だけで振る舞いが決まる。
- **フェーズの管理（重点）**：戦闘は `Battle` のフェーズ（コマンド選択・強制交代・終了）、冒険は `World` の場面（最初の 1 匹・フィールド・戦闘・技を覚える・クリア）、画面は App の `KeeperFlow`（タイトル・フィールド・メニュー・回復所・ボックス・戦闘・結果）。捕獲は戦闘のコマンドの 1 つで、捕まえた個体の行き先（手持ち・ボックス）は戦闘を書き戻すとき `World.FinishBattle` が決める。
- **Core**：`MonsterData`・`Monster`・`Formula`・`Battle`（解決と出来事 `BattleEvent`）・`TrainerAi`・`Roster`・`Explorer`・`World`・`SaveCodec`・`Records`・`Fingerprint`。整数と Tick だけで書き、乱数は `RandomSeries`（int-geometry）、ハッシュは `StateHash`（tile-motion）。
- **App**：`KeeperFlow`（意図 → メニュー → Core のコマンド、会話、一時停止）、`BattlePresenter`（出来事の列を Tick で見せる。状態は Core が先に決めていて、演出はそれを見せるだけ）、`Autopilot`（Flow にキーだけを送る操縦役）、`ISaveStore`。
- 戦闘の手持ちは始めに複製し、終わったら書き戻す。戦闘中の世界は `World.Battle` だけが変わる。
- 読み取りだけを見せる：`Monster` などの状態を変える操作は `internal` で、Unity と操縦役は公開の読み取りだけを使う。

- **Unity**：`KeeperGame`（物理キーごとの意図・Flow の駆動・同期）、`KeeperHud`（UI Toolkit をコードで組む）、`KeeperMapStage`（Tilemap の地図 Prefab、データとマスの種類・トレーナーの位置まで照合）、`KeeperBattleStage`、`KeeperAudio`、`FileSaveStore`（セーブと記録の 2 ファイル、原子的な置き換え）、`KeeperCaptureScenario`。シーンと Prefab と絵は `Editor/KeeperSceneBuilder`・`KeeperArtGenerator` で作る（`unity run games/045-monster-collector -- -executeMethod Game.Unity.Editor.KeeperSceneBuilder.Build`）。
- 操縦役は「トレーナーの番号 = 草むらの文字の番号」（1 人目の手前は `"`、2 人目は `;`、3 人目は `:`）を前提に鍛える場所を選ぶ。地図を変えたら操縦役も見直す。

## 試遊で見てほしい点

- メニューの操作の感触（決定・もどる・文送りの速さ、技・交代・どうぐの階層）
- 遭遇率（15%）と、草むらを避けて道だけを歩けること
- 捕まえやすさ（捕獲率・弱らせ方・眠りの効き）と、手持ち 6 匹を超えてボックスへ送る流れ
- レベル上げの量（L³/2）とトレーナー 3 人の強さ（Lv 5〜6 / 8〜9 / 11〜12。初回の試遊で「強すぎる」とされ 2 ずつ下げた）
- 相性の分かりやすさ（技の一覧に属性を出し、相性の結果は「ばつぐん」「いまひとつ」の文で出す）
- 音量
