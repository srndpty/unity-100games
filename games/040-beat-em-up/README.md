## 操作

| キー | 操作 |
| --- | --- |
| 矢印 / WASD | 移動（上下で奥と手前） |
| J | 攻撃（ヒットすると 3 段まで繋がる）。空中で跳び蹴り。掴み中は膝、3 回目か左右＋J で投げ |
| K | ジャンプ |
| L | 緊急技（体力を払って周りを吹き飛ばす） |
| 敵へ歩いて触れる | 掴み |
| Esc | 一時停止 |
| F1 | 判定箱と奥行きの帯の表示 |

## 採用ルール

| 項目 | 採用ルール |
| --- | --- |
| 時間 | 60 Tick/秒。座標は整数で 1 px = 256 |
| 座標 | x は横（面の進行）、z は奥行き（0 が手前、帯 `[ZMin, ZMax]`）、y は高さ。画面の縦位置 = z × DepthNum / DepthDen ＋ y（既定 1/2） |
| 描画順 | z の大きい（奥の）順に描き、同じ z は出現番号の小さい順。高さは順に影響しない。順序は Core の `Depth.DrawOrder` が決め、描画はそれを写すだけ |
| 判定箱 | 横・高さの矩形と奥行きの半幅の 3 軸。攻撃箱と喰らい箱は 3 軸すべてが重なったときだけ当たる。端がちょうど接するだけ（奥行きなら z の差が半幅の和ちょうど）では当たらない。掴み・押し合いも奥行きを見る |
| コンボ | 攻撃でジャブ。ヒットした技の硬直の始めから受付窓の間に攻撃が押されていれば次段へ。空振りは繋がらず、硬直が解けてから 1 段目。3 段目（アッパー）はダウンを奪う。押下は先行入力として `BufferTicks` Tick 保持 |
| 掴み | 地上を敵の方へ歩いて押し合いで触れ（横の余裕 `GrabReach`）、奥行きの差が `GrabDepth` 以内、敵が立ち・歩き・怯み中なら掴む。攻撃・ダウン・起き上がり・空中の敵は掴めない。掴み中の攻撃は膝（`MaxKnees` 回まで）、その後か左右＋攻撃で投げ。`GrabTicks` で離す |
| ジャンプ攻撃 | 空中で攻撃。着地まで 1 回。奥行きは跳んだときのまま |
| 緊急技 | 体力 `cost` を払い、左右と奥行きの周りを吹き飛ばす。出してから `invuln` Tick（発生と持続を含む）は無敵。体力が代償以下なら出ない。立ち・歩き・攻撃中・怯み中・掴み中から出せる |
| ヒット | 攻撃箱が喰らい箱に重なった Tick に成立。同じ技の発動 1 回につき 1 体に 1 ヒット（複数の敵には各 1 回）。同じ Tick の攻撃は全組を集めてから同時に適用する（相打ちあり） |
| 怯み | 技の怯み（Stagger）が相手の Poise 以上なら怯む。未満ならダメージだけで動きは止まらない（大男・ボスはジャブで怯まない） |
| ダウン | ダウン技・体力 0・空中で受けた打撃で吹き飛ぶ。倒れ・起き上がりの間は喰らい箱が無く、起き上がり後 `WakeupInvuln` Tick は無敵。体力 0 の敵は倒れた後に消え、以後は攻撃も攻撃権の要求もしない |
| ヒットストップ | 当てた側と当たった側だけが止まる。他の敵は動き続ける。止まりの間も先行入力は減らない |
| 残機 | `Lives`（既定 3）。体力 0 で倒れ、その場で全快・`RespawnInvuln` Tick の無敵で復帰。残機 0 で敗北。終わった後の入力は状態を変えない |
| 得点 | プレイヤーの与えたダメージ ＋ 撃破ごとの点（撃破は体力が 0 になった 1 回だけ数える） |
| 1 Tick の順 | 入力 → 出現 → 攻撃権 → 各登場者の状態 → 押し合いと端 → 掴み → 攻撃（同時適用） → 死亡・区画・面 |
