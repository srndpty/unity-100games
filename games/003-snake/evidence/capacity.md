# 003 Snake 最大盤面の負荷計測

## サポート範囲と判断

幅4〜32、高さ2〜20、最大640マスをサポートする。既定の20×16は変更していない。体節ごとのSpriteRendererを維持し、65,536マスへの最適化は行わない。餌配置の走査も最大640セルに制限される。

## 測定条件

- 日付：2026-11-16。Unity 6000.6.9f1、Windows 11、バッチPlayModeの実シーン。
- CPU：Intel Core i9-13900KF。GPU：NVIDIA GeForce RTX 4090。エディタのGameView：640×480。
- 盤面：32×20、初期長3、固定シード1。Appの巡回操縦で637個取得、101,517 Tickで全面クリア。
- シーンの設定・UXML・URPアセットは読み込み済み。計測用の新しいゲームルートを作り、通常のAwakeとRenderを実行する。
- `MaximumBoard_CreatesGrowsAndRendersWithinBudget` のStopwatchによるCPU経過時間。単位はms。

## 結果

| 項目 | 実測 | 測定方法・予算 |
|---|---:|---|
| 初期生成 | 4.714 ms | ゲームルート・コンポーネント・実行時素材・初期体節生成と初回描画。1,000ms未満 |
| 全面成長 | 100.163 ms | Coreの全Tickと、成長637回ごとの体節追加・描画更新を含む。5,000ms未満 |
| 満杯時のCPU描画更新 p50 / p95 | 0.158 / 0.175 ms | 30回ウォームアップ後のRender 300回。p95が16.667ms未満 |
| バッチ実フレーム間隔 p50 / p95 | 0.565 / 1.415 ms | 30フレームウォームアップ後、120フレーム。参考値として記録 |
| SpriteRenderer数 | 642 | 体節640＋盤面1＋餌1（クリア時は非表示）。厳密一致を検査 |
| ゲームルート内のGameObject数 | 643 | 上記642個＋ルート1。厳密一致を検査 |

満杯時のCPU描画更新のサンプルは、体節640個のTransform・色・表示状態の更新、カメラ・餌・HUDの更新を含む。実フレーム間隔はUnityの描画登録を通した参考測定だが、GPU実行時間を直接測ったものではない。

この結果は対象機・バッチエディタ・上記解像度での測定であり、他のPCやWindowsプレイヤーのFPS・GPU時間は保証しない。絶対時間の予算はこの検証環境での回帰検知用で、全環境共通の性能契約ではない。盤面上限と生成物数は環境に依存せず制限する。Windowsプレイヤーの既定1280×720での起動・描画は別途 `dev capture 003` で確認する。

## 再実行

```text
dev test 003 -Unity -Mode PlayMode
```

詳細値は `Logs/test-results-PlayMode.xml` の当該テストのoutputに出る。設定上限の境界（32×20は合法、幅33・高さ21・256×256は不正）はCoreテストで検証する。
