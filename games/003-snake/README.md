# 003. Snake

仕様書：[plan/games/003-snake.md](../../plan/games/003-snake.md)

格子の中で蛇を動かし、餌を取って伸ばす。壁や胴体にぶつかると敗北、盤面をすべて埋めるとクリア。

## 環境・起動

- Unity：6000.6.9f1（Universal 2D）、C# 9.0
- 対象：Windows / StandaloneWindows64
- 入力：Input System のボタンアクション。方向の押下イベントを発生順に受け付ける

```text
dev gui 003      # Assets/Scenes/Snake.unity を開く
dev build 003    # Windows ビルド
dev run 003      # 人間によるプレイ確認
dev capture 003  # 固定シード・Tick 駆動で撮影し、自動終了
```

## 操作

| 操作 | キー・ボタン |
|---|---|
| 方向転換 | 矢印キー / WASD |
| 開始・結果から再戦 | Enter / Space、START / PLAY AGAIN |
| 一時停止・再開 | P / Esc、停止中の RESUME |
| タイトルへ戻る | 停止・結果画面の TITLE |
| 終了 | タイトルの QUIT、ウィンドウを閉じる |

方向入力は押した瞬間だけ受け付ける。長押しによる繰り返しはない。ウィンドウからフォーカスが外れると一時停止する。

## 採用ルール

| 項目 | 内容 |
|---|---|
| 盤面 | 20列 × 16行。境界を越えると敗北。反対側にはつながらない |
| 初期配置 | 頭は `(幅 / 2, 高さ / 2)`、長さ3で左に伸び、右向き。座標の原点は左下 |
| 時間 | 毎秒8 Tick、1 Tick に1マス。加速なし。開始から最初の1 Tick分の時間が経過して動く |
| 餌 | 空きマスに1個。取得で長さ・得点がそれぞれ1増える |
| 方向入力 | 最大2手を予約し、1 Tick に1手を消費。最後の予約方向（なければ現在方向）と同じ方向・逆方向は無視。予約が満杯なら追加を無視 |
| 自己衝突 | 移動先が胴体なら敗北。ただし、その Tick に空く末尾のマスには入れる |
| 敗北 | 衝突する移動は胴体へ反映しない。結果画面では時間・移動・方向入力が進まない |
| 勝利 | 最後の空きマスの餌を取った時点でクリア。餌は消え、既定設定の最終得点は317 |
| 一時停止 | 方向予約と端数時間を捨てる。再開後、1 Tick 分の時間が経過してから移動 |
| 再戦 | 初期配置・得点・入力・端数時間をリセット。試合ごとに新しいシードを使用 |
| 処理落ち | 1フレーム最大5 Tick。超過した整数 Tick 分は捨て、端数だけ保持 |

設定は [SnakeSettings.asset](Assets/Game/Unity/SnakeSettings.asset) の盤面幅・高さ・初期長・速度・音量で調整する。幅4以上、高さ2以上、面積65,536以下、初期長2〜`幅 / 2 + 1`、速度は正の有限値で毎秒60以下、音量は0〜1の有限値を要求する。速度は1試合を通して一定。

## 設計

| 層 | 主な型 | 責務 |
|---|---|---|
| Core | `Cell`、`SnakeConfig`、`SnakeState` | 整数格子、固定容量リングバッファと占有配列、移動・成長・衝突・餌・勝敗。Unity非依存 |
| App | `SnakeFlow`、`Autopilot` | 画面遷移、2手先行入力、実時間から固定Tickへの変換。撮影・テスト用の操縦役。Unity非依存 |
| Unity | `SnakeGame`、`SnakeSettings`、`SnakeCaptureScenario` | 入力イベント、スプライト・カメラ・HUD・音、設定アセット、撮影台本 |

| 状態 | 遷移 |
|---|---|
| タイトル | 決定で新しい試合を開始 |
| プレイ | 停止操作・フォーカス喪失で一時停止、衝突・全面制覇で結果 |
| 一時停止 | 停止操作でプレイへ再開、TITLEでタイトル |
| 結果 | 決定で独立した試合へ再戦、TITLEでタイトル |

- **リングバッファ**：頭・末尾の更新と占有判定は定数時間。餌はxorshiftで空きマスの番号を選び、左下から行優先で走査して配置する。再抽選ループは使わない。
- **再現性**：1試合＝1シード。同じ設定・シード・Tickごとの方向列で再現できる。時刻やUnity物理はCoreへ入れない。物理エンジンに委譲する処理はない。
- **表示**：格子の現在状態をそのまま描き、補間しない。16:9基準の横長画面で盤面とHUDを表示する。音は控えめで、バッチテスト・撮影では `AudioPolicy` により消音。生成した画像・スプライト・音はシーン破棄時に破棄する。
- **シーン生成**：[SnakeSceneBuilder](Assets/Game/Unity/Editor/SnakeSceneBuilder.cs) が正。`unity run games/003-snake -- -executeMethod Game.Unity.Editor.SnakeSceneBuilder.Build` で再生成する。
- **証跡**：雛形の公開機構を利用する。操縦役は偶数列の盤面を巡回して成長・クリアまで進め、最後に再戦して壁衝突を撮る。既定盤面では最悪でも110,000 Tick以内に終わる。奇数列でも人間のプレイは可能だが、この操縦役による撮影は偶数列を要求する。
