# 021 振り返り

## 新たに学んだ点

物理エンジンを使わず、1 タイル = 256 単位の整数で横 → 縦の順に 1 軸ずつ解決すると、接地・天井・壁の判定が地形だけで決まり、盤面ハッシュが Mono と .NET で一致した。接地（`GroundProbe`）と敵の接触（`EnemyContact`）を別の関数にしたので、踏みつけと横衝突の区別を地形と無関係にテストできた。

踏みつけか横衝突かは、Tick の終わりの重なりでなく、敵から見た相対軌跡を掃引して最初に触れた面で決めた。敵が下から跳ね上がる場合や斜めのかすりも同じ規則で扱えた。自動操縦は `LevelRun.Clone()` で数通りの操作を先読みする方式にし、面の作りに合わせた調整なしで 3 面を完走した。

## 想定との差

タイトルの初期表示は「姿と表示の有無」だけを戻していて、遊んだ後にタイトルへ戻ると自機と敵が前の試合の位置で残ることをレビューで指摘された。撮影台本もテストもタイトルを最初の 1 回しか描いていなかった。Core の地図の開始位置・出現位置から表示を作り直すよう直した。

面は自動操縦で 10〜14 秒と、想定より短かった。

## 次回の改善点

「試合の前の表示」を持つ作品は、遊んだ後にタイトルへ戻った表示が起動直後と一致することを最初からテストする。描画の初期状態は Prefab の現在値に頼らず、Core のデータから作り直す。
