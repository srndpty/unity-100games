# 021. マリオ型2Dアクション — BRAMBLE DASH

仕様書：[plan/games/021-platformer-2d.md](../../plan/games/021-platformer-2d.md)

茨の野を駆けて旗の柱を目指す横スクロールアクション。走る・跳ぶ・踏むの 3 つで 3 面を抜ける。参考作品からはメカニクスだけを採用し、名称と見た目は独自に作っている。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード。HUD は PanelRenderer / UI Toolkit

## 起動手順

```
dev gui 021      # エディタで開く
dev build 021    # Windows ビルド
dev run 021      # ビルドを起動
dev capture 021  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| 入力 | タイトル | プレイ中 | 一時停止 | 結果 |
|---|---|---|---|---|
| ← → / A D | — | 歩く（押している間） | — | — |
| Shift / X | — | 走る（押している間） | — | — |
| Space / Z / ↑ / W | — | 跳ぶ（押す長さで高さが変わる） | — | — |
| Enter | はじめる | — | つづける | もう一度 |
| Esc / P | — | 一時停止 | つづける | — |
| R | — | — | 1 面から | 1 面から |
| T | — | — | タイトルへ | タイトルへ |

左右を両方押しているときは、後から押したほうに進む。一時停止・タイトル・結果・フォーカスの喪失で、押しているキーはいったん離したものとして扱う（押し直すまで動かない）。面の合間（クリア・ミスの直後）は押しているキーをそのまま次の面へ持ち越す。

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 単位 | 1 タイル = 16 px = 256 単位の整数。速度は単位/Tick。60 Tick/秒。浮動小数点を使わないので Mono と .NET で同じ結果になる |
| 地形 | タイルは空・固体・ゴール（旗の柱）の 3 種。面の左右の外は壁、上と下の外は空。下の外へ落ちたら穴 |
| 自機 | 12×14 px の箱。地形・敵とはこの箱で判定する |
| 横移動 | 左右で加速（接地中 2、空中 1）。歩きの最高速 24、走りキーで 40。入力がなければ接地中だけ摩擦で減速（空中は勢いを保つ）。接地中に反対へ入力すると強めに減速（4）してから向きを変える。走りをやめて最高速を超えていれば少しずつ落とす |
| ジャンプ | **接地中に、ジャンプキーを押し始めた Tick だけ**跳ぶ（上向き 96）。空中では何度押しても跳ばない。押したまま着地しても再ジャンプしない（一度離す）。面の開始時に押したままでも跳ばない |
| 可変ジャンプ | 上昇中にキーを離すと、上向きの速さを 32 まで切る。押し続けると約 4.3 タイル、すぐ離すと約 1 タイル |
| 重力 | 1 Tick に 4。落下の最高速 112（1 タイル未満。上限は設定の検証で保証） |
| 衝突解決 | 横 → 縦の順に 1 軸ずつ動かし、進む先の列（行）を近い順に調べて、最初の固体の手前で止める。移動量がタイルより大きくても途中を飛ばさない。壁に当たれば横の速さ 0、天井・床に当たれば縦の速さ 0 |
| 接地検出 | 縦の解決の後、足元の 1 単位下に固体があり、上向きに動いていなければ接地。床にちょうど接しているときだけで、敵の上には立たない |
| 敵 | 歩き虫（左右に歩き、壁で引き返し、崖から落ちる。踏める）、跳ね虫（その場で 80 Tick ごとに跳ねる。踏める）、茨玉（左右に歩き、壁と崖で引き返す。**踏めない**）。最初は左を向く。敵どうしは触れ合わない |
| 敵の起動 | 自機から 18 タイル以内に入ったら動き出し、以後は止まらない。カメラには依存しない |
| 接触判定 | Tick の中で自機と敵はそれぞれ直線で動くとみなし、敵から見た自機の相対軌跡を掃引して、最初に重なり始める時刻と面を求める。最初に触れた面が敵の上面で、自機が相対的に下へ動いていれば踏みつけ、それ以外は横衝突。縦と横が同時に触れた（角にちょうど当たった）ときは縦を優先する。辺が接するだけでは触れていない。Tick の始めから重なっていれば横衝突 |
| 複数の敵 | 最初に触れた時刻の接触だけを扱う。その時刻に横衝突（茨玉を含む）が 1 つでもあればミス、踏みつけだけなら全て倒す。それより後の接触は、跳ね返りで軌跡が変わるので捨てる（まだ重なっていれば次の Tick で判定する） |
| 踏みつけ | 敵を倒し、自機は上向き 56 で跳ね返る（ジャンプキーを押していれば 96）。跳ね返りは空中ジャンプにはならない。1 体 100 点 |
| ミス | 横衝突・茨玉への接触・穴・時間切れ（1 面 150 秒）。残機 −1 で、その面の最初からやり直す。踏みつけの得点は残る |
| ゴール | 旗の柱に自機が重なった Tick に面クリア。その Tick に敵は動かない（ゴールが優先）。以後の Tick・入力では状態を変えず、2 回目のクリアは起きない。残り時間 1 秒あたり 10 点 |
| 勝敗 | 3 面をクリアすれば勝利、残機 0（既定 3）で敗北。最高スコアは起動中だけ保持する |
| 1 Tick の順序 | 自機の移動（横 → 縦 → 接地）→ ゴール判定 → 敵の移動 → 接触判定 → 穴 → 時間切れ |
| 面の合間 | クリア・ミスの後、1.5 秒（設定）の間を置いて次の面かやり直しへ進む。フォーカスがない間は時間を数えない |
| 終了後の操作 | 面・試合の終了後の Tick と入力は受け付けず、状態を変えない |
| 乱数 | 使わない。面と入力の列だけで結果が決まる |
| カメラ | 横だけ追う。中央の遊び（左右 1.5 タイル、設定）を出たぶんだけ追い、面の左右の端で止める。左にも戻る |

## 設計上の選択

| 層 | 責務 |
|---|---|
| Core | `Box`・`Units`（整数の箱と単位）、`TileMap`（地形）、`Level`・`Levels`（文字の地図と 3 面）、`BodyMotion`（地形との衝突解決）、`GroundProbe`（接地検出）、`Player`（速度ベースの制御）、`Enemy`（3 種の敵）、`EnemyContact`（踏みつけ・横衝突の判定）、`LevelRun`（1 面の挑戦）、`Campaign`（3 面・残機・スコア）、`PlatformerConfig`（設定） |
| App | `PlatformerFlow`（画面遷移・実時間から Tick への変換）、`Intent`・`HeldControls`（入力の列と Tick ごとの入力）、`CameraFollow`（カメラの位置）、`Autopilot`（撮影・テスト用の操縦役） |
| Unity | `BrambleDashGame`（入力・カメラ・HUD・音）、`BrambleDashStage`（1 面の描画：Tilemap・自機・敵）、`BrambleDashSettings`（設定アセット）、`BrambleDashArtGenerator`・`BrambleDashSceneBuilder`（素材・Stage Prefab・シーンの生成）、`BrambleDashCaptureScenario`（撮影台本） |

- **物理エンジンには何も委譲していない。** 移動・衝突・接地・接触は Core の整数演算で、Rigidbody2D や Collider2D は使わない。
- **接地検出と敵の接触判定を分けた。** 接地は地形だけを見る `GroundProbe`、敵との接触は自機と敵の Tick 中の位置だけを見る純粋関数 `EnemyContact`。踏みつけの跳ね返りは接地とは無関係なので、敵の上で「接地してジャンプ」はできない。
- **接触は相対軌跡の掃引で判定する。** Tick の終わりの重なりだけで判定すると、速く落ちたときに横から触れたのか上から触れたのかが分からず、斜めに角をかすめた接触も見逃す。時刻は分数のまま比べる。
- **ジャンプの押し始めは Core が見分ける。** 入力は押している状態で渡し、前の Tick との差で押し始めを判定する。App はキーを押して離すまでが 1 Tick より短くても、1 Tick は押したことにして渡す。
- **3 面は Core の地図から作った Stage Prefab。** 生成スクリプトが Tilemap（地面・旗の柱）、旗、敵（地図の出現順）、自機を置いた Prefab を面ごとに作るので、プレイ前から Scene ビューで見える。既にある Prefab は上書きせず、地形と敵の数が Core の地図と違えば生成を止める（PlayMode テストでも照合する）。タイトルでは Core の地図の開始位置・出現位置から自機と敵の表示を作り直すので、遊んだ後に戻っても前の試合の位置や倒された敵は残らない。シーンには 3 面を置き、今の面だけを表示する。
- **素材はドット絵を生成する。** 1 タイル = 32 ピクセル、Point フィルタ。キャラクターは体の箱の下端の中央を基準点にして、Tick の状態をそのまま描く（補間しない）。
- **カメラは描画だけに使う。** `CameraFollow` の位置をカメラに写すだけで、敵の起動も接触も自機からの距離で決まる。
- **自動操縦は先読みで選ぶ。** 接地したとき、7 通りの操作（右・止まる・左 × 跳ばない・跳ぶ）を `LevelRun.Clone()` の複製で 120 Tick 先読みし、ミスしないもののうちゴールに着く・右へ進むものを選ぶ。既定の設定で 3 面ともミスなしでクリアする（594・759・824 Tick）。

## 未実装範囲
