## 操作

| 入力 | 動き |
|---|---|
| ↑↓＋Enter・クリック | 行動・選択肢・メニューを選ぶ |
| Enter・Space・↓・クリック | 会話を送る（表示の途中なら全文を出す） |
| Tab | 能力値の詳細を開く・閉じる |
| Esc | 一時停止（つづける・タイトルへ）。一時停止の中では戻る。ウィンドウのフォーカスを失っても一時停止になり、戻ったら「つづける」で再開する |

- 画面の流れ：タイトル（はじめから・つづきから・操作説明・終了）→ 朝（行動を選ぶ）→ 結果（段階と増減）→ イベント（会話・選択肢）→ … → 30 日目の夜の後に ED → 結果画面 → タイトル。再戦は新しいシード。

## 採用ルール

舞台は地方の高校の夏休みの天文部（オリジナル）。攻略対象は天文部の先輩と、図書室の同級生の 2 人。30 日を 1 日 1 行動で過ごし、最終日の流星群の夜の後に ED が決まる。台本（行動・イベント・ED の数値と会話）は `Assets/Game/Data/` の DSL で書く（下の「DSL」）。

### 1 日の流れ

| 段 | 内容 |
|---|---|
| 朝 | 日の始めに自動セーブ（1 枠）。この時点の状態だけを保存する |
| 行動 | 行動から 1 つ選ぶ。曜日で選べない行動がある（`week`）。強制の条件（`@forced`）が成り立つ朝は、その行動しか選べない |
| 結果 | 結果の段階（大成功・成功・失敗など）を重みで引き、行動の効果を当てる。効果の幅（`a..b`）は効果ごとに引く。増やす効果には段階の倍率（%）を掛ける（ただし費用の能力値＝疲労には掛けない）。減らす効果には掛けない |
| イベント | 枠「行動の後」→「夜」の順に、枠ごとに高々 1 本を選んで出す。会話を送り、選択肢があれば選ぶ（効果が当たる） |
| 最終日の後 | ED の判定（下の「エンディング」） |

### 能力値・フラグ

| 項目 | 採用ルール |
|---|---|
| 能力値 | 宣言した範囲（最小・最大）と初期値を持つ整数。好感度は攻略対象ごとの能力値（`@heart`）。疲労のような費用の能力値（`cost`）には段階の倍率を掛けない |
| 範囲 | 効果を当てるたびに宣言の範囲で飽和させる。実行時の飽和と、コンパイル時の区間の検証（下の「検証」）の両方で範囲外に出ないことを保証する |
| フラグ | 真偽。初期値は偽。`set`・`clear` で変える |

### イベントの選び方（優先順位と乱数の固定）

| 項目 | 採用ルール |
|---|---|
| 候補 | その枠で、期間（日の範囲・曜日）に入り、1 回だけ（`once`）なら未消化で、今日出たイベントと排他でなく、条件が成り立つもの |
| 順序 | 優先度の高い順、同じ優先度なら定義の順。先頭から順に確率（%）を引き、最初に当たった 1 本を出す。確率 100 は引かない（乱数を消費しない） |
| 同日排他 | 1 つの枠に出るのは高々 1 本（1 日に最大 2 本）。`@exclusive a b` の組は枠が違っても同じ日に出さない（先に選ばれた方が勝つ） |
| 条件の時点 | 「行動の後」の条件は行動の効果の後、「夜」の条件は行動の後のイベント（と選択）の後の状態で評価する。`action` は今日選んだ行動 |
| 乱数 | 用途ごとに別の系列：試合のシード・日・用途（1：行動の結果、2：イベントの確率）から派生する。行動の結果で引く回数が変わっても、イベントの抽選は変わらない。同じシードと同じ行動・選択の列なら、同じイベントの列になる |

### エンディング

| 項目 | 採用ルール |
|---|---|
| 判定 | 最終日の夜の後に、優先度の高い順に条件を見て、最初に成り立つ ED。最後は条件なしの既定の ED（`default`、ちょうど 1 つ） |
| 優先度 | 条件のある ED は優先度が必須で、同じ値を拒否する（両方成り立つときにどちらが先か決まらないため） |

### 命令と拒否

| 命令 | 受け付ける段 | 拒否 |
|---|---|---|
| 行動を選ぶ | 朝 | 範囲外の番号（OutOfRange）・朝でない（NotNow）・曜日や強制で選べない（Unavailable）・終わった後（Ended） |
| 送る | 選択肢のない会話 | 選択肢のある会話・朝（NotNow） |
| 選ぶ | 選択肢のある会話 | 範囲外の番号（OutOfRange）・それ以外の段（NotNow） |

- 拒否は状態・ハッシュ・出来事を何も変えない。

### 台本（`Assets/Game/Data/Summer.txt`）

| 項目 | 内容 |
|---|---|
| 能力値 | 学力・体力・感性（0〜100、初期 10）、疲労（0〜100、費用）、お金（0〜9999、初期 200）、好感度 2 人（0〜100） |
| 行動 7 | 勉強（学力）・運動（体力）・創作（感性）・バイト（お金、日曜は休み）・休む（疲労 −40）・天文部へ（澄の好感度 4〜6・感性）・図書室へ（栞の好感度 4〜6・学力、日曜は閉まる）。休む以外は疲労が増える |

### セーブ（日の始めに 1 枠）

| 項目 | 採用ルール |
|---|---|
| 書く時点 | 毎朝（行動を選ぶ前）に自動で上書きする。ED に着いたら消す |
| 中身 | シード・日・能力値・フラグ・1 回だけのイベントの済み・記録（ID で書く）・台本の指紋。行指向テキスト（key=value）・版番号・末尾のチェックサム |
| 読み込み | タイトルの「つづきから」。切れた・改変・版違い・指紋違い・キーの過不足・範囲外の値・記録の不整合は理由付きで拒否し、タイトルに理由を出す（移行はしない） |
| 失敗 | 読み書き・消去の失敗は例外にせず案内に変え、遊び続けられる。書き込みは一時ファイルから原子的に置き換える |

## DSL

1 行 1 文。行頭（または空白の後）の `#` から行末はコメント（`@char` の色 `#rrggbb` は除く）。ID は英小文字・数字・`_`。能力値・フラグ・人物の ID は同じ名前空間で、`day`・`weekday`・`action`・`and`・`or`・`not`・`set`・`clear`・曜日（`mon`〜`sun`）は予約語。

| 文 | 例 | 意味 |
|---|---|---|
| 暦 | `@calendar 30 mon` | 日数（1〜60）と 1 日目の曜日 |
| 能力値 | `@stat study 学力 0..100 = 10` | ID・表示名・範囲・初期値。末尾の `cost` で費用（倍率を掛けない） |
| 人物 | `@char sumi 星野澄 #9fc8ff faces normal,smile,shy` | 話者・名札の色・表情 |
| 好感度 | `@heart sumi 0..100 = 0` | 人物の好感度（`@char` の後） |
| フラグ | `@flag festival_sumi` | 初期値は偽 |
| 背景 | `@bg room 自室` | 背景の ID と名前 |
| 行動 | `@action study 勉強 week mon..sat bg room : study += 3..5 ; fatigue += 8` | 選べる曜日（省略で毎日）・背景・効果 |
| 結果の段階 | `@outcome great 大成功 x150 weight 20` | 倍率（0〜400 %）と重み |
| 重みの上書き | `@weight bad 60 when fatigue >= 80` | 条件が成り立つ朝の重み（段階ごとに最初に成り立つもの） |
| 強制の行動 | `@forced rest when fatigue >= 100` | 成り立つ朝はこの行動だけ |
| イベント | `@event e_club slot after day 1..10 week mon,wed priority 60 chance 100 once bg club when action == club` | 枠（`after`・`night`）・期間・曜日・優先度（0〜1000）・確率（1〜100）・1 回だけ・背景・条件。本文が続き `@end` で閉じる |
| 本文 | `sumi:smile「今夜、屋上で月を見ない？」`・`夕立が来た。`・`@bg roof`・`@do sumi += 2` | 台詞（話者・表情）・地の文・背景の切り替え（次の行から）・すぐ当てる効果 |
| 選択肢 | `- 行きます : sumi += 5 ; set rooftop_sumi` | 本文の最後に 2〜3 行。効果は省略できる |
| 排他 | `@exclusive e_festival_sumi e_festival_shiori` | 同じ日に出さない組 |
| ED | `@ending sumi 先輩ED priority 30 bg roof when sumi >= 70 and festival_sumi` / `@ending summer 天文部の夏 default` | 優先度と条件（`when` は文の最後）、または既定。本文が続き `@end` で閉じる（`@do`・選択肢は書けない） |

- 効果：`能力値 += 値`・`能力値 -= 値`・`set フラグ`・`clear フラグ` を `;` で区切る。値は 0 以上の整数。幅 `a..b` は `@action` の効果だけ。
- 条件：比較（`==`・`!=`・`<`・`<=`・`>`・`>=`）と `and`・`or`・`not`・括弧（優先順位は not ＞ and ＞ or）。比べられるのは能力値・整数・`day`。`weekday` は曜日と、`action` は行動の ID と `==`・`!=` で比べる。フラグは単独で真偽（数と比べると誤り）。

### 検証（コンパイル時。誤りは行番号と理由付き）

| 種類 | 拒否するもの |
|---|---|
| 構文 | 未知の文・塊の外の会話・閉じていない塊・選択肢の数（2〜3 以外）・選択肢の後の会話・長すぎる文（80 字）・読めない条件・括弧の不一致 |
| 名前と型 | 未宣言の能力値・フラグ・人物・表情・背景・行動・イベント、重複・予約語の ID、フラグと数の比較、比較のない能力値、`action`・`weekday` の大小比較 |
| 範囲 | 範囲外の初期値・逆向きの範囲や幅・負の値・確率（1〜100）・日（暦の中）・倍率（0〜400）・重み（0〜1000）・優先度（0〜1000）、既定の ED がちょうど 1 つでない、ED の優先度の重複、重みの合計が 0 になりうる段階の組、選べる曜日のない行動 |
| 区間 | 各能力値の d 日目に取りうる範囲（初期値 ± 1 日の最大の増減 × d、宣言の範囲で切る）で条件を 3 値（必ず偽・不明・必ず真）に評価し、期間と曜日の上で出る日のないイベント、どの日にも成り立たないイベントの条件、成り立たない ED の条件、必ず成り立つ（下の ED に届かない）ED の条件、必ず成り立つ強制の条件を拒否する。どこでも `set` されないフラグは必ず偽。見積もりは過大なので「必ず偽」「必ず真」と言い切れるものだけを拒否する |
| 個数 | 行数（4000）を展開の前に、能力値 16・フラグ 64・人物 8・行動 12・イベント 96・ED 8・会話 40 行を宣言のたびに |

- 1 日の最大の増加は「行動ごとの効果の最大 × 最大の倍率（費用は倍率なし）の最大 ＋ 枠ごとに（イベントのすぐ当てる効果 ＋ 選択肢の最大）の最大」。減少も同じ。
- コンパイル結果（`SummerBook`）は能力値・行動・結果の段階・イベント（条件は式の木 `Cond`）・ED の表と、データの指紋（本文のハッシュ）。実行器（`Summer`）はコンパイル結果だけを読み、構文解析の型を参照しない（リフレクションのテストで確かめる）。

## 設計上の選択

| 層 | 内容 |
|---|---|
| Core `Data/` | DSL のコンパイラ（`SummerCompiler`：字句 → 宣言 → 名前と型の解決 → 検証 → 区間の検証）、コンパイル結果（`SummerBook`）、条件式（`Cond`：評価と 3 値の区間の評価）、区間の見積もり（`StatBounds`） |
| Core `Play/` | 1 周の夏休み（`Summer`）：命令（行動・送る・選ぶ）・イベントの選択・効果と飽和・ED・記録・出来事・`Clone`・`Hash`・朝の写し（`Snapshot`・`Restore`） |
| Core `Save/` | 朝のセーブの直列化（`SummerSaveCodec`・`SaveText`） |
| App | 画面の流れ（`SummerFlow`：タイトル・操作説明・朝・結果・イベント・ED・一時停止・結果画面、意図の列・画面の版・文字送り・自動セーブ・経過時間）、操縦役（`Autopilot`：先輩・同級生・成り行きの 3 方針） |

- 操縦役の規則：強制の朝はその行動、疲労 70 以上は休む、夏祭りの前にお金 300 がなければバイト、3 日に 1 度は ED の能力値（先輩は感性・同級生は学力）を伸ばし、ほかの日は相手のいる場所へ。選択肢は効果の点数が最大のもの。成り行きはシード付きの乱択。
- 乱数は int-geometry の `RandomSeries.Derive`（シード・日・用途）、ハッシュは tile-motion の `StateHash`。
- ハッシュにはデータの指紋・シード・日・段・能力値・フラグ・1 回だけの済み・今日出たイベント・イベントの乱数の状態・記録まで混ぜる。

## 未実装範囲

（仕様書の Out of scope と、削った機能）

証跡画像はJPEG（`.jpg`）、品質85を標準とし、保存したJPEGのSHA-256をマニフェストに記録する。
