# 038. フライトゲーム

HALCYON SORTIE（仮）。滑走路から離陸し、敵機 3 機をミサイルで落とす 3D のフライトゲーム。仕様書：[plan/games/038-flight.md](../../plan/games/038-flight.md)

## 環境

- Unity：6000.6.9f1（URP 3D）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：キーボード（Input System）

## 起動手順

```
dev gui 038      # エディタで開く
dev build 038    # Windows ビルド
dev run 038      # ビルドを起動
dev capture 038  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| キー | 操作 |
|---|---|
| W S または ↑ ↓ | ピッチ（S・↓ で機首上げ、W・↑ で機首下げ） |
| A D または ← → | ロール（左右に傾ける）。地上では左右に曲がる |
| Q E | ヨー（機首を左右に振る）。地上では左右に曲がる |
| Shift / Ctrl | スロットルを上げる / 下げる |
| Space | ミサイル（LOCK 中だけ） |
| Tab | 目標を切り替える |
| Enter | 開始、再開、再挑戦 |
| Esc | 一時停止、再開。結果ではタイトルへ |

フォーカスを失うと一時停止し、押したままのキーを離したとみなす。復帰は Enter か Esc。

## 採用ルール

| 項目 | ルール |
|---|---|
| 時間 | 60 Tick/秒。入力はその時刻を含む Tick の前に反映する |
| 単位 | 長さ 1 単位 = 1 µm、速さは µm/Tick、加速は µm/Tick²、角度は 1 周 = 65536。浮動小数点は使わない（Mono と .NET で同じ結果） |
| 座標 | x 右（東）・y 上・z 北の左手系（Unity と同じ）。地面は y = 0 の平面 |
| 姿勢 | 整数のクォータニオン（成分は Q30）。毎 Tick、機体の軸まわりの角速度で 1 次の小回転 (1, ω/2) を右から掛けて正規化する。機首・上・右の向きは姿勢から求める |
| 速度 | 機首の向きとは別に持つ。**迎角**（機首が速度より上なら正）と**横滑り角**（速度が機首より右へ流れていれば正）が、機首と速度方向のずれ |
| 舵 | 角速度の上限はピッチ 25°/s・ロール 120°/s・ヨー 9°/s。効きは (速さ / 80 m/s)² で、80 m/s 以上は全部効く |
| 推力・抗力 | 推力は機首の向きに、スロットル 100% で 1 G。抗力は速度の逆向きに 推力 × (速さ / 200 m/s)²（水平の最高速度 200 m/s）。速さは 330 m/s を超えない |
| 揚力 | 機体の上方向に、重力 × (迎角 / 3°) × (速さ / 120 m/s)²。機体の上方向は迎角の分だけ後ろへ傾いているので、引くほど減速する |
| 横力 | 機体の左方向に、重力 × (横滑り角 / 6°) × (速さ / 120 m/s)²（横滑り角は ±20° で頭打ち）。さらに毎 Tick 横滑り角の 4% だけ機首を速度の向きへ回す（風見） |
| 失速 | 空中で、迎角が 20° を超えるか、速さが 50 m/s 未満。揚力は 20° での値の 40% に落ち、機首を速度の向きへ 30°/s で下げる（ピッチの上限より速いので、引き続けても下がる）。失速中はロックオンが切れる |
| 地上 | 滑走路の上で車輪で走る。ロールとヨーで向きを変える（止まっていれば変えない）。60 m/s 以上で機首上げを押すと機首が上がり（12° まで）、離すと下がる。転がり抵抗 0.05 G。揚力が重力を超えた Tick に浮く（既定では約 61 m/s）。接地中に滑走路の外へ出たら墜落 |
| 墜落 | 空中で機体の中心が車輪の高さ（2 m）より下になるか、ちょうどその高さで下りていたら墜落。地面は平面なので Tick の終わりの高さで判定すれば軌跡の接触を見逃さない。墜落した機体は動かない |
| 区域 | 一辺 12 km の正方形・高度 6 km まで。外に出たら警告し、10 秒続けば失敗 |
| ロックオン | 目標が機首から 12° 以内・2.5 km 以内で、自機が失速していなければ、1 秒続けて LOCK。条件を 1 Tick でも外れたら解除して数え直す。目標は円錐の中で最も機首に近い敵。Tab で円錐の中の次の敵へ |
| 発射 | LOCK 中・残弾がある・再装填（0.5 秒）が済んでいるときだけ。それ以外（未ロック・弾切れ・再装填中・地上・墜落後・終了後）は拒否して状態を変えない。残弾 16 |
| ミサイル | 自機の速度に機首の向きへ 30 m/s を足して出る。毎 Tick、誘導（比例航法：視線の回転の速さ × 4 の旋回を求める）が欲しい旋回を決め、運動（旋回 25 G まで、加速して 420 m/s まで、寿命 12 秒）がその分だけ曲げる。誘導と運動は別のコード |
| 命中 | ミサイルと目標の Tick 中の相対軌跡（直線）が近接信管の半径 12 m 以内に入れば命中（ちょうど 12 m は入らない）。同じ Tick の命中は発射の順に処理し、撃墜済みの機体には当たらない |
| 追尾の終了 | 目標が撃墜された（同じ Tick に別のミサイルが先に当てた場合を含む）、寿命、地面。目標を失ったミサイルは直進して寿命で消える（別の敵へ乗り換えない） |
| 被弾 | 敵は 1 発で撃墜。プレイヤーは 2 発目で撃墜 |
| 敵 | 3 機はプレイヤーと同じ飛行モデル。プレイヤーの少し先へ向かってロールしてから引き、速さを保つようにスロットルを使い、低いと引き起こす。ロックに 2 秒、再装填 6 秒、残弾 4。ミサイルの旋回は 16 G まで。初期位置と操縦のぶれは試合のシードで決める |
| ミッション | 滑走路から離陸し、区域の中心の先にいる 3 機を落とせば成功。プレイヤーの撃墜・墜落・区域外 10 秒・制限 5 分で失敗。終了した Tick より後の入力と Step は状態を変えない |
| 乱数 | 1 試合 = 1 シード。敵の配置と操縦のぶれは別の系列。再挑戦は起動時の値から進めた新しいシード |

## 設計上の選択

- 物理エンジンは使わない。飛行・ミサイル・命中は全て Core の整数で計算する。Unity は Core の位置と姿勢（Q30 → `Quaternion`）を描くだけ。
- Q30 の積（4 項の和）は 2^62 以下なので long に収まる。ベクトルの回転は成分 2^31 まで。速さの上限 600 m/s（設定の検証）と、揚力の基準の速さ 20 m/s 以上で、揚力・抗力の中間値も long に収まる。
- 揚力は「迎角に比例・速さの 2 乗に比例」の近似で、機体の上方向に向ける（速度に直交させない）。迎角を取ると揚力が後ろ向きの成分を持ち、旋回で速さが落ちる。
