# 038. フライトゲーム

HALCYON SORTIE（仮）。滑走路から離陸し、敵機 3 機をミサイルで落とす 3D のフライトゲーム。仕様書：[plan/games/038-flight.md](../../plan/games/038-flight.md)

## 環境

- Unity：6000.6.9f1（URP 3D）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：キーボード（Input System）

## 起動手順

```
dev gui 038      # エディタで開く
dev build 038    # Windows ビルド
dev run 038      # ビルドを起動
dev capture 038  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 操作

| キー | 操作 |
|---|---|
| W S または ↑ ↓ | ピッチ（S・↓ で機首上げ、W・↑ で機首下げ） |
| A D または ← → | 押している間、その向きへ鋭く旋回する（旋回の補助：深く傾けて失速しない範囲で引き、傾きで高度を保つ）。離すと翼が水平に戻る。地上では左右に曲がる |
| Q E | ヨー（機首を左右に振る）。地上では左右に曲がる |
| Shift / Ctrl | スロットルを上げる / 下げる |
| Space | ミサイル（LOCK 中だけ） |
| Tab | 目標を切り替える |
| Enter | 開始、再開、再挑戦 |
| Esc | 一時停止、再開。結果ではタイトルへ |

フォーカスを失うと一時停止し、押したままのキーを離したとみなす。復帰は Enter か Esc。

## 採用ルール

| 項目 | ルール |
|---|---|
| 時間 | 60 Tick/秒。入力はその時刻を含む Tick の前に反映する |
| 単位 | 長さ 1 単位 = 1 µm、速さは µm/Tick、加速は µm/Tick²、角度は 1 周 = 65536。浮動小数点は使わない（Mono と .NET で同じ結果） |
| 座標 | x 右（東）・y 上・z 北の左手系（Unity と同じ）。地面は y = 0 の平面 |
| 姿勢 | 整数のクォータニオン（成分は Q30）。毎 Tick、機体の軸まわりの角速度で 1 次の小回転 (1, ω/2) を右から掛けて正規化する。機首・上・右の向きは姿勢から求める |
| 速度 | 機首の向きとは別に持つ。**迎角**（機首が速度より上なら正）と**横滑り角**（速度が機首より右へ流れていれば正）が、機首と速度方向のずれ |
| 舵 | 角速度の上限はピッチ 25°/s・ロール 120°/s・ヨー 9°/s。効きは (速さ / 80 m/s)² で、80 m/s 以上は全部効く |
| 推力・抗力 | 推力は機首の向きに、スロットル 100% で 1 G。抗力は速度の逆向きに 推力 × (速さ / 200 m/s)²（水平の最高速度 200 m/s）。速さは 330 m/s を超えない |
| 揚力 | 機体の上方向に、重力 × (迎角 / 3°) × (速さ / 120 m/s)²。機体の上方向は迎角の分だけ後ろへ傾いているので、引くほど減速する |
| 横力 | 機体の左方向に、重力 × (横滑り角 / 6°) × (速さ / 120 m/s)²（横滑り角は ±20° で頭打ち）。さらに毎 Tick 横滑り角の 4% だけ機首を速度の向きへ回す（風見。1 Tick に 10° まで） |
| 失速 | 空中で、迎角が 20° を超えるか、速さが 50 m/s 未満。揚力は 20° での値の 40% に落ち、機首を速度の向きへ 30°/s で下げる（ピッチの上限より速いので、引き続けても下がる）。失速中はロックオンが切れる |
| 地上 | 滑走路の上で車輪で走る。ロールとヨーで向きを変える（止まっていれば変えない）。60 m/s 以上で機首上げを押すと機首が上がり（12° まで）、離すと下がる。転がり抵抗 0.05 G。揚力が重力を超えた Tick に浮く（既定では約 61 m/s）。接地中に滑走路の外へ出たら墜落 |
| 墜落 | 空中で機体の中心が車輪の高さ（2 m）より下になるか、ちょうどその高さで下りていたら墜落。地面は平面なので Tick の終わりの高さで判定すれば軌跡の接触を見逃さない。墜落した機体は動かない |
| 区域 | 一辺 12 km の正方形・高度 6 km まで。外に出たら警告し、10 秒続けば失敗 |
| ロックオン | 目標が機首から 12° 以内・2.5 km 以内で、自機が失速していなければ、1 秒続けて LOCK。条件を 1 Tick でも外れたら解除して数え直す。目標は円錐の中で最も機首に近い敵。Tab で円錐の中の次の敵へ（切り替えた Tick から数え直す）。LOCK は Tick の終わりに決まり、発射は次の Tick の始めに判定する |
| 発射 | LOCK 中・残弾がある・再装填（0.5 秒）が済んでいるときだけ。それ以外（未ロック・弾切れ・再装填中・地上・墜落後・終了後）は拒否して状態を変えない。残弾 16 |
| ミサイル | 自機の速度に機首の向きへ 30 m/s を足して出る。毎 Tick、誘導（比例航法：視線の回転の速さ × 4 の旋回を求める）が欲しい旋回を決め、運動（速度に直交する成分だけを使い、プレイヤーは 25 G・敵は 6 G まで。速さは 1 Tick に 40 mm/Tick ずつ、プレイヤーは 420 m/s・敵は 280 m/s まで。寿命 12 秒）がその分だけ曲げる。重力は受けない。誘導と運動は別のコード |
| 命中 | 全機が動いた後、ミサイルと目標の Tick 中の相対軌跡（どちらも直線）が近接信管の半径 12 m より近づけば命中（ちょうど 12 m は当たらない）。近接信管は目標にだけ反応する。同じ Tick の命中は発射の順に処理し、撃墜済みの機体には当たらない。機体どうしは当たらない |
| 追尾の終了 | 目標が撃墜された（同じ Tick に別のミサイルが先に当てた場合を含む）、寿命、地面。目標を失ったミサイルは直進して寿命で消える（別の敵へ乗り換えない） |
| 被弾 | 敵は 1 発で撃墜。プレイヤーは 3 発目で撃墜 |
| 敵 | 3 機はプレイヤーと同じ飛行モデルだが、舵の効きは 75%（急旋回を続ければ後ろの敵を前へ回り込ませられる）。区域の中心の北に散らばって巡回する（半径 1.2 km の円）。プレイヤーが空中で 5 km 以内に入った敵から交戦を始め、以後は巡回に戻らない。**攻撃役は 1 機だけ**で、ロックと発射は攻撃役だけが行い、他の交戦中の敵はプレイヤーのまわり 2.5 km を回って待つ。攻撃役は 10 秒追い続けるか撃ったら 4 秒まっすぐ離脱し、攻撃役は番号の順に次の敵へ移る。攻撃役はプレイヤーの 0.75 秒先の位置（±150 m のぶれ、1.5 秒ごとに引き直す）へ、点が機体の真上に来るようロールしてから引く。速さは 150 m/s を保ち（プレイヤーは全開で振り切れる）、地面に向かっていれば引き起こし、自分を追うミサイルが 800 m 以内なら視線と直角に逃げる。ロックは機首から 8° 以内・1.5 km 以内で 4 秒（プレイヤーより狭く短く遅い）、再装填 6 秒、残弾 4。初期位置と操縦のぶれは試合のシードで、別の系列から引く |
| ミッション | 滑走路（南端 z = -5.5 km、長さ 1.5 km、幅 50 m）から離陸し、3 機を落とせば成功（敵が墜落しても数える）。プレイヤーの撃墜・墜落・区域外 10 秒・制限 5 分で失敗。同じ Tick に最後の敵を落として自分も落ちたら失敗。終了した Tick より後の入力と Step は状態を変えない |
| 乱数 | 1 試合 = 1 シード。敵の配置と操縦のぶれは別の系列。再挑戦は起動時の値から 1 ずつ進めた新しいシード |
| 1 Tick の順序 | 目標の切り替え → 発射（プレイヤー、LOCK した攻撃役。撃ったら離脱）→ 攻撃役の決め直しと離脱の残りの更新 → 敵の狙いのぶれの引き直し → 全機の飛行（敵の操縦は全機が動く前の状態から決める）→ ミサイルの誘導・移動・命中（発射の順）→ ロックオンの更新 → 勝敗 |

## 設計上の選択

- 物理エンジンは使わない。飛行・ミサイル・命中は全て Core の整数で計算する。Unity は Core の位置と姿勢（Q30 → `Quaternion`）を描くだけ。
- 描画は Core の座標をそのまま m にして置く（区域は ±6 km なので float の精度で足りる）。その Tick の状態を描き、補間しない。カメラは機体に固定した後ろ上から機首の先を見る（機体と一緒に傾く）。撃墜・墜落の後は最後の位置を水平に見る。
- 機首と速度方向のずれは HUD で見せる：十字が機首の 1 km 先、翼つきの円が速度の向きの 1 km 先。迎角の値も出す。
- 爆発・被弾の赤い画面・撃墜の表示・煙は Core の Tick（`Fighter.DownTick`・`HitTick`）から描くので、撮影は同じ絵になる。
- 姿勢の小回転は 1 次の近似 (1, ω/2) で、要求 θ に対して 2·atan(θ/2) 回る。1 Tick の回転は舵・失速の検証と風見の上限で各軸 10° 以下に収め、誤差を 0.03° 程度に保つ。
- `Mission.Hash()` は動的状態に加えて検証済みの設定の全フィールドを混ぜる（設定だけが違う 2 つのミッションを見分ける）。
- Q30 の積（4 項の和）は 2^62 以下なので long に収まる。ベクトルの回転は成分 2^31 まで。速さの上限 600 m/s（設定の検証）と、揚力の基準の速さ 20 m/s 以上で、揚力・抗力の中間値も long に収まる。
- 揚力は「迎角に比例・速さの 2 乗に比例」の近似で、機体の上方向に向ける（速度に直交させない）。迎角を取ると揚力が後ろ向きの成分を持ち、旋回で速さが落ちる。
- 追尾誘導の分離：誘導は `IGuidance`（既定は `ProNav`）で、目標とミサイルの位置・速度だけを受け取って欲しい横向きの加速を返す。曲げられる上限・速さ・寿命はミサイルの運動（`MissileBody`）と `Mission` が持つ。誘導の中間値は mm 単位の long で、最後の割り算だけ BigInteger。
- 近接の判定（`Proximity`）は、相対軌跡の最小距離の 2 乗の比較を BigInteger で厳密に行う。1 Tick に数 m 進むミサイルが目標の横をすり抜けても見逃さない。
- 敵の操縦（`Steering`）はプレイヤーの操縦役（`Autopilot`）と共有する純粋関数。点へ向かうロール → ピッチ、引き起こし、回避、区域内へ戻る。
- 敵の強さは、操縦役で多くのシードを通して決めた。8 G・420 m/s の敵のミサイルでは、操縦役は 20 シード全てで撃墜された。6 G・280 m/s・ロック 12°／1.8 km／3 秒・プレイヤーの耐久 3 で、操縦役は 60 シード全てに勝つ。試遊で「ロックオンされやすすぎる」とされ、敵のロックを 8°／1.5 km／4 秒にした（操縦役の 40 試合で、ロックされている表示の時間が 8.3% → 4.6%、敵の発射が 1 試合 0.8 発 → 0 発）。6 G なら、500 m に迫られてから 90° 傾けて引くと外せる（`GuidanceTests`）。
- 操縦役は敵のミサイルを避けない。水平の回避を入れると撃たれる時間が延び、勝率が下がった（40 シードで 39 勝 → 33 勝）。
- 試遊で「1 機落とした後は後ろに張り付かれて一方的にロックされる」とされた。敵を 600 m 後ろに置いた場面を測ると、真っすぐ逃げれば 30 秒で 2.2 発撃たれ、急旋回を続けても同じ性能の敵を前に出せなかった（20 シードで 0）。操縦役は正面から先に撃ち落とすので、この場面を通らず、テストも見逃していた。
  - 敵：舵の効き 75%・巡航 150 m/s・攻撃役 1 機・10 秒追うか撃ったら 4 秒離脱。
  - 操作：左右のキーを旋回の補助にした（ロールと引きを同時に操作しなくてよい）。
  - HUD：攻撃役が円錐に入れているだけなら「狙われている n%」、LOCK したら「ロックされた」。
  - テスト：キーだけで 0.2 秒遅れて押す操縦役（`KeyboardPilot`、補助を通す）で、20 シードの勝率と、敵が後ろ 600 m の場面（60 秒で LOCK 11/20・撃墜 10/20・敵の発射 20 試合で 2 発）を確かめる。

## 未実装範囲

- 仕様書の Out of scope：高精度航空力学、大規模地形、素材の量産。
- 着陸はない（離陸後に地面へ触れたら墜落）。機銃・フレア・複数の機種・複数のミッションはない。
- 機体どうしの衝突はない（すり抜ける）。地形は平らな地面と目印の塔だけで、塔に当たりはない。
- Core の Step は、ミサイルが飛んでいる間、誘導と近接の BigInteger で 1 Tick 平均 300 バイト程度を割り当てる（描画の更新は割り当てない）。

## 試遊で見てほしい点

- 操作：S で機首上げ・W で機首下げ（操縦桿の向き）で良いか。舵の効き、低速での鈍さ。
- 離陸：スロットル全開から約 8 秒・約 250 m で浮く速さ。
- 失速：引きすぎ・遅すぎで STALL になる入りやすさと、機首が下がって回復する感じ。
- 戦闘：LOCK までの 1 秒、ミサイルの当たりやすさ、敵のミサイル（6 G）の避けやすさ、耐久 3、敵の強さ、制限 5 分。
- 見た目：追従カメラの位置、HUD の大きさ、音量。
