# 004. Space Invaders — STAR GUARD

仕様書：[plan/games/004-space-invaders.md](../../plan/games/004-space-invaders.md)

左右に動いて射撃し、下降する敵編隊を3Wave撃破する。盾は自分の弾でも削れる。原作完全互換ではなく、編隊管理と所有者別衝突判定を学ぶ独自ルールを採用する。

## 環境・起動

- Unity 6000.6.9f1、Universal 2D、C# 9.0。
- Windows / StandaloneWindows64。入力はInput Systemのボタンアクション。
- シーン：`Assets/Scenes/Invaders.unity`。

```text
dev gui 004
dev build 004
dev run 004
dev capture 004
```

## 操作

| 操作 | キー・ボタン |
|---|---|
| 左右移動 | ←→ / A・D。両方向同時押しは停止 |
| 射撃 | Space長押し |
| 開始・再戦 | Enter / START / PLAY AGAIN |
| 停止・再開 | P / Esc / RESUME |
| タイトルへ戻る | 停止・結果画面のTITLE |
| 終了 | タイトルのQUIT / ウィンドウを閉じる |

フォーカス喪失で停止し、復帰後も手動再開する。停止・画面遷移では保留操作と端数時間を捨て、押し続けている移動・射撃キーは一度すべて離してから受け付ける。

## 採用ルール

| 項目 | 内容 |
|---|---|
| 勝利・敗北 | 3Wave撃破で勝利。残機0または生存敵の下端が侵入ラインへ到達すると敗北 |
| 編隊 | 8列×4行。生存敵の左右端が壁に着いたTickはそこで停止。次のTickで0.5下降して反転し、その次から水平移動 |
| 難易度 | 水平速度はWaveごとに1.0 / 1.35 / 1.7。射撃間隔は0.9秒を基準にWaveごとに0.8倍。敵数による加速はない |
| 敵射撃 | 生存列の最下段から射手をシード付きxorshiftで選ぶ。下向きに毎秒6進む。同時最大12発 |
| 自機射撃 | 0.25秒間隔、上向きに毎秒20進む。同時最大3発。満杯中の射撃要求は予約しない |
| 移動 | 自機は毎秒8。フィールド幅20、自機幅1、中心の移動範囲は±9.5 |
| 盾 | 3基、各12列×6行のセル。両陣営の弾が最初に当たったセル1個を破壊して消える。編隊と接触したセルも破壊 |
| 衝突マスク | 自弾→敵・盾、敵弾→自機・盾。同陣営・弾同士は通過 |
| 被弾 | 残機3から開始。同じTickの複数被弾は1回だけ減算。全弾を消し中央へ戻り、1秒間進行を止め、その後1秒間無敵 |
| Wave移行 | 全滅で全弾を消去し中央へ戻る。1秒後に次の編隊を生成。残機・得点・盾の損傷を引き継ぐ |
| Wave末尾の被弾 | 最後の撃破と被弾が重なって残機が残った場合はWave移行を行い、次Waveでも復帰後の無敵を適用する。待機はWave待ちと復帰待ちの長い方 |
| 同Tickの決着 | 最後の撃破と残機0が同じTickに成立した場合は敗北を優先 |
| 得点・再戦 | 敵1体100点、全96体で9,600点。再戦は全状態を初期化し、新しい試合シードを使う |

設定は [InvadersSettings.asset](Assets/Game/Unity/InvadersSettings.asset)。公開フィールドのCore設定をUnityがシリアライズする。各値は有限値・許容範囲を検証し、編隊は最大10×5、弾は自弾8・敵弾24までとする。速度・射撃間隔・下降量・待機時間・無敵時間・音量を調整可能。盾の形とフィールド寸法はルール定数。

## 設計

| 層 | 主な型・責務 |
|---|---|
| Core | `InvadersConfig`、`InvadersState`、`PlayerCommand`、`BulletOwner`、`Motion`。編隊・射撃・盾・残機・得点・Wave・衝突。Unity非依存 |
| App | `InvadersFlow`。画面遷移、保持入力、フォーカス、実時間→60Hz固定Tick。`Autopilot`は撮影と通しテストで共有 |
| Unity | `InvadersGame`、`InvadersSettings`、`InvadersCaptureScenario`。入力・自作ドット絵・HUD・音・撮影 |

- 編隊は原点・方向・下降待ちと各敵の生死を持つ。外側の敵が倒れたら残った敵の範囲で壁を判定する。
- 衝突はTick中の相対移動による掃引AABB。端で止まる移動は到達時刻で区切る。弾の命中と敵→盾の接触を一つの時系列で処理し、撃破前の盾接触は残し、撃破後の接触は無効にする。先に壊れた盾を後続の弾は通過する。同時刻は弾の接触を先に処理し、撃破時刻ちょうどの敵→盾接触も無効にする。同種の接触は発生元の生成順→対象種別→対象番号で固定する。Unity物理に委譲する処理はない。
- 弾の作業配列と生成済みSpriteRendererを再利用する。現在Tickをそのまま描き、補間は行わない。
- 1フレーム最大5Tick。超過整数Tickは破棄し端数を保持する。時間の整数部と端数は同じTick換算値から取り出す。
- 秒設定は整数Tickへ切り上げる。ただし整数Tickの秒数に対応するfloat表現はその整数として扱う。その直上のfloat値は次のTickになる。タイトルの残機数と説明文も設定値を使う。
- 1試合＝1シード。設定・シード・Tickごとの入力で同じ実行環境内の状態を再現する。Monoと.NET間の浮動小数点完全一致は要求しない。
- タイトル→プレイ→結果→再戦。プレイから停止、停止・結果からタイトルへ戻れる。Core内の復帰待ち・Wave待ちはプレイ画面で扱う。
- 16:9基準、16:10〜21:9の横長画面で領域を収める。PanelRendererのHUDは読み込み直後にも反映する。生成Texture2D・Sprite・AudioClipはシーン破棄時に破棄する。
- 音は振幅0.05・音量0.15が既定。`AudioPolicy`でバッチテストと撮影を消音する。
- シーンの正は `InvadersSceneBuilder`。再生成：`unity run games/004-space-invaders -- -executeMethod Game.Unity.Editor.InvadersSceneBuilder.Build`。

## 検証

```text
dev lint
dev check
dev test
dev test 004 -Unity
dev test 004 -Unity -Mode PlayMode
dev build 004
dev capture 004
```

- Core：端での一度だけの反転・下降、生存範囲、盾の二重命中、所有者マスク、移動中の衝突、残機・無敵・侵入・Wave・同時決着、不正設定、固定シード再現、最大設定の乱択入力。
- App：開始・停止・復帰・再戦、両方向、端数時間、処理落ち、最大有限時間、フォーカスのイベント順序、3試合目の独立再現、固定シード3種類の3Wave勝利。
- PlayMode：実シーンでの入力とHUD、フォーカス競合、結果・再戦、Wave・勝利表示、横長カメラ、消音、再読み込み時の破棄、最大設定のCPU更新・描画更新と生成物数。
- 撮影は固定シード1でタイトル・交戦・Wave移行・勝利、その後シード2で無操作による敗北。各ループ60,000Tick以内を要求し、実時間やプレイヤー入力で進めない。

実測結果と画像は [evidence/README.md](evidence/README.md)、最大設定の条件は [evidence/capacity.md](evidence/capacity.md) に記録する。
