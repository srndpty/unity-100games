# 049 閉館後の展示室

展示メダルがすり替わった博物館で、5件の証言を尋問し、8点の証拠から矛盾を立証する推理ゲーム。

## 起動と操作

Unity 6000.6.9f1 / 2D URP / Windows x64。リポジトリのルートで `dev build 049`、`dev run 049` を実行する。マウスで証言と証拠を選択し、尋問・提示ボタンを押す。タイトルの「遊び方」でも操作を確認できる。

| 操作 | ルール |
|---|---|
| 尋問 | 解放済みの証言ごとに一度、資料を取得。開始時から展示目録と会場図を所持 |
| 提示 | 現在の照合対象に所持済みの証拠を提示できる。正解で次の証言が解放され、3件の立証で勝利。立証済みの証言を選ぶと立証記録を読み返せる |
| 誤提示 | 残り回数を1減らす。初期値3、0で敗北 |
| 再戦 | 証拠、証言の解放、残り回数を初期化 |

## 構成

Core の事件データで証言、証拠、尋問報酬、照合と解放の関係を定義。照合の循環および到達時点の証言・証拠の参照を検証する。App は画面遷移と操作の順序を管理する。Unity は PanelRenderer、USS、生成した展示室背景で表示し、封印の図は資料本文に合わせてUIで構成する。`DeductionSettings` で残り回数と効果音量を調整できる。

本編は固定の1事件。裁判演出の完全再現、音声認識、追加事件や製品化機能は仕様の対象外。

シーンを再生成する場合は `unity run games/049-deduction -- -executeMethod Game.Unity.Editor.DeductionSceneBuilder.Build` を実行する。
