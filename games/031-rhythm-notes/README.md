# 031 リズムゲーム

Unity 6000.6.9f1 / 2D URP / Windows 64-bit / キーボードとマウス

`dev build 031` でビルドし、`dev run 031` で起動する。エディタでは `dev gui 031` から `Rhythm` シーンを再生する。

## 操作

| 入力 | 操作 |
|---|---|
| ↑ / ↓ または曲ボタン | 曲選択 |
| ← / → または ±5 ms ボタン | 入力補正を調整 |
| Enter | 演奏開始 / 結果画面から再演奏 |
| F / J | 丸 / ひし形のノーツを打つ |
| Esc | 一時停止 / 再開 |
| T | 一時停止・結果画面から曲選択へ |

ノーツが各レーン左側の色付きの線に重なるときに打つ。打鍵が遅く判定されるときは補正値を上げる。補正は −100〜+100 ms、5 ms 刻みで保存され、次の演奏から反映される。

## ルール

| 判定 | 条件 | 配点 |
|---|---|---|
| 良 | 誤差 ±30 ms 以内 | 100 |
| 可 | 誤差 ±80 ms 以内 | 50 |
| ミス | 未判定のまま遅い側の窓を通過 | 0 |

同じ打種の未判定ノーツのうち誤差が最小のものを採点する。同距離では早いノーツを優先する。空打ちでノーツは消費されない。良・可でコンボが増え、ミスで途切れる。曲が終わると得点と判定の内訳を表示する。

「港の灯」「雨上がり」「夜の軌道」は 96・120・144 BPM、各12小節のオリジナル曲。オンラインランキング、曲ライセンス機能、課金・実績は仕様の対象外。

## 実装と再生成

- Core は譜面の検証と採点を担当する。判定は 32 kHz の整数サンプルで比較する。
- App は演奏の状態と入力補正を管理する。入力を曲時刻順に扱えるように採点を100 ms保留し、同時刻では受信順に処理する。
- Unity は DSP 開始時刻を共有して曲の予約再生とノーツの位置を決める。打鍵は Input System のイベント時刻を DSP 時刻へ換算する。停止中はオーディオと DSP 時間を保持し、復帰後は手動で再開する。
- シーンと音源は `unity run games/031-rhythm-notes -- -executeMethod Game.Unity.Editor.RhythmSceneBuilder.Build` で再生成できる。音源と譜面は共通の拍→サンプル変換を使う。WAV はモノラルの16ビット PCM で、最長30秒の曲もコミット時の2,000 KB上限に収まる。配点・判定窓・表示先行時間・音量は `RhythmSettings.asset` にある。
