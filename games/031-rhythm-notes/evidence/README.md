実シーンのテストでは、再生予約中と演奏中に一時停止・再開した。停止中は DSP 時刻、再生サンプル位置、譜面位置が固定され、再開後は再生位置（出力バッファの遅れを引いた位置）と譜面位置が DSP バッファの許容差内で一致した。仮想キーボードから送った打鍵が採点に反映され、破壊演出が1つ出ることも確認した。もう1つのテストでは、→キーで補正が保存されること、C キーで補正テストがクリック音源で始まり、演奏中は補正を変えられないことを確認した。

Windows ビルド時のログに Unity CLI がライセンスクライアントの検証メッセージを報告した。ビルド・撮影・終了コードは成功だった。音を聞きながらの通しプレイ、補正テストの実測値と補正後の感触は人間による確認待ち。

WAV の最大サイズは 1,920,044 バイト（補正テストは 1,706,710 バイト）で、コミットフックの 2,000 KB 上限内。
