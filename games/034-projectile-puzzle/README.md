# 034. 投射パズル — PEBBLE SIEGE（仮）

仕様書：[plan/games/034-projectile-puzzle.md](../../plan/games/034-projectile-puzzle.md)　実装計画：[plan/games/034-projectile-puzzle-implementation.md](../../plan/games/034-projectile-puzzle-implementation.md)

発射台の石つぶてを引いて放ち、砦の灯籠（標的）を全て落とす。全 5 面、弾は通常・重い・爆発の 3 種。参考作品からはメカニクスだけを採用し、名称と見た目は独自に作る。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のマウス（発射台の近くを押して引き、離して撃つ）とキーボード
- 共通パッケージ：[com.games100.tile-motion](../../packages/com.games100.tile-motion/)（`StateHash`）
- 物理：Unity の Physics2D（従来の Box2D、速度 8・位置 3 反復）に委譲する。何を委譲したかは「設計上の選択」を参照

## 起動手順

```
dev gui 034      # エディタで開く
dev build 034    # Windows ビルド
dev run 034      # ビルドを起動
dev capture 034  # 証跡を evidence/ に撮る（画像は captures/<画像世代>/、撮影記録は runs/）
```

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 時間 | 60 Tick/秒。物理は Script モードで 1 Tick に 1 回 `Physics2D.Simulate(1/60)`（自動のシミュレーションは切る）。Core・App は Tick 単位で進む |
| 座標 | 1 = 1 m（Unity のワールド座標と同じ）。盤は 32 × 18 m、原点は地面の左端、y は上向き。地面は y = 0 |
| 射出 | 発射台から 1.2 m 以内を押すと構える。引き ＝ 離した位置 − 発射台。初速 ＝ 引きの逆向き × 21 m/s × min(長さ, 2.4) / 2.4。**初速は離した位置だけで決まり**、ドラッグの経路・フレームレート・弾の種類（質量）に依らない（速度を直接与える）。長さが 0.35 m 未満で離したら取り消し（弾を消費しない）。右クリック・Esc でも取り消し |
| 弾道プレビュー | 構えている間、Core の `Trajectory`（Physics2D と同じ半陰的オイラー：v += g·dt、x += v·dt、弾の減衰 0）で最初の 48 Tick を 3 Tick おきの点で描く。何にも触れない間は実際の弾の位置と一致する |
| 弾 3 種 | 通常（半径 0.32 m）／重い（半径 0.42 m、密度が通常の約 2.3 倍）／爆発（飛行中のクリック・Space、または最初に何かへ触れてから 90 Tick で起爆。弾は消え、半径 2.8 m 内の部材に距離で減るダメージと外向きの撃力）。起爆は 1 発で 1 回だけ |
| 弾の順 | 面のデータで弾の列を決め、順に使う（選ばない） |
| 部材 | 木・石・氷の箱（軸に沿って置く）と灯籠（標的）。素材ごとに HP・密度・得点が違う |
| ダメージ | 衝突が始まったとき（`OnCollisionEnter2D`）の法線撃力の合計 I について、floor((I − 閾値) × 係数)。閾値以下は 0。衝突した両方の部材が受ける（地面・弾は受けない）。押し合いの持続は数えない。最初の弾を撃つまでは、面の始めの 60 Tick の衝突を数えない（積み上げの落ち着き） |
| 破壊 | HP が 0 になった Tick に 1 回だけ壊れ、得点を足す。以後の衝突・爆発・落下は何もしない（**二重得点しない**）。壊れた部材に付いていた接合は外す |
| 接合 | 面のデータで 2 つの部材と外れる力を決める（`FixedJoint2D`）。力が上限を超えて Physics2D が外したとき、またはどちらかの部材が壊れたときに外れる。1 つの接合は 1 回だけ外れる |
| 消滅線 | 部材の中心が y < −3 m、または盤の左右 4 m の外へ出たら壊れたとみなす（得点あり） |
| 静止 | 動く物（壊れていない部材と弾）の最大の速さ < 0.12 m/s かつ最大の角速度 < 10 度/s が 30 Tick 続いたら静止。撃ってから 720 Tick 経ったら静止とみなす。弾は撃ってから 480 Tick、または静止で消える |
| 勝敗 | **静止したときにだけ判定する**：標的が全て壊れていれば勝ち。でなければ弾が残っていれば次の弾を構えられ、残っていなければ負け。静止の前に標的が全て壊れても、まだ勝ちにならない（その間の破壊も得点に入る） |
| 得点・星 | 得点 ＝ 壊した部材の得点の和 ＋（勝ったら）残った弾 × 2000。星 ＝ 勝ったら 1 ＋ 残った弾（最大 3）。面ごとの最高点と最多の星を記録する（起動中だけ） |
| 解放 | 最初は 1 面だけ選べる。勝った面の次の面が解放される。5 面に勝つと全面の結果を出す |
| 終了後 | 勝ち・負けの後の射出・起爆・物理の報告は状態を変えない。R でやり直すと物理の状態ごと作り直す |
| 乱数 | 使わない |

### 素材と弾（既定値）

| 素材 | HP | 得点 | 密度 | 閾値（N·s） | 係数 |
|---|---|---|---|---|---|
| 木 | 100 | 500 | 1.0 | 2 | 9 |
| 石 | 260 | 800 | 2.4 | 4 | 9 |
| 氷 | 50 | 300 | 0.8 | 1 | 12 |
| 灯籠（標的） | 30 | 3000 | 0.6 | 0.6 | 15 |

値は `PebbleSiegeSettings.asset` で調整する（Core の `SiegeConfig.Validate` が範囲を検証する）。

### 面データ

`Assets/Game/Data/Stages.txt` に 5 面を書く（`stage`・`hint`・`launcher x y`・`shots 弾…`・`block 素材 x y 幅 高さ`・`joint a b 外れる力`・`end`）。Core の `StageBook` が読み、検証する（5 面ちょうど・弾 1〜5 発・標的 1 つ以上・部材が盤の内で地面より下にない・部材どうしが重ならない・発射台の周り 3.6 m に部材がない・接合の番号・自己接合と重複がない・接合する部材が接している）。

## 設計上の選択

- **物理は Physics2D に委譲する**：剛体の運動・衝突・積み重ね・接合の力と外れは Unity の Physics2D が計算する。Core（`SiegeRun`）は射出ベクトル・弾道プレビュー・Health・接合の台帳・得点・静止・勝敗を持ち、Unity から 1 Tick ごとの報告（`TickReport`：衝突の撃力・爆発の距離・外れた接合・消滅線・最大の速さ）を受け取る。
- 1 Tick の順序：Core の `BeginTick` が命令（射出・起爆・弾の消去）を返す → Unity が命令を反映して `Physics2D.Simulate` → Unity が報告を書く → Core の `EndTick` がダメージ・破壊・静止・勝敗を決め、消す部材と接合を返す → Unity が消す。操作（撃つ・起爆）は次の Tick の境目でだけ効き、物理の途中に割り込まない。
- App（`SiegeFlow`）は物理の世界を `ISiegeWorld` として受け取る。App のテストは物理のない偽物の世界で画面遷移・構え・射出・起爆・勝敗を確かめる。
- **再現性の範囲**：Core と App は物理なしで .NET と Mono の両方でテストする。物理を含む通し（5 面の解答の再生）は同じビルド・同じ機械・Script モードで同じ結果になることを確かめ、.NET と Mono の物理の一致は求めない。
- **面ごとに物理の世界を作り直す**：`PebbleSiegeWorld` は面を読み込むたびに、局所の物理を持つ新しいシーン（`LocalPhysicsMode.Physics2D`）を作り、その `PhysicsScene2D` だけを 1 Tick に 1 回進める。Box2D の世界ごと作り直すので、前の面・やり直しの履歴に依らず、同じ面・同じ命令の列なら同じ結果になる。部材は組み終えてから眠らせ、触れられるまで動かない。
- **衝突の報告**：各部材が自分の `OnCollisionEnter2D` で、自分が受けた法線撃力の合計だけを報告する（2 つの部材の衝突なら両方が自分の分を報告し、Core の「両方が受ける」と同じになる）。弾は触れたことだけを報告する（爆発の弾の導火線）。接合の外れは `OnJointBreak2D` で報告し、Core が壊れた部材の接合を外せと返したものは Unity が消す。
- **爆発**：起爆の Tick に、弾の位置から各部材の当たりの最も近い点までの距離を測り、半径内の部材に外向きの撃力（距離で減る）を与えて距離を報告する。爆風は壁に遮られない。
- Unity（`PebbleSiegeGame`）はマウスの左ボタン・右ボタン・位置を PassThrough のアクションで 1 つずつ拾い、画面 → ワールド座標に直して時刻つきで渡す。カメラは盤の幅（32 m と余白）が収まるよう、画面の縦横比から大きさを決める。
- 描画は Stage Prefab（`Art/PebbleSiegeStage.prefab`：背景・地面・発射台・構えた弾・ゴム・弾道の点 32・爆発・土ぼこり 12、部材と弾の見本 7）を正とする。面の部材と弾は見本を物理のシーンへ複製し、Physics2D の体と当たりを付ける。部材の色は残りの HP で暗くする。タイトル・面選択の背景には、選んでいる面の初期配置を物理を進めずに置く。
- 5 面の解答（`Assets/Game/Data/Solutions.txt`）は、PlayMode の `[Explicit]` テスト `SolutionSearch` が実際の Physics2D で 1 発ずつ、角度（0〜75 度、2.5 度刻み）× 引きの長さ（4 通り）× 起爆の Tick（爆発の弾だけ）を総当たりして見つけた。面のデータ・設定・物理の設定を変えたら探し直す（`unity test games/034-projectile-puzzle --mode PlayMode --filter SolutionSearch`）。撮影とテストだけが使い、ゲームの画面には出さない。
- シーンは `unity run games/034-projectile-puzzle -- -executeMethod Game.Unity.Editor.PebbleSiegeSceneBuilder.Build` で生成する（既存の Prefab と設定アセットは上書きしない。Physics2D の simulationMode を Script にする）。絵は `PebbleSiegeArtGenerator` が描く。射出・素材・弾・爆発・静止の値と音量は `PebbleSiegeSettings.asset` にある。

### 許容誤差

- 弾道プレビューと実際の弾の位置：何にも触れない間、3 種とも 40 Tick で 1e-4 m 以内（テストの基準）。
- 静止の判定：速さ 0.12 m/s・角速度 10 度/s 未満が 30 Tick。積み上げは面の始めの 900 Tick で 1 cm 以上動かない（テストの基準）。
