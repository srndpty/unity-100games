# 034 振り返り

- **学び**　物理を Physics2D に任せても、Core が Health・接合の台帳・静止・勝敗を持ち、Unity から Tick ごとの報告を受ける形にすれば、ルールは物理なしで .NET と Mono でテストできる。面ごとに局所の物理のシーンを作り直すと、同じ操作で同じ結果になり、解答を実際の物理の総当たりで探して撮影とテストで再生できた。
- **想定との差**　設定の重力をプレビューだけに使い、物理に反映し忘れた。勝敗が決まる静止の Tick に、次の Tick の命令で消すはずの弾が残った。フレームをまたぐと衝突のコールバックの順番が変わり、部材を消す順番から Box2D の計算がずれた。小数 3 桁に丸めた解答では崩れ方の敏感な面が勝てなかった。
- **次回**　設定値は「どこで効くか」を物理側まで追って、既定値以外の値でもテストする。物理のエンジンへの操作（生成・削除）の順番は、コールバックの順番に頼らず番号順にそろえる。探索で見つけた値は丸めずに保存する。
- **不具合**　P2-1 重力の設定が物理に効かない、P2-2 検証済みの設定を外から書き換えられる、P3-1 勝敗が決まったときに弾が残る（転がり続ける弾で回帰テストが修正前にも通っていた）。
