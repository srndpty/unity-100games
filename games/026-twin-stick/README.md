# 026. ツインスティックSTG — HALO SIEGE（仮）

仕様書：[plan/games/026-twin-stick.md](../../plan/games/026-twin-stick.md)　実装計画：[plan/games/026-twin-stick-implementation.md](../../plan/games/026-twin-stick-implementation.md)

画面より広いアリーナで、キーで動きながらマウスで狙って撃ち、5 分間生き残る。敵は 3 種で、時間とともに湧く間隔が短くなる。参考作品からはメカニクスだけを採用し、名称と見た目は独自に作る。

## 環境

- Unity：6000.6.9f1（Universal 2D、C# 9.0）
- 対象プラットフォーム：Windows (StandaloneWindows64)
- 入力方式：Input System のキーボード（移動）とマウス（照準・射撃）。ゲームパッドは対応しない。HUD は PanelRenderer / UI Toolkit
- 共通パッケージ：[com.games100.tile-motion](../../packages/com.games100.tile-motion/)（`Units`・残り Tick の `Countdown`・状態ハッシュ `StateHash`）

## 採用ルール

| 項目 | 採用ルール |
|---|---|
| 単位 | 1 セル = 256 単位の整数。速さは単位/Tick、60 Tick/秒。時間の設定は Tick 数。浮動小数点を使わないので Mono と .NET で同じ結果になる |
| アリーナ | 48×27 セルの矩形。障害物なし。画面に映るのは 32×18 セル |
| 画面（視野） | 自機を中心にし、アリーナの端では寄せ止めた 32×18 セル（`View.Of`）。カメラも同じ関数で決めるので、「画面外」の定義が描画とルールで一致する |
| 試合 | 5 分（18000 Tick）。残機 3。生き残れば勝ち（残機 1 つにつき 500 点を足す）、残機 0 で負け |
| 移動 | 8 方向に速さ 28（斜めは各軸 181/256 倍、最低 1）。アリーナの外周で止まる |
| 照準 | 毎 Tick「狙う点」（アリーナ座標の整数。マウスの位置から作る）を受け取り、**移動の後の自機からその点への向き**に撃つ。向きは整数平方根で弾の速さに正規化する。狙う点が自機にちょうど重なる Tick は直前の向きを保つ。**移動キーは射撃の向きに影響せず、照準は移動に影響しない** |
| 射撃 | 押している間、6 Tick ごとに 1 発（押した Tick に撃ち、以後 6 Tick ごと）。次の Tick までに押して離した短いクリックも 1 発撃つ。弾は速さ 96 で直進し、**撃った Tick を含めて 50 Tick** か、アリーナの外に出た Tick に消える（その Tick の通り道では当たる）。武器は 1 種だけ |
| 弾の数の上限 | 同時に存在する弾は寿命 ÷ 連射の間隔の切り上げ（既定 9 発）を超えない。設定の検証でこれが 32 以下になることを保証し、超えたら例外にする（fail-closed） |
| 敵 3 種 | **Chaser**（体力 1・速さ 14・10 点）：毎 Tick 自機へ向きを変えて追う。**Bouncer**（体力 1・速さ 20・20 点）：出現時に乱数で決めた向きへ直進し、外周に着いたらその軸の速度を反転する。**Lancer**（体力 3・50 点）：自機へ速さ 6 で 60 Tick 歩く → 止まって 30 Tick 狙う（向きは狙い始めの自機の方向で固定）→ 速さ 64 で 24 Tick 突進（外周に着いたらやめる）、を繰り返す。敵は弾を撃たない。敵どうしは重なってよい |
| 外周 | 敵は外周に着いた時点で止まったとする（その Tick の軌跡は始めから止まった位置への直線） |
| 出現の予告 | 新しい敵はまず予告（45 Tick、出現した Tick を含む）として現れる。予告中は動かず、当たらない（自機も弾も素通りする）。予告の次の Tick から動く |
| 出現位置 | **画面の内側**（いちばん大きい敵が収まる範囲）の乱数の点で、**自機から 5 セル以上**離れたもの。8 回探して見つからなければ、その Tick は見送る（次の Tick に探し直す） |
| スポーンレート | 60 秒ごとの 5 区間の表で、出現の間隔と種類の重みを決める（間隔 75 → 55 → 40 → 30 → 22 Tick。Lancer は 2 区間目から）。予算を毎 Tick 1 ずつ貯め、間隔に達したら 1 体出して 0 に戻す。**予算は間隔 1 回分で頭打ち**にし、1 Tick に出すのは最大 1 体（上限から空いた瞬間にまとめて湧かない） |
| 敵の密度の上限 | 生きている敵は予告中を含めて **36 体まで**。上限に達している間は出さない |
| 画面外の敵 | 画面の外に **180 Tick 続けて**居た敵（予告中を含む）は、得点なしで消える。画面に戻れば数え直す。画面外の敵は溜まらない |
| 当たり判定 | 自機・弾・敵はすべて円（半径：自機 72・弾 32・Chaser 96・Bouncer 104・Lancer 120）。**Tick の中の相対軌跡どうしを掃引**し、中心の距離が半径の和より小さくなったら触れたとする（ちょうど接するだけでは触れない）。触れるかどうかは整数で厳密に判定し、どれが先かは切り上げの整数平方根で求めた時刻で比べる |
| 弾の当たり | 弾 1 発は、その Tick の通り道で最初に触れた 1 体にだけ当たって消える。当たった敵は体力が 1 減り、0 で消えて得点が入る |
| 被弾 | 無敵でない自機が敵に触れると、その Tick で最初に触れた 1 体だけで残機が 1 減り、その敵は得点なしで消える。**被弾した Tick を含めて 120 Tick は無敵**（その間に触れた敵は消えず、残機も減らない。121 Tick 目から再び当たる）。自機はその場で続ける（周りの敵は消さない） |
| 1 Tick の順序 | 時間を進める（無敵・連射・弾の寿命・予告）→ 自機の移動 → 照準 → 射撃 → 弾の移動 → 敵の移動 → 弾×敵 → 自機×敵 → 画面外の除去 → 出現 → 時間切れの判定。**同じ Tick では弾の当たりを先に解決する**（撃ち落とした敵には触れない）。最後の Tick に残機 0 になったら負け |
| 乱数 | 1 試合 = 1 シードの xorshift。出現位置・種類の選択・敵の行動（Bouncer の向き）で系列を分ける。再戦は次のシード |
| 終了後 | 勝ち・負けの後の Tick と入力は状態を変えない |

## 設計上の選択

- **物理エンジンは使わない。** 移動・当たり・反射はすべて Core の整数演算で行う。
- **移動と照準は別の経路で Core に渡す。** 移動キーは時刻付きの押下・解放の列（`Intent` → `HeldControls`）、照準は「今の値」としてフレームごとに `SiegeFlow.SetAim` で渡し、Core の `ShipCommand` で初めて 1 つになる。Core の中でも移動の量と弾の向きは互いを参照しない。
- **画面の範囲は Core の規則。** 出現位置と画面外の除去は `View.Of`（自機中心・端で寄せ止め）で決め、カメラも同じ関数で置く。
- **出現の制御は「区間の表＋頭打ちの予算＋密度の上限」の 3 つだけ。** どれも Tick 数の整数で、上限に張り付いた後の振る舞いまでテストで確かめる。
- **描画は Stage Prefab 1 つ。** 床と外周の壁は Tilemap、自機・照準・敵・予告・突進の筋・弾は SpriteRenderer で、生成スクリプト（`HaloSiegeSceneBuilder`）が設定のアリーナから Prefab を作る（既存の Prefab は上書きせず、アリーナと一致するかだけ確かめる）。数の決まらない敵・弾は Prefab の見本を 1 つ目とし、足りなければ見本から増やす。Tick の状態をそのまま描き、補間しない。
- **マウスの位置は、前のフレームのカメラ（画面に見えていた位置）でアリーナの座標に直す。** マウスを動かさなくても、カメラが動けば照準点は動く。プレイ中は OS のカーソルを隠し、照準カーソルを描く。HUD のボタンの上で押したクリックは撃たない。
- 被弾の後の無敵は、自機を半透明で点滅させる（消すと被弾の直後に見失う）。狙い中の Lancer は突進の通り道を筋で示す。
- 自動操縦（`Autopilot`）は App に置き、照準（いちばん近い敵の少し先）と移動（9 通りの向きから数 Tick 先の敵との隙間が広いもの）を別々に決める。撮影台本とテストで共有する。
