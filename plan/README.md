# Unityゲーム制作100本ノック v1.1 — 制作仕様書セット

**確定版100題材**を、1題材1Markdownの独立仕様書にまとめました。v1.0からのジャンル拡張を反映したv1.1を採用し、番号は確定リストのままです。

## 構成

- `games/001-pong.md` ～ `games/100-systemic-action.md`：各題材の制作仕様書（計100ファイル）
- `INDEX.md`：全100題材へのリンク、難易度、対応するPhase
- `progress.csv`：進捗管理用台帳（UTF-8 BOM付き、Excelでも開きやすい）
- `docs/COMMON_RULES.md`：全題材の品質ゲート・共通技術方針
- `docs/WORKFLOW.md`：着手から完了までの標準手順
- `docs/CHANGELOG.md`：v1.0 → v1.1 の置換記録

## 推奨する進め方

1. `INDEX.md`から番号を選び、各仕様書のIn scope/Out of scopeを確認。
2. `docs/COMMON_RULES.md`を読み、題材に必要なルールと非機能目標を着手前に固定。
3. 先にCoreとそのテストを作り、後からUnityの描画・演出を接続。
4. `Core → Playable → Verified`の3ゲートを満たしたら1本完了。
5. `progress.csv`でステータス、所要時間、課題、コミット等を記録。

## 重要な考え方

- **ゲームの規模は小さく、ルール実装は正確に**。コンテンツ量より検証可能性を優先します。
- 各ファイルは実装前の「着手可能な仕様」であり、原作の完全再現仕様ではありません。
- 実装方式や厳密なルールの差異は`着手前に固定する事項`で決め、差異を記録します。
- すべての100本を一律に過剰設計せず、適切な責務分離を学習目標にします。
- 画像・音声などの第三者アセットは許諾・ライセンスを確認して使用します。
