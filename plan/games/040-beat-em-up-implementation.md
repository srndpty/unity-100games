# 040 ベルトスクロールACT 実装計画

## Context

- 040 ベルトスクロールACT（難易度 3・Phase 2）は未着手。仕様書 [plan/games/040-beat-em-up.md](040-beat-em-up.md) の中心課題は「**疑似3Dの奥行きと描画順**」、重点は「**攻撃範囲の深さ方向判定**」。
- In scope：1 面・敵 3 種＋ボス、奥行き移動と近接コンボ、敵の同時出現制限、タイトル→操作説明→勝敗/結果→再プレイ。Out of scope：ローカル 3 人協力、多数武器（武器は作らない）、素材・面の量産。
- 題材固有テスト：**異なる奥行きの敵には当たらない／敵の攻撃権が偏らない／倒れた敵が再攻撃しない**。完了判定：**1 面をクリア可能**、**多敵時に移動/攻撃が安定**。
- ユーザーと決めたこと：
  - **区画ロック方式**：1 面を 4 区画＋ボス区画に分け、区画で画面が止まり、敵の波を全滅させると「GO →」で先へ。
  - **攻撃の幅**：3 段コンボ（3 段目でダウン）＋掴み（膝・投げ）＋ジャンプ攻撃＋体力を払う全方向の緊急技（囲まれ対策）。
  - **残機 3・その場で復帰**（無敵付き）、残機 0 で敗北。制限時間なし。
  - **見た目は生成ドット絵**で始め、試遊後に差し替えを検討。
- 作品名はオリジナル（仮）：**SOOT ALLEY**。参考作品の名称・キャラ・演出は使わない。
- 作業は `main` から `feature/game040` を切る。この計画は session 0 で `plan/games/040-beat-em-up-implementation.md` に置き、ルールの正は作品 README の「採用ルール」とする。
- 039 の技表（`Moves.txt` と `MoveTable` の読み込み・検証、発動ごとの 1 ヒット、ヒットストップ、時刻つき入力）の方式を下敷きにする。共通化は 2 題目なので行わず、040 用に奥行きを足して写して直す（3 題目が出たら `packages/` 抽出を検討）。

## ルール表（セッション1・2で README に固定する要点）

| 項目 | 採用ルール |
|---|---|
| 時間 | 60 Tick/秒。入力は起きた時刻を含む Tick に反映（022・037・039 の時刻つき入力、フレーム単位の Tick 上限） |
| 座標 | 整数、1 px = 256。**x：横（面の進行）、z：奥行き（帯の中、0 が手前）、y：高さ（ジャンプ・吹き飛び）**。z は帯 `[ZMin, ZMax]` に、x はカメラの左右端と区画の端に制限 |
| 画面への投影 | 画面 X = x、画面 Y = z × `DepthNum` / `DepthDen`（整数比、既定 1/2）＋ y。投影は Core の 1 つの関数（`Projection`）で、描画と撮影もそれを使う |
| 描画順 | **z の大きい（奥の）順に描き、同じ z は実体の番号順**（決まった順）。高さ y は順に影響しない（跳んでも手前に出ない）。順序は Core の `DrawOrder` が返し、Unity は sortingOrder に写すだけ。影は地面（y = 0）の位置に、実体より先に描く |
| 判定箱 | 箱は x・y の矩形＋奥行きの幅 `[z − Depth, z + Depth]` の 3 軸。**攻撃箱 × 喰らい箱は 3 軸すべてが重なったときだけ成立**（端ちょうどは触れない、半開）。掴み箱 × 被掴み箱、押し合いも同じく 3 軸。向き（左右）で x を反転 |
| プレイヤー | 8 方向移動（z は x より遅い）、J 攻撃、K ジャンプ、L 緊急技。状態：`Idle / Walk / Attack(段・発生・持続・硬直) / Jump / JumpAttack / Grab / GrabKnee / Throw / Special / HitStun / Knockdown / Wakeup / Dead / Respawn` |
| コンボ | J で 1 段目。各段の**受付窓（持続〜硬直の前半）に J が来たら次段**へ。**次段はヒットしたときだけ繋がる**（空振りは 1 段目からやり直し）。3 段目はダウンを奪う。受付窓の前の押下は先行入力 `BufferTicks` で保持 |
| 掴み | 歩いて敵に押し合いで触れ、奥行きの差が `GrabDepth` 以内、相手が立ち・ヒット硬直中なら掴む（ダウン中・空中・攻撃の発生後・ボスの突進中は不可）。掴み中 J で膝（最大 2 回）、3 回目か前後＋J で投げ（ダウン）。`GrabTicks` で離れる。投げた敵は他の敵に当たらない（多数武器と同様に範囲を広げない） |
| ジャンプ攻撃 | 空中で J。着地まで 1 回。当たるとダウン。奥行きは跳んだときの z のまま |
| 緊急技 | L。全方向（左右・奥行き）の攻撃、発生まで無敵、体力 `SpecialCost` を払う（体力 `SpecialCost` 以下なら出ない＝自分で倒れない）。当たれば攻撃中の敵の攻撃は打ち消す |
| ヒット | 攻撃箱が喰らい箱に重なった最初の Tick に 1 回。**同じ技の発動 1 回につき 1 体に 1 ヒット**（039）。緊急技は複数の敵に同時に当たる（各 1 ヒット）。ダメージ・ヒット硬直・ノックバック・ヒットストップ |
| ダウン | ダウン（吹き飛び→倒れ→起き上がり）の間、喰らい箱・被掴み箱・攻撃箱は無い。起き上がり後 `WakeupInvuln` Tick は喰らい箱なし。**体力 0 の敵は倒れた後に消え、以後の攻撃・攻撃権の要求をしない** |
| ヒットストップ | 当てた側と当たった側だけ `HitStop` Tick 止まる（他の敵は動き続ける：多敵で全体が止まり続けないように）。止まり中も入力履歴と先行入力は積む |
| 敵 | 3 種：**雑魚（素早い 2 段パンチ）**、**重量（遅い・体力多い・強い打撃、1 段目の打撃には怯まない）**、**跳び蹴り（距離を取り、奥行きを合わせて跳び蹴り）**。ボス：**突進（同じ奥行きへ合わせてから直進）＋掴み投げ＋連打**、体力大、体力の半分でダウン後に速くなる。敵の技も技表に置く |
| 敵の行動 | 状態：`Approach（周りの位置取り）/ Wait（攻撃権待ち、間合いの外を回る）/ AlignDepth / Attack / Retreat / HitStun / Knockdown / Dead`。行動の選択は敵ごとの乱数系列（試合のシードから番号で分ける、015） |
| **攻撃権** | `AttackDirector`：同時に攻撃に入れる敵は `MaxAttackers`（既定 2、ボスは別枠 1）。権利は **待った Tick の長い順、同じなら番号順**に与え、攻撃が終わったら返して `Cooldown` 後に再要求できる。ヒット硬直・ダウン・死亡・区画の終わりで**直ちに返す** |
| 同時出現制限 | 区画の波は待ち行列。画面に出ている敵は `MaxActiveEnemies`（既定 4）まで、空いたら次を左右の画面外から出す。上限は設定の検証で敵の配列の容量以下に限る |
| 区画 | `Stage.txt`：区画ごとの x 範囲、波（敵の種類・出る側・z・遅延 Tick）。区画の敵を全滅させると右端のロックが外れ「GO →」。最後の区画はボスと護衛、ボス撃破で面クリア |
| 残機 | 残機 3。体力 0 でダウン→その場で `RespawnInvuln` Tick 無敵で復帰（体力全快）。残機 0 で敗北。敗北・クリア後の入力は状態を変えない |
| 得点 | ヒット・撃破で加点（結果に表示）。外部ランキングなし |
| 1 Tick の順序 | ①入力を履歴へ ②出現（待ち行列から空きへ） ③攻撃権の返却と付与 ④各実体の状態を進める（ヒットストップ中の実体は残りを 1 減らすだけ） ⑤押し合い・帯と画面の端 ⑥掴み判定 ⑦攻撃判定（全組を集めてから同時に適用、相打ちあり） ⑧死亡・区画・面の判定。README とテストで固定 |
| 乱数 | 敵の行動のぶれだけ `SeededRandom`。1 試合 = 1 シード、再戦は起動時の値から進めた新しいシード（010） |
| 操作 | 矢印/WASD 移動、J 攻撃、K ジャンプ、L 緊急技、Esc 一時停止、F1 判定箱（奥行きの帯も描く）。フォーカス喪失で一時停止し、先行入力を捨てる |

## セッション1：判定と技表とプレイヤー（Core）

- `DepthBox`（x・y の矩形＋z の幅、半開の 3 軸重なり）、`Projection`・`DrawOrder`
- `MoveTable`（039 の書式に `depth` と `next`（コンボの次段）・`window`（受付窓）・`knockdown`・`armor` を足す。発生 ≥ 1、Tick ごとの箱の数の一致、次段の存在、箱が有限で大きさ > 0 を検証）、`Assets/Game/Data/Moves.txt`（プレイヤー・敵 3 種・ボス）
- `Actor`（状態・残り Tick・位置 x/y/z・速度・向き・体力・発動番号・ヒットストップ）、`PlayerBrain`（入力 → 状態機械）、`CombatResolver`（全組の掴み・攻撃を集めて同時に適用）
- `Brawl`（世界：プレイヤー・敵の固定容量の配列・`Hash`・`Clone`）、`FrameLog`

### テスト（セッション1）

- **奥行き**：x・y は重なるが z の差が幅ちょうど（触れない）・1 単位内側（当たる）・外側の境界。跳んでも z は変わらず、奥の敵にジャンプ攻撃が当たらない。緊急技も奥行きの幅の外には当たらない。掴み・押し合いも同じ境界
- **描画順**：z の順・同じ z は番号順・跳んだ実体の順が変わらない・2 体が入れ替わる Tick で順が切り替わる
- **技表のログ照合**：全技を中立から出し、発生・持続・硬直とヒット時の硬直差が `Moves.txt` と一致。README の技表は `Moves.txt` から生成した表（039）
- **コンボ**：ヒットで 2・3 段目が繋がる、空振りでは繋がらない、受付窓の境界、先行入力が 1 回だけ効く、3 段目でダウン
- **掴み**：条件の境界（奥行きの差・相手の状態）、膝 2 回→投げ、時間切れで離す、ダウン中・空中・ボスの突進中は掴めない
- **緊急技**：発生までの無敵、体力 `SpecialCost` 以下で出ない、複数の敵に各 1 ヒット
- 多重ヒット防止（持続中に重なり続けても 1 ヒット、次の発動では再ヒット）、ヒットストップ中の更新順と止まらない第三者
- 同じ入力列の最終ハッシュが .NET と Mono で一致。ハッシュは止まり・先行入力・保持中の入力・発動番号まで（022・039）

## セッション2：敵・攻撃権・区画・残機（Core / App）

- `EnemyBrain`（3 種＋ボス、位置取りは攻撃権のない敵が間合いの外の円周上の空き位置へ）、`AttackDirector`、`SpawnQueue`、`StageData`（`Stage.txt` の読み込み・検証）、`Run`（区画・ロック・残機・得点・クリア/敗北）
- App：`BrawlFlow`（Title / Intro / Playing / Go / Paused / Result、時刻つき入力、フレームの Tick 上限）・`Autopilot`（攻撃権のある敵へ奥行きを合わせて殴る、撮影・テスト共有）・`Intent`

### テスト（セッション2）

- **攻撃権が偏らない**：4 体が待つ場面で `MaxAttackers` を超えない、各敵が `MaxAttackers` 回の付与の間に必ず 1 回は権利を得る（待ち時間の上界）、長い通しで付与回数の差が上限内、権利を持つ敵が怯む・倒れる・区画が終わると直ちに返る
- **倒れた敵が再攻撃しない**：攻撃の発生前・持続中に倒した敵の攻撃箱が消え以後ヒットしない、ダウン中・死亡後に攻撃権を要求しない、体力 0 の敵が配列から抜けて出現枠が空く（一度出してから消えることを確かめる、038）
- **同時出現制限**：波の敵が上限を超えて出ない、倒すと次が出る、波の残りがある間は区画が終わらない
- 区画のロックと GO、ボス撃破でクリア、残機 0 で敗北、復帰の無敵の境界、敗北・クリア後の入力無視、重複した撃破イベントで二重加点しない
- 設定・データの負テスト：`MaxActiveEnemies` 0・容量超え、未知の敵の種類、z が帯の外の出現、空の区画
- 操縦役で 20 シード全部が規定 Tick 内に面クリア、入力なしは敗北。人寄りの操縦役（反応を遅らせキー入力に丸める）のクリア率を記録して難易度を決める（038）
- 再戦で新しいシード・状態の初期化、30〜240fps・不規則な間隔で同じ入力のハッシュ一致、フォーカス喪失で先行入力を捨てる
- **多敵の安定**：`MaxActiveEnemies` を最大許容値にした長い通しで、実体の配列の上限・攻撃権の上限・帯の外へ出ないことを不変条件として毎 Tick 検査

## セッション3：Playable（Unity）

- `SootGame`・`SootStage`（区画の背景・出現位置の Prefab と Core のデータを `Mismatch` で照合、種類と位置まで、023）・`SootSettings`（ScriptableObject：受付窓・攻撃権の数・出現上限・敵の強さ・音量）・`SootInput`（PassThrough・物理キーごと・時刻つき、032・037）・HUD（体力・残機・得点・ボスの体力・GO →・結果）・音（出来事の累計から取り出す、039）・`SootSceneBuilder`・撮影台本
- 実体の表示はプールした SpriteRenderer。sortingOrder は `DrawOrder` から、影は別の層。姿勢は Core の状態とフェーズの Tick から毎回決め、補間しない（029）

- F1 で判定箱と奥行きの帯を色分けして重ねる。撮影でも 1 枚
- 撮影台本（Tick で進める）：タイトル、操作説明、区画 1 の乱戦、コンボのヒット、奥行きがずれて空振り（判定箱表示）、掴み・投げ、緊急技、GO →、ボス戦、クリア結果、敗北結果
