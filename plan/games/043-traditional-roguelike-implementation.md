# 043 伝統的ローグライク 実装計画

## Context

- 仕様書 [plan/games/043-traditional-roguelike.md](043-traditional-roguelike.md) の中心課題は「**行動を統一ターンスケジューラで処理**」、重点は「**視界／既知マップを別管理**」。
- In scope：自動生成 5 階層・敵 5 種、ターン制移動・視界、拾う／使う／投げる、タイトル→操作説明→結果→再プレイ。Out of scope：数百アイテム、オンライン。
- 題材固有テスト：**無効操作で敵ターンが進まない／視界外の情報を UI に出さない／同一シード・操作列で地形・結果一致**。完了判定：**5 階突破または死亡まで／乱数再現テスト合格**。
- ユーザーと決めたこと：**テンキー 8 方向＋矢印/WASD（Shift で斜め）、マウスなし**、追加要素は**満腹度だけ**（未識別・装備は入れない）、**死んだら終わり・5 階の階段を降りたら勝利**（どちらも結果画面→タイトル→新しいシードで再挑戦）。
- 作品名はオリジナル（仮）：**MIRE LANTERN**。参考作品の名称・敵・アイテム名・演出は使わない。
- 作業は `feature/game043`（042 のマージ後に main から切る）。ルールの正は作品 README の「採用ルール」。

## ルール表（セッション1・2で README に固定する要点）

| 項目 | 採用ルール |
|---|---|
| 盤 | 1 階 = 48×26 マスの格子（全体が 1 画面、右に HUD）。部屋と通路の 2 種の床、壁、階段。整数と行動時間だけで書き、浮動小数点を使わない |
| **地形生成** | 3×3 の区画に部屋を 6〜9 個（空き区画は通路の交点）。区画の全域木で通路をつなぎ、余分な通路を 1〜2 本足す。階段・自機・敵・品の位置を部屋の床から引く。生成後に「全ての床が自機から到達可能」「階段が自機の部屋と別」を検証し、満たさなければ同じ系列で引き直す（回数の上限を置き、超えたら例外。テストで上限に届かないことを確かめる） |
| **乱数の系列** | 試合シードから用途別に派生（015・041 の `GameRng.For…` 方式）：**地形 = (シード, 階)**、配置 = (シード, 階)、戦闘・敵の考え = (シード, 階) の別系列。地形は自機の行動に依らず階ごとに同じ（「同じシードなら別の操作でも同じ地形」をテスト） |
| **統一ターンスケジューラ** | 全ての行動者（自機・敵）が「次に動ける時刻」（long）を持つ。最小の時刻の行動者が 1 行動し、行動の重さ（通常 100、速い敵は 50、遅い敵は 200）を足す。同時刻は**自機が先、敵は出現番号順**。満腹度・自然回復も自機の行動の時刻で数える。自機の番で Core は止まり、コマンドを待つ |
| **無効操作** | 壁・角抜け（斜めの両脇のどちらかが壁）への移動、足元に品がないのに拾う、空の枠を使う、階段でないのに降りる、終了後の全操作は **`Rejected(理由)` を返し、時刻・乱数・満腹度・状態ハッシュを変えない**。向きだけ変える（Ctrl＋方向）は時間を使わない有効操作 |
| 移動 | 8 方向 1 マス。斜めは両脇の壁で塞がれる。敵のいるマスへの移動＝攻撃。品の上に乗ると自動で拾う（持ち物が満杯なら拾わず案内）。足踏み（テンキー 5／Space）は 1 行動 |
| **視界** | **対称シャドウキャスティング**（整数の傾きの分数で計算）、半径 8。壁は見えるが先を遮る。毎回の自機の行動の後に再計算 |
| **既知マップ** | `KnownMap` は視界と別の構造：見たことのある地形（マスごとの「見た」印と地形）と、**最後に見たときの品**（記憶なので古いことがある）。敵は**今見えているものだけ**。巻物（地図）は地形と階段だけを既知にし、品・敵は明かさない |
| **UI に出す情報** | Unity は `Run` を直接読まず、Core の `PlayerView`（既知マップ・記憶の品・**視界内の**敵・自機の能力・持ち物・視界内で起きた出来事）だけを描く。メッセージも視界内の出来事からだけ作る（視界外の敵の攻撃の外れ・拾う・眠る等は出さない） |
| 自機 | HP 最大 20 から、攻撃・防御、レベル（経験値の表、上限 10）。自然回復：一定の行動ごとに HP 1 |
| **満腹度** | 最大 100、自機の 10 行動ごとに 1 減る。0 で毎行動 HP 1 減り、HP 0 で死亡（餓死）。食べ物で回復（上限 100）。残り 20・0 で案内 |
| 戦闘 | 命中 90%（敵も同じ）、ダメージ `攻撃 × (87〜112)/100 − 防御/2`（最低 1、整数）。HP 0 で消え、経験値を得る |
| 敵 5 種 | ①**すばしこい小獣**（速さ 50、弱い）②**重い岩人形**（速さ 200、強い）③**射手**（同じ直線 8 方向・射程 6・間に遮蔽なしで射つ）④**盗っ人**（隣で持ち物を 1 つ盗んで逃げる、倒すと落とす、盗んだ後は追わない）⑤**眠りの大蛇**（部屋で眠って出る、自機が隣に来るか攻撃されると起きる、強い）。階ごとの出現表（深いほど強い種）。視界に自機が入れば追跡（距離の幅優先探索）、見失ったら最後に見た位置へ、それもなければ部屋を巡回。敵は自機と同じ視界の対称性を使う |
| アイテム（8 種） | 回復薬（HP 回復）、毒薬（使うと自分に害・投げると敵に害）、眠り薬（投げると敵を眠らせる）、パン（満腹 +50）、大きなパン（+100）、石（投げて固定ダメージ）、巻物：地図（既知マップに地形と階段）、巻物：瞬間移動（同じ階のランダムな床へ）。持ち物 16 枠 |
| 投げる | 向いている方向へ最大 10 マス、最初の敵か壁で止まる。敵に当たれば効果（薬は割れる、石はダメージ、他は 1 ダメージ）して消える。外れたら手前の床に落ちる（埋まっていれば近い空き床、階の品の上限あり）。投げは 1 行動 |
| 階段・勝敗 | 階段の上で `>`（または Enter）で次の階。新しい階は (シード, 階) の地形。**5 階の階段を降りたら勝利**、HP 0 で死亡。結果画面：勝敗・到達階・行動数・レベル・倒した数・死因 → タイトル。再挑戦は新しいシード（起動時の値から試合ごとに進める、010） |
| 状態ハッシュ | 地形・自機・敵・品・既知マップ・スケジューラの時刻・満腹・乱数の状態・データの指紋を混ぜる（022・040） |

## セッション1：地形・視界・既知マップ・スケジューラ（Core）

- `FloorGrid`（地形の格子）、`FloorGenerator.Generate(rng, floor, config)`（部屋と通路・配置・検証・引き直し）
- `Fov.Compute(grid, origin, radius, visible)`（対称シャドウキャスティング、整数の分数）、`KnownMap`（見た印と記憶の品）
- `TurnScheduler`（行動者の次の時刻、同時刻の順序、行動の重さ）
- `CrawlRun`（試合：Step(Command) → `Accepted`/`Rejected`、Clone、Hash）、`Command`（Move・Face・Wait・Pickup・Use・Throw・Descend）、`CrawlConfig`（検証付き）
- `RunRng`（用途別の系列の派生、041 `RngStream.cs` を写す）

### テスト（セッション1）

- **無効操作で敵ターンが進まない**：壁・角抜け・空の拾う・階段外の降りる・終了後の操作のそれぞれで、時刻・敵の位置・乱数の状態・満腹度・ハッシュが変わらない。続けて有効操作をすると敵が動く（裏も確かめる）。速い敵がいても同じ
- **地形の再現**：同じシードで全 5 階の地形が一致、操作列が違っても同じ階なら同じ地形、シードを変えると地形が変わる（019 の多様さ）。全床の到達性・階段の位置を多数のシードで検証、引き直しの上限に届かない
- 視界：素朴な参照実装（全マスへの線分が遮られないか、対称性：A が B を見る ⇔ B が A を見る）と乱数の盤で照合、半径の境界、壁の角
- 既知マップ：見たマスだけ既知、視界を離れても地形は残る、品の記憶は古いまま（見えない所で品が消えても記憶は残る）、巻物（地図）は地形だけ
- スケジューラ：速さ 50/100/200 の行動回数の比、同時刻の順序、時刻の桁（long）

## セッション2：敵・戦闘・アイテム・App

- Core：`Actor`（自機・敵）、`MonsterKind` 5 種の考え（追跡・射撃・盗む・眠り）、`Combat`、`Leveling`、`Hunger`、`ItemKind` 8 種と `Inventory`、投げの軌跡（`Vec2i` の 8 方向）、階段・勝敗・結果、`GameData`（敵・品・出現表を TextAsset のテキスト表で持ち、041 `GameDataValidator` の方式で理由付き検証、040 `Fingerprint.cs` の方式で指紋）
- `PlayerView`：Run から既知・視界内だけを写した読み取り専用の窓口（032・042：可変の部品を公開しない）、`RunEvent` に「自機が見た／聞いた」フラグを付けて視界外を落とす
- App：`CrawlFlow`（Title / HowTo / Playing / Inventory / ThrowAim / Paused / Result、意図の列を 1 本で処理 012）、`MoveRepeater`（押しっぱなしの連続移動、押したフレームの deltaTime を含めない 012）、`MessageLog`、`Autopilot`（既知マップの未探索の境界へ幅優先探索、隣の敵を攻撃、HP が低ければ回復薬、空腹ならパン、射手には石を投げる、階段が既知になり探索し終えたら降りる）と人寄りの操縦役

### テスト（セッション2）

- **視界外の情報を UI に出さない**：視界外の敵・品の変化・出来事が `PlayerView` とメッセージに出ない、見えた瞬間に出て離れると敵は消えて地形と品の記憶は残る、盗っ人が視界外で逃げても位置を出さない、巻物（地図）で敵・品が出ない。`PlayerView` の全公開メンバーを列挙して既知/視界の範囲外の座標を含まないことを乱択の局面で確かめる
- **同一シード・操作列で結果一致**：操縦役の操作列を記録して再生し、最終ハッシュと結果が一致。シード 1 のハッシュを固定値として .NET と Mono で照合（013）
- 戦闘・レベル・満腹（10 行動ごと・0 での減少・餓死）・自然回復の境界、投げ（壁で止まる・敵に当たる・落ちる場所が埋まっている）、盗む→倒すと落とす、眠りの起床条件、射手の遮蔽
- 状態遷移：タイトル→プレイ→結果→タイトル→新しいシード、結果の後の入力を無視、持ち物を開いている間は時刻が進まない、満杯で拾えない
- 負テスト：データの重複 ID・未定義の参照・重みの合計 0 と int 超え（041）、設定の範囲外
- 操縦役：20 シードで「5 階突破または死亡」まで必ず決着する（上限行動数以内）、勝率を記録（目安を決めて調整）

## セッション3：Playable（Unity）

- `LanternGame`（Flow の駆動）、`LanternInput`（物理キーごとのアクション：テンキー 1〜9、矢印/WASD、Shift、Ctrl、G、I、T、`>`/Enter、Esc。035/037/042 の教訓で最初からキーごと）
- Stage Prefab：Tilemap（床・壁・階段）、プレイ前は (シード 1, 1 階) の地形を焼いて Scene ビューで見える（AGENTS の方針）。実行時は `PlayerView` から**既知のマスだけ**塗り、視界外の記憶は暗く、記憶の品は半透明

- 音：出来事（攻撃・命中・外れ・拾う・食べる・投げる・階段・被弾・死亡・勝利）の累計の差から（039）、控えめな音量・バッチで消音
- `LanternSettings`（ScriptableObject：音量・連続移動の待ち・滑りの時間）、`LanternSceneBuilder`・`LanternArtGenerator`（042 の `AshenSceneBuilder`・`AshenArtGenerator` を写す）、撮影台本（タイトル、操作説明、1 階の開始と視界、探索後の既知マップ、戦闘とメッセージ、持ち物、投げる、空腹の案内、深い階、死亡の結果、勝利の結果）
