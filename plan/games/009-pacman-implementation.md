# 009 Pac-Man 実装計画

## 採用方針

参考作品のメカニクスだけを採用したオリジナル作品「NIBBLE MAZE」。夜の食料庫でネズミがパン屑を集め、猫4匹（トラ・ミケ・クロ・シロ）をかわす。マタタビを取ると猫が逃げ、触れると寝床へ帰る。迷路は29×15マスの独自レイアウト1面。残機3、全餌の取得で勝利。ルールの詳細は[作品のREADME](../../games/009-pacman/README.md)に固定した。

## 実装

- Coreは整数のみで計算する。1マス=600単位、速度は0.1マス/秒単位、時間は60HzのTick。迷路はグラフとして持ち、構築時に行き止まりや孤立通路を検証する。
- 猫の追跡先は `ITargetSelector` の4実装で差し替える。分岐は逆走を除く通行可能方向から目標に最も近いものを選び、逃走時はシード付き乱数で選ぶ。
- 1Tickを4つの部分ステップに分け、自機移動→餌→勝利判定→猫の移動→接触判定の順に処理する。接触は部分ステップ内の軌跡どうしで判定する。
- Appはタイトル・進行・停止・結果、時間変換、保留入力を担当する。操縦役 `Autopilot` はテストと撮影で共有する。
- Unityは図形から描き出したPNGとStage Prefabで盤面を組み立て、HUDはPanelRenderer、設定はScriptableObjectに分離する。
- Unity 6000.6.9f1、Universal 2D、Windows、16:9基準。物理エンジンへの委譲なし。

## 検証と引き渡し
