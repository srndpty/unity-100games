# 032 タイピングゲーム 実装計画

## Context

- 032 タイピングゲーム（難易度2・Phase 2）が未着手。仕様書 [plan/games/032-typing.md](./032-typing.md) の中心課題は「**入力文字列と表示文を分離**」、重点は「**ひらがな入力規則は採用方式を仕様固定**」。In scope：敵と対応する単語 50 種、正誤入力・連続正解、難度段階と結果表示、タイトル→操作説明→結果→再プレイ。Out of scope：オンライン対戦、全 IME 変換方式。
- 題材固有テスト：誤字で進行しない／複数敵のターゲットが混線しない／バックスペースの扱いが規則通り。完了判定：50 単語が出題可能、クリア・失敗を一貫処理。
- ユーザーと決めたこと：
  - **表示文（漢字かな交じり）＋読み（ひらがな）を、ローマ字で直接打つ**。複数の綴り（shi/si、tsu/tu、ん、っ、拗音など）を受け付け、打った綴りに合わせて案内を変える。IME は使わない。
  - **Backspace＝狙いの解除**：誤字は入力されないので消す文字はない。Backspace で今の狙いを外し、その敵の打鍵の進み具合を最初に戻す。
  - **2D 奥から迫る**：敵が画面の奥から近づいて大きくなる疑似奥行き。手前の線に着くと被弾。
  - **難度選択＋規定数撃破**：タイトルで やさしい／ふつう／むずかしい を選び、規定数を倒せばクリア、体力 0 で失敗。

作品名はオリジナル（仮）：**INK VIGIL**。参考作品の名称・素材・演出は使わない。
この計画は着手時に `plan/games/032-typing-implementation.md` として保存し、各セッションの結果を追記する（025〜030 と同じ）。

## セッション1：ルール表（README に固定）と Core / App

### ルール表（要点）

| 項目 | 採用ルール |
|---|---|
| 時間 | 60 Tick/秒の整数。敵の距離は整数（奥 = 10000、手前の線 = 0）。浮動小数点を使わない |
| 打鍵 | 受け付ける記号は `a`〜`z` と `-`（長音「ー」）と Backspace。物理キーを読み（Input System の Key）、IME と配列の文字変換を通さない。大文字小文字は区別しない |
| ローマ字の綴り | かなを「区切り」（1〜3 かな）ごとの綴りの候補の表で受け付ける（下表）。区切り方が複数ある読み（「きゃ」＝kya ／ ki+xya）も全て並べ、打った文字と矛盾しない道筋だけを残す。どの道筋でも続かない文字は**誤字** |
| ん | `nn`・`xn` はいつでも可。単独の `n` は、次の区切りの綴りが母音・`y`・`n` で始まらないときだけ（「ん＋次」を 1 区切りの候補として作る）。語末の「ん」は `nn`/`xn` のみ |
| っ | 次の区切りの綴りの先頭子音を重ねる（`kka`、`tchi` は不可で `cchi`）。母音・`n` 始まりの前は不可。単独は `xtu`・`ltu`・`xtsu`・`ltsu` |
| 主な別綴り | し si/shi/ci、ち ti/chi、つ tu/tsu、ふ hu/fu、じ zi/ji、しゃ sya/sha、ちゃ tya/cha/cya、じゃ zya/ja/jya、を wo、小書き x/l 始まり、ー `-` |
| 誤字 | 進行しない。誤字数を数え、連続正解（コンボ）を 0 に戻す。狙いは保つ |
| 狙い | 狙いがないとき、打った 1 文字を受け付ける敵のうち**最も手前（距離が小さい）**、同距離は出現順の早い敵を狙う。受け付ける敵がなければ誤字。狙いがある間は、打鍵はその敵にだけ効く（他の敵は進まない）。打ち切ると撃破し狙いが外れる |
| Backspace | 狙いがあれば外し、その敵の進み具合を最初に戻す（誤字にもコンボの途切れにも数えない）。狙いがなければ何もしない |
| 出現 | 難度ごとの単語の山をシードで切り、尽きるまで重複なく出す。同時に出ている敵と最初の 1 文字の候補が重ならない単語を山から優先する（重なる場合は上の狙いの規則で決まる） |
| 被弾 | 敵が距離 0 に着いた Tick に体力 −1、その敵は消える（狙っていれば外れる） |
| 勝敗 | 規定数を撃破したらクリア。体力 0 で失敗。同じ Tick に撃破で規定数に達し被弾で 0 になる場合は、**打鍵の反映 → 敵の前進 → 被弾**の順で決める（テストで場面を作る） |
| 難度 | やさしい（短い単語・同時 2 体・到達 9 秒・10 体）／ふつう（同時 3 体・7 秒・15 体）／むずかしい（長い単語・同時 4 体・5.5 秒・20 体）。体力 3。値は設定（既定値は仮、試遊で決める） |
| 得点 | 正しい打鍵 10 × (1 + コンボ/20 の整数部、上限 ×5)、撃破ボーナスは単語のかな数 × 50 |
| 結果 | クリア／失敗、撃破数、正しい打鍵数・誤字数・正確さ（‰ の整数）、打鍵速度（正しい打鍵/分、遊んだ Tick から）、最大コンボ、得点。起動中の難度ごとの最高得点 |
| 乱数 | 1 試合 = 1 シードの `SeededRandom`。単語の山と出現間隔で系列を分ける（015）。再戦は起動時の値から試合ごとに進めた新しいシード（010） |
| 終了後 | クリア・失敗の後の Tick と打鍵は状態を変えない |

### 単語帳（入力文字列と表示文の分離）

- `Assets/Game/Data/words.tsv`（TextAsset）：`表示文<TAB>読み<TAB>段（1〜3）` を 50 行。オリジナルの語（例：「夜明けの鐘」よあけのかね）。表示文は描画だけ、照合は読みだけを使う。
- Core の `WordBook.Parse` が検証：50 行ちょうど、読みが表にあるかなだけ、重複なし、各段の語数が同時出現数以上、全語の照合器が作れる（語末の「ん」・「っ」の位置など）。dotnet のテストも同じファイルを読む。

### Core（`Assets/Game/Core/`）

- `RomajiTable`：区切り → 綴り候補（上表）。「ん＋次」「っ＋次」の結合候補を作る
- `Reading`：読みを区切りの候補の列（NFA）に変換（不正なかなは例外）
- `RomajiMatcher`（値型または再利用バッファ）：生きている道筋の集合 `(かな位置, 候補, 打った長さ)`。`Accepts(c)`／`Type(c)`→ 正しい／誤字／完了、`Typed`（打った文字列）、`Guide`（残りの推奨綴り：今の道筋の続き＋以降の既定綴り）、`Reset()`
- `WordBook`・`WordEntry`（表示文・読み・段）
- `Enemy`（単語・距離・速さ・照合器・出現順）、`Targeting`（狙いの選択と解除）
- `TypingRun`：試合全体。`Type(char)`・`Backspace()`・`Tick()`・`Clone()`・`Hash()`・`StartWith(...)`（テスト・撮影用に敵の配置を指定）、統計と結果
- `VigilConfig`：公開フィールド＋検証（範囲・同時数 ≤ 段の語数・規定数 ≥ 1・到達 Tick ≥ 1 など）。難度 3 段の設定を持つ
- ハッシュに照合器の道筋・狙い・距離・山の残り・乱数の状態・コンボを含める（022）

### App（`Assets/Game/App/`）

- `VigilFlow`：Title / Playing / Paused / Result。打鍵は受け取った順の 1 本の列で処理（012）、フレーム単位の Tick 上限と遊んだ時間の分離（017・022）。フォーカス喪失で保留中の打鍵を捨て一時停止、復帰は手動再開
- タイトル・結果の操作は文字キーと衝突しないキーだけ（↑↓ で難度、Enter 開始／再挑戦、Esc 一時停止・タイトルへ）
- `Typist`（操縦役）：狙いの案内（`Guide`）どおりに一定の打鍵間隔で打ち、シード付き乱数で誤字・Backspace を混ぜられる。撮影・App テスト・PlayMode で共有。試合・再戦ごとに判断状態を捨てる（023）

### テスト（題材固有を優先）

- **誤字で進行しない**：全 50 語の各位置で、受け付けない全文字（a〜z, -）を打っても `Typed`・道筋・敵の状態が変わらず誤字数だけ増え、コンボが 0。誤字の後に正しい文字で続けて打ち切れる
- **ローマ字の照合**：素朴な参照実装（読みの全区切り方 × 全候補を総当たりで文字列に展開）と照合器を比べ、全 50 語で「受理する完全な綴り」と「途中で受け付ける接頭辞」が一致。乱数の文字列でも一致。ん（`kantan` を `kanntann` でも可、`kanna` が「かんな」、`kan'i` 相当の「かんい」に単独 n 不可、語末 n 不可）、っ（`kitte`・`xtu`、母音前不可）、拗音（`sha`/`sya`/`shixya`）の境界例
- **ターゲットが混線しない**：同じ先頭文字の敵 2 体で手前を狙う／同距離は出現順／狙い中に他の敵の単語の文字を打つと誤字で他の敵が進まない／撃破・被弾で狙いが外れた直後の文字は改めて選ぶ／狙っていた敵が被弾で消えた Tick の打鍵
- **Backspace の規則**：狙い中に押すと解除され進み具合が最初に戻る・誤字とコンボに影響しない／狙いなしでは何も変わらない／解除後に別の敵を狙える／連打
- **50 単語が出題可能**：各難度の山が段の語を全て含み、全難度の和で 50 語を網羅。山が尽きるまで同じ語が出ない
- **勝敗の一貫処理**：規定数ちょうどでクリア、体力 0 で失敗、同じ Tick の撃破と被弾の順序、終了後の打鍵・Tick の無視
- 操縦役：各難度で速い打鍵（例 6 打/秒）は 20 シード全勝、遅い打鍵（例 1 打/秒）は失敗する。固定シードの最終ハッシュを .NET と Mono で照合
- 共通：状態遷移（開始→進行→結果→再戦）、負テスト（未定義の文字・範囲外の設定・NaN 相当の値なし＝整数設定・重複イベント）、再現性（同シード同打鍵で同ハッシュ、「今は同じでも以後が分かれる」組で違うハッシュ）、単語帳の検証の負例（49 行・未知のかな・重複・語末の小さい「っ」）

## セッション2・3：Playable と Verification（Unity 層）

- 単語の札（UI Toolkit、PanelRenderer）：敵の頭上に表示文・読み・ローマ字の案内（打った部分は色を変える）。狙い中の札を強調し手前に描く。札の位置は敵の位置から毎フレーム決める
- HUD：体力・撃破数／規定数・コンボ・得点。タイトル（難度選択と操作説明：ローマ字の綴りの例・Backspace の意味）、一時停止、結果画面（統計・最高得点）。作った直後に一度描画、タイトルへ戻ったら Core から作り直す（021）
