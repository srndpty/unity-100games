# 008 Frogger 実装計画

## 採用方針

道路と川の1面。幅11マス、開始岸・道路3列・中間岸・川3列・ゴール岸の9行。安全地帯への1回の横断で勝利、車接触・落水・足場による場外移動で敗北。残機・制限時間・スコアは設けない。方向キー/WASDで1押下1マス、長押しリピートなし。同時入力は上・下・左・右の順で1方向を選ぶ。

## 実装

- Coreは60Hzで方向入力と着地判定→足場確定→物体移動→危険判定。ホップは瞬時の移動で着地先を判定する。車はTick中の掃引と周期コピーで判定し、丸太に乗ったカエルは正規化前の変位を受け取る。カエルをラップさせない。
- Appはタイトル・進行・停止・結果、時間変換と保留入力を担当。停止・遷移・フォーカス喪失で保留入力と端数時間をリセットする。
- Unityはイラスト主体の見下ろし2D。生成素材は保存したスプライトとStage Prefabで組み立て、シーン生成スクリプトは既存Prefabを保持する。HUDはPanelRenderer、設定はScriptableObjectに分離する。
- Unity 6000.6.9f1、Universal 2D、Windows、16:9基準。固定レーン配置で乱数なし。物理エンジンへの委譲なし。
