## DSL（セッション 1 で README に固定する文法の案）

1 行 1 文。`#` 以降はコメント。インデントは意味を持たない（ブロックは `*label` 単位）。

| 文 | 例 | 意味 |
|---|---|---|
| ラベル | `*harbor_night` | 飛び先。ファイル内で一意 |
| 宣言 | `$var clue = 0` / `$var trusted_mio = false` | 変数（int / bool）の宣言と初期値。先頭でのみ |
| 人物定義 | `@char mio 澪 #8fc3e0` | 話者 ID・表示名・名前の色 |
| 背景 | `@bg lighthouse_hall` | 背景を切り替え（ID は素材表と照合） |
| 立ち絵 | `@show mio smile left` / `@hide mio` | 表情・位置（left/center/right） |
| 地の文 | `扉の向こうで、何かが倒れる音がした。` | 1 クリックで送る 1 文 |
| 台詞 | `mio「見なかったことにはできないよ」` | 話者つき。話者は `@char` で定義済み |
| 代入 | `$set clue += 1` / `$set trusted_mio = true` | int は `= += -=`、bool は `=` のみ |
| 条件分岐 | `$if clue >= 2 -> truth_route` | 成り立てばジャンプ（比較は `== != < <= > >=`、bool は `$if trusted_mio -> x`） |
| ジャンプ | `-> act2` | 無条件 |
| 選択肢 | `?choice` に続けて `- 鍵を調べる -> look_key { clue += 1 }` を 2〜3 行、`?end` | 選んだら `{}` の代入を適用してジャンプ |
| 終端 | `@ending truth 真相` | ED の ID と名前。ここで試合終了 |

- コンパイル結果は `Instruction[]`（`Text`・`SetBg`・`Show`・`Hide`・`Assign`・`JumpIf`・`Jump`・`Choice`・`Ending`）と、ラベル → 番地の表。**実行器はパーサの型を参照しない**（アセンブリ内でも名前空間を分け、テストで依存を確かめる）。
- 各 `Text` には**安定した ID**＝「直前のラベル名＋そのラベル内の連番」を付ける。既読はこの ID の集合で持つ（文を挿入するとそのラベル内の後ろの既読は付け直しになる、と README に明記）。

## 検証（`ScriptValidator`、`ScriptError`＝行番号・列・理由）

- **構文**：未知の命令・括弧/引用の不一致・空の選択肢・選択肢 1 個または 4 個以上・`?choice` の閉じ忘れ
- **参照**：**存在しないラベルへのジャンプ／選択肢の飛び先**、重複ラベル、未定義の変数・話者・背景・立ち絵・表情、型の不一致（bool に `+=`、int を条件単独で使う）
- **到達性**：開始からどこにも到達しないラベル・文（デッドコード）を拒否
- **終了性**：**全ての選択の列（3 箇所なので高々 3³ 通り）をたどり、どの経路も `@ending` で終わる**（実行器を使った網羅探索。無条件の循環は「同じ（番地・変数）に戻ったら」で検出して拒否）。宣言された 3 つの ED がそれぞれ少なくとも 1 経路で到達できる
- **テキスト**：空の文、1 文の文字数がテキスト枠の上限（設定値、例 90 字）を超える、未対応の制御文字。話者名の長さ
- **数**：選択肢の箇所数・ED の数を仕様（3・3）と照合（作品の設定として持つ）
- 行数・文の数の上限を展開前に検証（044 の教訓）

## ルール表（セッション 1・2 で README に固定する要点）

| 項目 | 採用ルール |
|---|---|
| 実行器 | `ScriptRunner`：番地・変数・表示状態（背景・立ち絵 3 枠・話者・今の文）・待ち（文／選択）を持つ。`Advance()` で次の待ちまで命令を実行、`Choose(i)`、`Clone`・`Hash`・`Snapshot/Restore`。待ちでない命令（背景・代入・ジャンプ）は 1 回の `Advance` でまとめて流す。**無限の流し**は検証で防ぎつつ、1 回の流しの命令数に上限（超えたら例外） |
| 拒否 | 選択待ちで `Advance`、文の待ちで `Choose`、範囲外の選択番号、終了後の操作は `Rejected(理由)` で状態・ハッシュを変えない（044 の方式） |
| 表示状態 | ロード時に命令を再生せず表示を戻せるよう、背景・立ち絵は Runner の状態として持つ（描画は状態を写すだけ） |
| 文字送り（App） | 1 文を Tick で 1 文字ずつ出す（速さは設定）。表示途中の決定で全文、表示済みで次へ。演出中の入力は 1 本の列（012） |
| **既読** | 文を**表示し終えて送った**時点で既読に記録（表示途中で飛ばした文も送った時点で既読）。選択肢は既読の対象外 |
| **スキップ** | Ctrl 押し続け／S で切り替え。**既読の文だけ**を Tick ごとに送り、**未読の文・選択肢・ED で止まる**（切り替えは解除）。「未読もスキップ」は作らない |
| **クイックセーブ** | F5 で保存・F9 で読み込み（タイトルの「つづきから」も同じ枠）。保存するのは Runner の Snapshot（番地・変数・表示状態・今の待ち）。**選択肢を表示中に保存したら、読み込むと選ぶ前の状態に戻る**（選択の代入は `Choose` の時点で初めて適用されるので、保存時点では未適用） |
| セーブ形式 | 041 の `SaveCodec`：行指向テキスト、版番号・**スクリプトの指紋**・末尾のチェックサム。拒否（切れた・改変・版違い・指紋違い・未知の番地・待ちでない番地・未定義の変数・値域外）は理由付きでタイトルに案内（移行はしない）。書き込みは一時ファイル→原子的置換（041 の `FileSaveStore`） |
| 既読ファイル | `read.txt`：既読 ID の集合と到達 ED。同じ方式（指紋違いなら破棄して案内し、空から始める）。文を送るたびではなく、**選択・ED・タイトルへ戻る・終了時**にまとめて書く（失敗しても遊べ、案内だけ出す） |
| ED と結果 | `@ending` で結果画面：ED 名・到達 ED の一覧（未到達は「？？？」）・タイトルへ。再プレイは最初から（既読は持ち越す） |
| 操作 | クリック／Enter／Space／↓ で送る、↑↓＋Enter かクリックで選択、Ctrl 押し続け・S でスキップ、F5/F9 クイック、Esc で一時停止メニュー（つづける・タイトルへ）、H でテキスト枠を隠す（仕様の範囲を広げない程度、試遊で不要なら外す） |
| フォーカス | フォーカス喪失で押し続けのスキップを解除、復帰直後のクリックは捨てる（010） |

## セッション 1：DSL と実行器（Core）

- `Script/`：`Lexer`（行 → トークン、行番号付き）、`Parser`（構文木 `ScriptAst`）、`ScriptValidator`、`ScriptCompiler`（AST → `CompiledScript`：命令列・ラベル表・Text ID・変数表・素材表・指紋）
- `Runtime/`：`Instruction`、`ScriptRunner`、`RunnerSnapshot`、`RunnerView`（読み取り専用の窓口、043）、`StepResult`/`Rejected`
- `ScriptCatalog`（作品の素材 ID の表：背景・人物・表情。Unity 側の素材と照合するため Core に置く）
- `PathExplorer`：Runner を `Clone` して全選択列を列挙（検証の終了性・到達性と、テストの ED 網羅に共用）

### テスト（セッション 1）

- **存在しないラベル参照の検出**：`-> nowhere`・選択肢の飛び先・`$if` の飛び先のそれぞれで、行番号と理由付きで拒否。綴りの 1 文字違いも拒否
- 検証の負例：上の「検証」の各項目を 1 ケースずつ（重複ラベル・未定義の変数/話者/背景/表情・型の不一致・到達しないラベル・ED のない経路・無条件の循環・文字数超過・選択肢 1 個/4 個・閉じ忘れ）
- 実行器：地の文と台詞・背景と立ち絵の状態・代入と条件（境界 `>=` のちょうど・1 足りない）・選択の代入がジャンプ前に適用・ED で終了・終了後の全拒否・待ちと違う操作の拒否で状態不変
- `Snapshot → Restore` で `Hash` 一致、Restore 後の同じ操作列で最終ハッシュ一致（022）
- 実行器がパーサの型に依存しないこと（リフレクションで `Runtime` 名前空間の参照を確認）

### テスト（セッション 2）

- **未読を既読スキップしない**：既読 2 文 → 未読 1 文 → 既読の並びでスキップすると未読の直前で止まる・未読の文は表示途中から始まる。選択肢と ED でも止まる。押し続けを離すと止まる。1 周目を読んだ後、2 周目は最初の選択肢まで止まらずに進む（分岐後の未読で止まる）
- **ロードで選択前状態復帰**：選択肢を表示中に F5 → 選んで先へ進む（変数・背景が変わる）→ F9 で選択待ち・変数・表示状態・ハッシュが保存時点と一致 → 別の選択肢で別の分岐へ進める。ファイルを経由（Encode → Decode）しても同じ
- セーブの拒否：全切り位置・1 文字改変・版違い・**スクリプトの指紋違い**・待ちでない番地を理由付きで拒否（041）。既読ファイルの破損は空から始めて案内
- 全 27 経路を列挙し、全て ED で終わり、3 ED とも到達。各 ED の代表の選択列で最終ハッシュを .NET と Mono で固定値照合
- 状態遷移：タイトル→はじめから/つづきから→…→ED→結果→タイトル→はじめから（既読は残る、変数は初期化）、結果後の入力の無視、重複した決定で 2 文送らない・選択を 2 回適用しない
- 本番シナリオが検証を通ること（.NET では csproj にコピーしたファイルを読む、Mono は TextAsset）
