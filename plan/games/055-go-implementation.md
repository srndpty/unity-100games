# 055 囲碁 実装計画

## 実装中の変更（下の計画は着手時のもの。現在のルールは作品の README を正とする）

- **RAVE とアタリへの応手**：純粋なランダムのプレイアウトの UCT では、1,000 回でアタリの 4 子を取る手を見分けられなかった。探索に RAVE（AMAF）を、プレイアウトに「直前の手がアタリを作ったら取る・逃げる」を足した。探索項は √N ÷ (1 + n) の整数版（log を使わない）。
- **CPU の考える時間**：1 Tick に 250 回はエディタの Mono（約 4,800 回/秒）でフレームを止める。1 Tick に必ず回す数を 20 にし、Unity はフレームの残り時間でも回す（`GoFlow.Think`）。手は総数だけで決まる。
- **パス**：根では「相手が直前にパスした」か「ほかに手がない」ときだけパスを候補にする（CPU から先にはパスしない）。相手のパスの後、パスで勝っていればパスで終える。
- **投了の対局は計点しない**（死石の確定の画面を通さない）。

## ルール表（セッション 1 で README に固定する案）

### 盤と着手

| 項目 | 採用ルール |
|---|---|
| 盤 | 9 路（81 点）。座標は列 A〜J（I を除く）、行 1〜9（下から） |
| 手番 | 黒が先手。置き石なし |
| 着手 | 空点に置く。置いた後、呼吸点が 0 になった相手の連を全て取り、その後で自分の連の呼吸点を見る |
| 自殺手 | 置いて相手の石を取れず、自分の連の呼吸点が 0 になる手は**禁止**（理由付きで拒否、局面・ハッシュ不変） |
| コウ | 着手後の盤面（石の配置）が、対局中に現れたいずれかの盤面と同じになる手は禁止（positional superko）。単純コウはその特別な場合で、拒否の理由は「コウ」と「同型反復」を分けて返す |
| 同型の判定 | 64 ビット Zobrist ハッシュの履歴で候補を引き、一致したら盤面そのものを比べて確定する（衝突で誤って拒否しない） |
| パス | いつでも可。パスは盤面を変えないので同型反復の対象外 |
| 終局 | 両者が連続してパス／どちらかが投了／手数の上限（既定 300 手）に達した |
| 投了 | プレイヤーは一時停止メニューから。CPU は 30 手目以降に根の勝率が既定 10 % 未満で投了（設定） |

### 計点（中国式の面積・Tromp-Taylor 型）

| 項目 | 採用ルール |
|---|---|
| 死石の確定 | 終局後、MCTS（試合のシード由来の決まった回数）の所有率で相手の地と推定した連に「死」の印を付ける。プレイヤーは連をクリックして生死を切り替え、「確定」で計点。投了・手数上限でも同じ画面を通す（投了は計点を表示するだけで勝敗は投了で決まる） |
| 面積 | 死石を取り除いた盤で、各色の**石の数＋その色の石だけに接する空点の領域**。両色に接する空点（セキの中の空点など）はどちらにも数えない |
| コミ | 白に 7 目。勝敗は「黒の面積 − （白の面積 ＋ 7）」の符号。0 は引き分け |
| アゲハマ | 表示はするが、面積計点なので得点には足さない |

### CPU（MCTS）

| 項目 | 採用ルール |
|---|---|
| 探索 | UCT（UCB1、探索係数は設定）。手番ごとに木を作り直す（前の木は使い回さない） |
| 木の合法手 | 対局の履歴＋木の経路で同型反復まで判定した合法手とパス。自分の眼（四方が自分の石で、斜めが一定以上自分）を埋める手は候補から外す |
| プレイアウト | 軽いランダム：眼埋め以外の合法手から一様に選ぶ（単純コウだけ判定）。合法手がなければパス、2 連続パスか上限手数（81×3）で打ち切って Tromp-Taylor で面積を数える（死石の推定なし）。勝敗（コミ込み）を報酬にする |
| 回数で止める | 強さはプレイアウトの総数で決める（弱い／普通／強い の初期値 500／2,000／8,000、設定アセット）。1 Tick に回す数の上限（既定 250）で分けて回し、画面を止めない。**総数だけで手が決まり、Tick への分け方に依らない** |
| 手の決定 | 訪問回数の最大（同数は点の番号の小さい方）。「考える間」の最小 Tick（既定 30）を置いて打つ |
| 乱数 | `RandomSeries`（試合シード × 手数 × 用途：探索・死石の推定）。手ごとに系列を作り直し、ほかの手の乱数の使用回数に影響されない |
| 表示 | 考え中は進み具合（回数）と根の勝率を HUD に出す |

### 操作

| 入力 | タイトル・結果 | 対局中 | 死石の確定 |
|---|---|---|---|
| 左クリック | ボタン | 交点に打つ（打てない点は理由を表示） | 連の生死を切り替え |
| 矢印 / WASD | 強さ（左右）・手番（上下） | カーソル移動（キーを使うまで出さない） | カーソル移動 |
| Enter / Space | 開始・もう一度 | カーソルの点に打つ | カーソルの連を切り替え |
| P / ボタン | — | パス | — |
| Esc | — | 一時停止（再開・投了・タイトルへ） | 確定（ボタンでも） |

- CPU の手番・演出中のクリックとキーの着手は入力の受付（App）で捨てる（015・016）。フォーカスを失ったら一時停止（手動で再開）。復帰直後のクリックは捨てる。押した画面の版を意図に持たせ、当てはめる直前に照合する（044）。
- 時間は 60 Hz の固定 Tick。石を置く・取る演出は短く（既定 12 Tick）、パスの通知 60 Tick。

## テスト（主なもの）

### 題材固有

- **自殺手を拒否**：1 子の自殺・複数子の連の自殺・盤の隅と辺。相手を取れば呼吸点 0 の点でも合法（取った後に呼吸点ができる）。拒否で盤・手番・ハッシュ・履歴が変わらない。
- **単純コウの即時取り返し禁止**：コウを取った直後の取り返しを「コウ」で拒否、1 手よそに打った後は合法。打って返し（1 子を取らせて 2 子以上を取り返す）はコウではなく合法。三コウなどの循環を「同型反復」で拒否。パスを挟んでも盤面が同じなら拒否。
- **取り石後の呼吸点数一致**：差分更新した全ての連の呼吸点数・石の集合・連の番号が、毎回盤から塗りつぶしで数え直した参照実装と一致する（手作りの局面＋多数シードの乱択対局の全局面）。取った石の数の累計がアゲハマと一致する。

### ハッシュと合法手（中心課題）

- Zobrist の差分更新が、全局面で盤から作り直したハッシュと一致（乱択対局）。
- 衝突への対策：わざと衝突させた表（テスト用に差し込む）で、盤面の比較により誤った拒否が起きない。
- 合法手の列挙が、全ての空点に `Check` を当てた結果と全局面で一致（047 の知見）。
- 状態ハッシュ（`StateHash`）：「今の盤は同じでも履歴が違う（以後の同型反復が変わる）」組で違う値。

### 計点

- 手作りの局面：単純な地・セキ（共有の空点は数えない）・死石の印を付けた場合・コミで引き分け・1 目差。
- 死石の推定：明らかな死石（地の中に 1 子）を死、セキの石を活と推定する。プレイヤーの切り替えが連単位で効く。

### MCTS

- 同じシード・同じ総数なら同じ手、1 Tick の上限を変えても（1／7／総数）同じ手。
- 木とプレイアウトが打つ手は全て合法（同型反復を含む）。プレイアウトは上限手数内で終わる。
- 詰めの局面：取れば勝つアタリの大石を取る、自分の大石のアタリを逃げる、自分の眼を埋めない。
- 強さ：既定の「弱い」でもランダム打ちに多数シードで勝ち越す。「強い」が「弱い」に勝ち越す（数字は README に記録、特定の Tick・軌道は期待しない）。
- 投了の条件・パスの選び方（相手がパスした後、パスで勝てるならパスする）。

### 共通

- 状態遷移：タイトル → 対局 → 終局 → 死石の確定 → 結果 → 再戦（新しいシード）。終局後・死石の確定中の着手は拒否。CPU の手番の入力は捨てる。一時停止中は Tick（CPU の探索も）が止まる（044）。
- 負テスト：盤外・埋まった点・手番違い・終局後の着手・二重の投了・同じ Tick の重複したクリック。
- 設定の検証（プレイアウト数・1 Tick の上限・コミ・手数の上限・勝率の閾値の境界と NaN）。
- 操縦役どうしの 1 局の最終ハッシュを .NET と Mono で固定値と照合（整数だけで書くので一致する）。

### PlayMode

- 仮想キーボードとマウスだけで弱い CPU と 1 局を終局し、死石を確定して結果画面へ（操縦役の手をキー入力に変換）。
- 自殺手・コウの点をクリックすると理由が出て石が増えない。
- 一時停止・フォーカス喪失・投了、タイトルへ戻った表示が起動直後と同じ（021）。
- CPU の思考中にフレームが止まらない（1 Tick の上限で分けて回していることを、フレームの処理時間で確かめる）。
