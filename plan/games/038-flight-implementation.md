# 038 フライトゲーム 実装計画

## Context

- 038 フライトゲーム（難易度 4・Phase 2）は未着手。仕様書 [plan/games/038-flight.md](./038-flight.md) の中心課題は「**姿勢（Quaternion）と速度・揚力近似を管理**」、重点は「**追尾誘導を分離**」。

## ルール表（セッション1・2で README に固定する要点）

| 項目 | 採用ルール |
|---|---|
| 時間 | 60 Tick/秒。入力は起きた時刻を含む Tick に反映（022・037 の時刻つき入力、フレーム単位の Tick 上限） |
| 座標 | 1 単位 = 1 mm。x 右・y 上・z 北（Unity と同じ左手系にして描画の変換を素通しにする）。位置・速度は `long`（3 成分の `Vec3l`）。浮動小数点は使わない |
| 姿勢 | 整数クォータニオン `Quat`（成分は Q30 の `long`、積は 128 ビットに溢れない範囲で右シフト）。毎 Tick、機体軸の角速度から小回転 `(1, ω·dt/2)` を右から掛け、`IntMath.Sqrt` で正規化する（ノルムのずれが許容内に留まることをテスト）。機首・上・右の軸は単位ベクトルを回して得る |
| 操作 | ピッチ（W/S または ↑↓）・ロール（A/D または ←→）・ヨー（Q/E）、スロットル（Shift 上げ/Ctrl 下げ、段階 0〜100%）、Space ミサイル、Tab 目標切替、Esc 一時停止 |
| 舵の効き | 角速度の上限 × 入力 × 効き。効きは動圧の近似 `min(v² / vRef², 1)`。低速では舵が効かない |
| 迎角 | 機首と速度方向のなす角を機体の上下面に射影した値（迎角）と横（横滑り角）で持つ。速度は自動では機首に揃わない |
| 揚力 | 機体の上方向（速度に直交する成分）へ `CL(迎角) × v²`。`CL` は `StallAngle` まで線形、超えると急に下がる（**失速**）。横滑りには横力で速度を機首へ寄せる |
| 抗力・推力 | 推力は機首方向、スロットルに比例。抗力は速度の逆向きに `(Cd0 + k·CL²) × v²`。旋回で迎角を取るほど減速する |
| 失速 | 迎角が `StallAngle` 超、または速さ < `StallSpeed`。失速中は揚力が落ち、機首が下がる回転を足し（下げ頭モーメント）、ロックオンの継続も切れる。HUD に STALL を出す |
| 地上 | 滑走路の上で車輪接地。ロール・ヨー入力は地上では向きだけ（車輪の転舵）、ピッチは速さ ≥ `RotateSpeed` で機首上げ可。揚力が重さを超えたら離陸。滑走路の外の地面を走ると墜落 |
| 墜落 | 離陸後、機体の円（当たり半径）が地面（y = 0）に触れたら墜落。Tick 中の軌跡で判定する（`y` の符号の変わり目、ちょうど 0 も接触） |
| 区域 | 一辺 `ArenaSize` の正方形と高度上限。外に出たら警告し、`OutOfAreaTicks` 続けば失敗 |
| ロックオン | 目標が機首から `LockCone` 以内・`LockRange` 以内・自機が失速していない間、`LockTicks` 連続で LOCK。条件を 1 Tick でも外れたら解除。目標は円錐内で最も機首に近い敵、Tab で次へ |
| 発射 | LOCK 中・残弾 > 0・再装填 0 のときだけ発射。それ以外は拒否（理由を返す：未ロック・弾切れ・再装填中・地上・終了後） |
| ミサイル | 自機の速度＋`LaunchBoost` で機首方向へ。運動（`MissileBody`：速さ・最大旋回率・寿命）と誘導（`IGuidance`：目標の位置・速度から欲しい旋回を返す純粋関数。既定は比例航法 `ProNav`）を分ける。当たりは Tick 中の相対軌跡で近接信管の半径に入ったか（3D の掃引、整数で厳密）。地面に触れたら消える |
| 追尾終了 | 目標が撃墜された（同じ Tick に別のミサイルが先に当たった場合を含む）・寿命・地面で誘導をやめる。目標を失ったミサイルは直進して寿命で消える（新しい目標を探さない） |
| 被弾 | 敵は 1 発で撃墜。プレイヤーは耐久 2（2 発目で撃墜）。同じ Tick の複数命中は番号順に 1 発ずつ処理し、撃墜済みには当たらない |
| 敵 | 3 機は同じ飛行モデル。`EnemyPilot`：プレイヤーの未来位置へ向かう旋回（ロール→ピッチ）、速度を保つスロットル、低高度では引き起こし。ロックはプレイヤーより遅く（`EnemyLockTicks`）、発射間隔・残弾は少なめ。初期位置と操縦のぶれは試合のシード（場面ごとに系列を分ける、015） |
| ミッション | 離陸 → 区域の中心へ。3 機撃墜で成功、被撃墜・墜落・`MissionTicks` 経過・区域外で失敗。終了の Tick 以後の入力・Step は状態を変えない |
| 乱数 | 1 試合 = 1 シード（`SeededRandom`）。再戦は起動時の値から進めた新しいシード（010） |

## セッション1：整数の 3D 数学と飛行モデル（Core）

- `Vec3l`（long の 3 成分、内積・外積・長さは `IntMath.Sqrt`）・`Quat`（Q30、積・共役・ベクトルの回転・小回転・正規化）。float の参照実装（テスト側の `System.Numerics`）と乱数で誤差内の一致を照合
- `FlightConfig`（公開フィールド＋検証：有限・範囲・失速速度 < 離陸速度 < 最高速度、1 Tick の移動量・回転量の上限）
- `Aircraft`（位置・速度・姿勢・スロットル・接地・失速・耐久）と `FlightModel.Step(Aircraft, Controls)`：舵 → 姿勢 → 迎角・横滑り → 揚力・抗力・推力・重力 → 速度 → 位置 → 地面
- `AirData`（迎角・横滑り角・速さ・失速かどうか）を Step の結果として公開し、HUD とテストが同じ値を見る
- テスト：
  - **機首と速度方向のずれ**：水平飛行からピッチを上げた直後は迎角 > 0（機首が速度より上）、数十 Tick で速度が機首へ寄る。横滑りがヨーで生じ横力で減る
  - **失速**：迎角を `StallAngle` の前後 1 単位で揚力が切り替わる。低速ではピッチ入力の角速度が下がる。失速すると高度を失い、機首が下がる。スロットル 0 の上昇で速度が落ちて失速に至る
  - 離陸：`RotateSpeed` 未満は機首が上がらず浮かない、超えて機首上げで浮く、滑走路の外へ出たら墜落
  - 墜落：降下で地面にちょうど触れる Tick、1 Tick で地面を跨ぐ速さでも見逃さない
  - クォータニオンのノルムが 10 万 Tick の旋回で許容内、ロール 360° で元の姿勢へ戻る（誤差内）
  - 設定の検証：NaN・範囲外・順序の矛盾を拒否

## セッション2：ロックオン・ミサイル・敵・ミッション（Core / App）

### Core
- `LockOn`（目標の選択・連続 Tick・解除の理由）、`Missile`（`MissileBody` と目標の番号）、`IGuidance`・`ProNav`（誘導は位置と速度だけを受け取る純粋関数）、`Sweep3D`（動く球どうしの最初の接触。2 次式を整数で厳密に、`Sweep.Touches` と同じ考え方で大きい値は `BigInteger`）
- `EnemyPilot`（`Controls` を返す純粋関数。プレイヤーの Autopilot にも使う）
- `MissionConfig`・`Mission`（Tick の順序：入力 → 全機の Step → ロックの更新 → 発射 → ミサイルの誘導と移動 → 命中（番号順）→ 墜落・区域・勝敗）。`Hash()`（全機・ミサイル・ロックの連続 Tick・再装填・乱数まで、022）・`Clone()`

### App
- `Intent`（舵は押している間の軸、発射・目標切替は押した瞬間の出来事。キーごとの押下を Flow が持つ、035/037）
- `SortieFlow`：Title / Briefing（操作説明）/ Playing / Paused / Result。時刻つき入力、フレームの Tick 上限、フォーカス喪失で保留入力も消して一時停止、再開は手動
- `Autopilot`：`EnemyPilot` の考え方で離陸 → 接近 → ロック → 発射 → 回避。試合ごとに判断状態を捨てる（023）

### テスト（題材固有を優先）
- **ロック解除で発射拒否**：LOCK の 1 Tick 前は拒否、LOCK で受理、円錐の外へ 1 Tick 出た直後は拒否、範囲外・失速・弾切れ・再装填中・地上・終了後もそれぞれ拒否し状態を変えない
- **目標撃墜時に追尾終了**：2 発を同じ目標に撃ち、先の命中の後に残った 1 発は誘導せず直進して寿命で消える。同じ Tick に 2 発が当たっても撃墜は 1 回。他の敵へ乗り換えない
- 誘導の分離：`ProNav` を直進目標・等速旋回目標で単体テスト。`MissileBody` は旋回率の上限を超えない。急旋回する目標には外れる（回避に意味がある）
- 掃引：速いミサイルが近接半径より短い距離ですれ違う場合も命中、ちょうど半径は当たらない（規則を決めて固定）、浮動小数点の細分参照と乱数で照合
- ミッション：3 機撃墜で成功、プレイヤー 2 被弾で失敗、墜落・時間切れ・区域外の失敗、結果後の操作は無視
- 状態遷移・負テスト：開始 → 進行 → 終了 → 再戦、一時停止中の入力、重複押下、未定義の操作、不正な設定
- 再現性：同じシード・入力列で同じハッシュ、操縦役が 20 シードで離陸から 3 機撃墜（決着して上限内）、シード 1 の最終ハッシュを .NET と Mono で固定値照合。30〜240fps で同じハッシュ

- 計画との差：

- Core 33 件（.NET）、共通パッケージを含めて Mono 95 件。離陸から上昇・旋回・横滑り・急降下を混ぜた 3000 Tick の最終ハッシュ `1290656686` が .NET と Mono で一致。
- 既定値：離陸は約 61 m/s・約 250 m（8 秒）。150 m/s から引き続けると宙返りでき、70 m/s まで落ちる。

  - 敵が強すぎた。8 G・420 m/s の敵のミサイルで、操縦役は 20 シード全てで撃墜された。敵のミサイルを 6 G・280 m/s、ロックを 1.8 km／3 秒、プレイヤーの耐久を 3 にした。操縦役は 60 シード全てに勝つ（最長 197 秒、制限 300 秒）。
  - 敵は自分を追うミサイルが 800 m 以内なら視線と直角に逃げる。操縦役は避けない（避けると勝率が下がった）。
  - 操作説明はタイトルに置き、別の画面（Briefing）は作らない。
  - テストで場面を作るため、`Mission` に internal の `Place`・`Launch`・`EnemyPilots` を置いた。
- Core 65 件・App 13 件（.NET）、共通パッケージを含めて Mono 140 件。操縦役のシード 1 の最終ハッシュ `2858234725` が .NET と Mono で一致。
